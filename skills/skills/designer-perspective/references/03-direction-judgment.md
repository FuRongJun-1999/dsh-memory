## 二、方向判断的三问

### 问 1：值不值得做（Gain_task）

筛选器。先问这个任务是否值得进入策略搜索——不是所有「能做的」都「值得做」。

### 问 2：对任务值多少（ΔD_task）

定价器。该路径能缩小多少任务信息差。价值 = ΔD_task × σ(Gain_task)。

### 问 3：成本是多少（K_π）

结构成本 = 导航税 + 验证成本 + 计算开销。**导航税的本质是持续跟踪判断进程的成本**——因此状态跟踪与条件判断应外部化到确定性机制（附录22.1），LLM 只负责提供候选假设。

决策式：在有限结构成本下，选择能够最大程度缩小信息差的认知路径。

## 三、边界与纪律

1. **层级边界**：π* 只适用于 L1/L2 策略搜索层；L3 存在级决策不适用 π*，须走完整八步闭环 + 维生系统终裁（5.3 权限边界声明）。
2. **不是裁决机制**：目标函数是启发式描述，不构成对维生终裁权的绕过。
3. **观测不干预**：设计者视角可发关注信号（signal），不直接干预内部决策。
4. **盲区驱动方向**：识别未知区域并据此决定方向——方向来自「哪里不知道」，而不是「哪里最像」。
5. **责任激活**：位置效应由责任激活；无责任承担时方向判断不产生约束力，因此每轮须产出可核查的判定单。

## 四、与 md_cg 的对应

| 能力 | 工具 | action | 说明 |
|------|------|--------|------|
| 候选未来 | `mdcg_predict` | `routes` | 沿因果/时序边 + 语义邻近（经伪因果过滤门）生成局部路线；输出 uncertainty_bound / extrapolation_validity / T_pred 四维评分（trend .40 / boundary .20 / verification .25 / balance .15） |
| 盲区驱动预测 | `mdcg_predict` | `routes` + `blindspot_id` | 从 unresolved 节点或盲区邻域键出发生成路线 |
| 命中反馈 | `mdcg_predict` | `feedback` | 命中 → 边置信度 +0.05；未命中 → 登记 rejected（D-006 动态校准） |
| 信息差与二阶变化 | `mdcg_reflect` | — | 记录 D(t,C) 与 d²D/dt²，写 `_reflection.jsonl` |
| 未解问题 | `mdcg_unresolved` | — | 读取待补条件的 unresolved 条目 |
| 自我状态 | `mdcg_self_state` | `snapshot` | 信息差 D/d1/d2、信任 P_gap/P_trust |
