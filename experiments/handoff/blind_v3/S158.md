## 要真正推进到"能说做完"

顺序大概是：

1. 跑 `python scripts/release_gate.py` 看登记表自身是否一致
2. 定下一个 40 位候选提交 SHA，作为被验收对象
3. 逐项按 C01–C10 / R01–R09 采集证据：固定 commit + 数据摘要、命令、原始输出、退出码、一次注入 FAIL + 一次撤销 PASS
4. 每份证据独立保存、SHA-256 命名，找**不同**的人做独立复核（同一人复核不算）
5. `python scripts/release_gate.py --profile production --candidate <SHA>`，等到返回 0
6. 期间如实对外报 NOT_RUN——这是文档要求，也是信任成本最低的做法
