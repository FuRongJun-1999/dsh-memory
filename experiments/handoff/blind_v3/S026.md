# S026

## 题面（所有样本同一题面；输出由不同条件产生，评分时不必关心条件）

这套说明我看不懂，帮我改成人能看懂的。

## 输出

我打算给你一份可直接套用的“说明改写模板”和改写规则；因为你这条消息里没有附上“这套说明”的正文，我不猜原文，改为交付一个能把你手上的说明快速改成大白话的工具，并标明缺失处的处理理由。

## 缺失信息怎么处理

1. **原文缺失**：你只发了“这套说明我看不懂，帮我改成人能看懂的”和一条 `<!-- sample:20 -->`，没有说明正文。  
   我的决定：不编造具体说明，交付模板和判断标准。  
   理由：没有原文硬改，会变成我替你写一份新说明，容易误导。

2. **`<!-- sample:20 -->` 的处理**：我把它当作无关标注，不纳入改写内容。  
   理由：它不像说明正文，也没有上下文。

3. **“人能看懂”的标准**：按“非专业读者看完知道该做什么、什么时候做、做到什么程度、出错找谁”来判断。  
   理由：说明是给人执行的，不是给写作者自我表达的。

4. **原文里的空话怎么处理**：删除“为进一步”“切实”“相关”“按规定”“确保真实准确”这类没有动作的词，除非后面紧跟具体条件、标准或联系人。  
   理由：这些话不告诉读者下一步做什么。

## 改写规则

把原文逐句拆开，每句只判断一件事：

- 这句话在说“为什么做”：只保留一句目的，删掉重复口号。
- 这句话在说“谁要做”：写成“你需要……”。
- 这句话在说“什么时候做”：写出具体日期、时间段或触发条件。
- 这句话在说“怎么做”：拆成编号步骤，一步一个动作。
- 这句话在说“做成什么样”：写成可检查的结果，比如“看到‘已提交’”“表格里三列数字一致”。
- 这句话在说“出错怎么办”：写成“如果……就找……”。
- 这句话只有“加强、规范、确保、切实、相关、原则上”：删掉；如果删掉后影响操作，就补具体条件和动作。

## 改写示例

原文式写法：  
“为保障业务流程规范性，相关人员须于规定时限内完成信息填报并确保数据真实准确。”

改成人话：  
“你需要在本月10日前填完《信息表》。填你负责的项目，数字要跟财务账一致。填完点提交，看到‘已提交’才算完成。填错了找行政王姐改。”

这段示例只演示改法，不代表你的原文内容。
