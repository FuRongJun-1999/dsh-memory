## 你自己验一遍

在仓库根目录跑：

~~~text
python scripts/check_all.py
~~~

Python 3.11+，只用标准库，不用装任何依赖。意思就是：把所有检查跑一遍。

另有一份目录清单 `scripts/spec-tree.lock.json` 和只读检查器 `scripts/spec_tree.py`：逐个文件核对规格目录里每个文件的名字和内容摘要，对不上就报出来。增、删、改都要有人看过；机器不会自己重写清单。**清单对得上，也不等于我获准发布。**
