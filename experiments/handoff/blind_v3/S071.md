# 《记忆系统给别人用之前：人话版风险说明》

## 一句话结论
可以给别人用，但**别承诺“它不会记错”**。要承诺四件事：

1. 每条重要记忆**有来源**；  
2. 不确定时**会明说**；  
3. 错了**能改、能追**；  
4. 隐私和权限**说清楚**。

信任不是“从不出错”，而是“错了不藏、能修、有人负责”。

---

## 最可能出问题的 8 个地方

| 毛病 | 为什么会让信你的人吃亏 | 怎么改 |
|---|---|---|
| 把“猜的”当“记得的” | 你可能根据推断做决定 | 推断必须标“不确定”，不能当事实 |
| 没来源、没时间 | 不知道信息从哪来、还准不准 | 每条重要记忆带来源和时间 |
| 过时信息不提醒 | 旧情况被当成现在 | 设过期时间/定期复核 |
| 冲突信息自动合并 | 两个说法被合成一个“确定答案” | 冲突时并列显示，不擅自下结论 |
| 谁都能看、改、删 | 隐私泄露或被人误改 | 分权限，关键操作二次确认 |
| 删除不彻底 | 用户要求删了，备份里还有 | 删除流程覆盖备份和导出 |
| 没有纠错入口 | 错了只能干着急 | 一键标记“错误/过时”，说明响应时间 |
| 记忆越过边界 | 泄露第三人信息、给人贴标签、替代承诺 | 不把 A 的信息用于 B；不用记忆评价人 |

尤其注意：**钱、健康、法律、承诺、关系这类高风险决定，不能让记忆系统单独决定，必须人工二次确认。**

---

## 给别人看的《使用须知》草稿  
可以直接复制给对方：

> 1. 这个记忆系统是辅助，不是最终裁判。  
> 2. 重要信息必须二次确认，不能只靠它。  
> 3. 看到一条记忆时，请看：来源、时间、是否标“不确定”、谁最后确认。  
> 4. 发现错误，请点“纠错/标记过时”，说明哪里错了；我会在约定时间内处理，并通知受影响的人。  
> 5. 只记录必要信息；敏感信息单独授权；你可以要求查看、导出、删除你的记忆。  
> 6. 我不会把 A 的信息用于 B，也不会用记忆给你贴标签。  
> 7. 如果系统说“不知道/不确定”，这是正常且负责的表现，不是敷衍。  

---

## 记忆条目最少要有这些字段
内容 / 来源 / 记录时间 / 最后核实时间 / 置信度 / 适用条件 / 可见范围 / 过期时间 / 纠错记录。

一句原则：**没有来源和时间的记忆，只能当线索，不能当事实。**

---

## 交接前 12 项自查
- [ ] 每条重要记忆能点开看来源  
- [ ] 过时信息会自动标记或提醒  
- [ ] 冲突信息不会自动合并成“确定事实”  
- [ ] 不确定时系统会说“不知道”  
- [ ] 有查看/修改/删除权限  
- [ ] 删除后备份也处理  
- [ ] 敏感信息单独保护  
- [ ] 涉及第三人信息有同意或脱敏  
- [ ] 关键操作有日志  
- [ ] 有纠错入口和响应时间  
- [ ] 高风险决定要求人工复核  
- [ ] 定期抽查准确率并记录  

---

## 出错后的处理流程
发现 → 先标记“待核实”，别继续用 → 通知受影响的人 → 更正或删除 → 查原因 → 写进变更记录 → 必要时补偿。  
**核心不是不犯错，而是错了能发现、能改、能追责。**

## 关于你想得到认可
认可别押在“完美记忆”上。别人更会认可一个：敢说不知道、有来源、能纠错、保护隐私、出事负责的人/系统。  
你可以直接说：**“我不敢保证它永远不错，但我保证错了你能看见、能改、能追。”**

如果你要我具体看毛病，给我：系统功能清单、使用者是谁、存什么信息、权限怎么设、能不能删除、有没有日志和纠错入口、典型使用流程。我可以按这份清单逐条帮你标风险。
