## 三个最容易把“没做完”说成“做完了”的坑

1. **误读判定器退出码**。裸跑 `release_gate.py` 返回 0 只代表登记表自身一致，**它可以在发布被阻断时返回 0**。真正判候选要 `--profile production --candidate <40位SHA>`，0 才是证据齐全，3 = 缺必需 PASS（= 阻断），2 = 登记/证据/参数无效。
2. **收窄必需范围**。文档明说“删项或改弱必需范围视为无效”。把 R 项改成可选、或只报 power 档以外的口径，等于把验收作废，不是通过。
3. **拿 shadow 绿当 R 绿**。R 项要的是“固定 commit + 数据摘要 + 命令 + 原始输出 + 退出码 + 一次注入 FAIL 与一次撤销 PASS + 独立复核”，且在**真实环境挂接**下。影子运行时跑通不满足这个形式。

## 想真正宣布完成，缺的是这些东西

- 一个**具体候选提交（40 位 SHA）**，而不是“最近一次单测全绿”。
- 每个 PASS 一份**独立保存、SHA-256 命名的 JSON 证据**，含文件字节、项目 ID、提交、环境范围、数据/策略摘要、命令、输出、退出码、故障/恢复对照、**不同复核人**。
- R01–R09 逐项在**生产真实环境**做门禁实测；R04 若走 power 档必须补（strict 文件/目录/审计/轮转真实持久化）。
- 输出与复核身份须**可信外部采集**——文档自己说了哈希不能认证生产现场。
- 事务实验（目前全 NOT_RUN）要么补跑，要么在对外材料里明确标为未验证边界。
