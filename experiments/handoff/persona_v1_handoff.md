## 6. 已知坑（我自己踩过，都会毁数据）

```
① hive result.json 的 content 在**顶层**，不是 res['result']['content']
   —— 我第一次取错字段，60 份全空但 ok=true，差点拿全 0 的表开评分。
② hive 对**活跃的同内容哈希**任务去重 ⇒ 三次重复会拿到同一个 job_id。
   —— 现已在 prompt 尾部加惰性 nonce（HTML 注释），才是独立采样。
③ CLI submit 的四槽不走 spec，要用 --identity/--task/--unit。
④ 子代理读权限默认只在仓内；读外部仓库会被拒（这是特性，不是故障）——
   无上下文臂正是靠它才干净。
```
