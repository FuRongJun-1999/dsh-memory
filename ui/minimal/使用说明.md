# 灵枢极简 UI 分享包 v1.0

这是原版灵枢 `@furongjun1999/dsh-memory` 的前端增量包，不是独立技能，也不包含灵枢大脑本体。适配本次已验证的灵枢 0.8.1 单桥入口；0.9.x 仅在安装器兼容性检测通过后安装（0.9.11 未做跨版本实测，安装器会先检查再落盘）。

## 群友安装（Windows）

1. 先在自己的 DSH 安装并启用原版灵枢插件。没有安装灵枢的电脑，仅凭本 UI 包不能使用记忆功能。
2. 完全退出 DSH，包括托盘后台。
3. 解压本包，双击 `安装UI.cmd`。会自动寻找当前用户的灵枢插件；找到多个或找不到时，输入自己灵枢插件的根目录（包含 package.json 的那一级）。
4. 重新启动 DSH，左侧点击「灵枢」。若侧栏没有出现，检查插件是否启用、安装目录是否属于正在使用的 profile，以及 DSH 是否已完整重启。
5. 权限不足时查看灵枢自己的凭据设置；安装器不会签发令牌或绕过权限。

PowerShell 方式（可指定路径，推荐先检查）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -PluginPath '你自己的灵枢插件目录' -CheckOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -PluginPath '你自己的灵枢插件目录'
```

这里只对这次脚本进程使用 Bypass，不修改系统执行策略。不要运行来源不明的安装脚本。

## 为什么读取的是各自电脑的记忆？

本包只补 UI 代码，服务端复用接收者**已配置的同一个 MdcgClient 大脑桥**，没有内置任何作者记忆或作者路径。所有页面调用使用当前 DSH 的同源接口，不连接作者电脑，也不设置远程记忆服务器。

原版灵枢默认记忆根位于当前用户 DSH_HOME 下的 `.dsh-memory/data/mdcg`；常见 Windows 默认展开为 `%USERPROFILE%\.dsh\.dsh-memory\data\mdcg`。如果接收者已有 MDCG_ROOT、paths.json 或 mdcg.root 自定义配置，沿用他自己的配置，不强行改回默认。

因此：甲打开看到甲的记忆，乙打开看到乙的记忆；新用户的空库仍是空库，不会出现分享者的记忆。若用户主动把 root 配到共享盘/同步盘，其共享行为由他自己的配置决定，本包不保证同一电脑多用户或多 profile 自动分库。

安装器不修改认知图 root、身份主体、自动记忆开关、MDCG_TOKEN、DSH profile 或凭据。原版灵枢启动后本来就会记录/读取自己的记忆，那是原插件行为，不是分享包导入。

## UI 功能

概览、记忆检索与写入、目标任务、自我认知、时空关系、审核维护，以及真实 MCP 工具目录和 JSON 调用入口。常用功能填表，全部未单列的能力进入「工具台」。工具数量取决于群友安装的灵枢版本，不硬编码为33。

保留原插件权限和护栏。页面及 API 依赖支持 connection.admit 的 DSH 宿主鉴权；不兼容的旧宿主会明确报错，不会降级开放。修改操作需确认；记忆写入可能接受、合并、丢弃或进入审核，以真实回执为准。

## 包内包含什么 / 不包含什么

包含：前端页面、侧栏客户端 bundle、同源接口代码、构建脚本、安装器、完整性清单、MIT 许可。

不包含：作者记忆图、data目录、keys、token、.credentials.yaml、paths.json、个人profile、session、聊天记录或原版灵枢全插件副本。

**只分享本 ZIP；不要直接压缩你自己的 .dsh、.mdcg、灵枢整个运行目录或安装器在你本机生成的备份。** 本地备份可能含你原来插件源码中的个性化改动，仅用于回退。

## 卸载与升级

完全退出 DSH 后双击 `卸载UI.cmd`，或对同一插件目录执行 `install.ps1 -Uninstall`。只恢复本安装器备份的代码，不删除记忆。

如果安装后源码/清单发生变化，卸载会停止，避免把你的新改动或上游升级覆盖掉。不要强制绕过。原版灵枢升级可能替换 UI 文件：升级前卸载 UI，升级后检查本包是否仍兼容，再安装。已安装则重复执行不会覆盖。

## 验证范围

原实现：8项接口测试通过，真实只读认知图页面交互及390px响应式测试通过，现有DSH客户端模块图和受保护路由已挂载。已登录桌面GUI的最后点击链路由使用者自行确认。

分享安装器额外在临时插件副本验证：兼容性检查、安装、幂等、不兼容拒绝、安装后变化防覆盖、卸载逐文件恢复，以及记忆/paths/profile哨兵不变。接收者不同DSH版本的安装尚未跨机器实测。
