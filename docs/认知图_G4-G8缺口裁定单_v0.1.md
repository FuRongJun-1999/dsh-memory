**归因（三方条件空间 × 失配维度）**

| 对象条件 | 230 条混合内容（流水账/感知产物）与 6330 条知识共层 | 对象条件失配：**情境性内容被当作长期知识** |

**执行前置条件（全部满足才动手）**

4. **回滚路径**：按批次号或 id 定向回滚（复用 promote/rollback 的幂等模式），**执行后立即实测回滚 1 条再迁回**；

7. **副作用登记**：层计数（knowledge 6330→6100、contextual 0→230）与召回指标变化必须登记。

**不做**：不删节点、不合并、不改正文、不补 comment、不动 `ccg_exempt`。

## 十、纪律蒸馏（可复用）

1. **库根先声明**：本次实测发现工作区库根仅 1 节点、真实库在异地仓库——**观测前先冻结「对象是谁」**，否则一切计数无效。
2. **空字段 ≠ 漏写**：`evidence={}` 是「口径未声明」而非「写入遗漏」。**先定位产出侧根因，再决定补写还是标注**；补写前必须能回答「这个值由谁产出」。
3. **DEFER 的正确出路是「条件化」而非「取消条件」**：G6/召回分池由 DEFER 转 ACCEPT 靠的是**声明前置条件**（20 条抽检 / 先冻基线），不是降低标准。
4. **层位移必须成套**：字段 + 落点目录 + 演化条目 + 批次台账 + 回滚路径，**五件事缺一即为不可回滚的脏改**。
5. **脱敏是内容约束而非形式约束**：编号引用 + 只落结构化字段 + 不读原图，**且不得在库内留下敏感语义描述**。
6. **证据「有源才落、缺一不落」**：回填前先定「这个值由谁产出」——本轮 70 条全部命中档 2、20 条**宁可空着标 BLINDSPOT**；
   把 `model_evidence`（本库不存在）当默认值硬填，就是幻觉落库。
7. **扫描范围要按「识别规则」而非「当前落点」定**：视觉节点按 id 前缀全层识别，才没漏掉 G4 因 fail-closed 留在 `knowledge` 的
   2 条密文节点；**用「已知落点」当扫描范围 = 制造静默盲区**。
8. **层位移与证据回填的跳过语义要一致**：无密钥节点两轮都 `fail-closed` 计数，**绝不因为「流程要求走完」而解密或编造**；
   跳过项要能与「已处理项」在报表里区分（`skipped_locked` vs `written`）。
9. **「抽检单位」必须先于「抽样」定死**：`min_cluster=3` 下 20 条**节点**样本 0 簇——抽检单位若取「节点」，
   小样本会**结构性**交不出可核对对象，抽检流程看起来跑完了却很可能是空跑。抽检设计第一步应自检
   「这个样本量能否产出 ≥1 个待核对单元」，**否则抽检=形式合规**。
10. **词面统计判据必须显式声明 df 阈值**：没有 df 门槛时，「整行含时间戳的条件文本」会伪装成唯一区分性特征；
   模板词与伪区分性是**同一根因（归一化缺失）**的两面——先声明口径再抽检，否则人工核对只是在核对噪声。
11. **只读预演与写入必须分权**：`refine` 全程只读（工单/预演/闸门/校准），真写节点的口子留在 `consolidate.induce`；
   把「能不能写」与「写什么」拆到两个 op，才能让「预演先行」成为**机制**而非**自律**。
12. **「有能力」≠「有驱动」**：G7 的缺口不是缺功能（`consolidate`/`weights`/`scrub` 早已存在），
   而是缺一个周期性问「现在有多少候补」的**驱动源**。补驱动必须**同步补闸门**——否则驱动会把
   「偶发的人工决策」变成「每 2 小时自动执行」，风险等级完全不同；且自动范围应**只取确定性动作**。
13. **代理指标要标注为代理**：巡检为省 IO 用索引字段（`verification_basis`/`has_neg_conditions`）
   替代「读正文算 CCG 完整度」——必须在返回里显式写 `proxy=true`，否则下游会把候补量误当判定结论。
14. **同名概念不等于同一落点**：「链接 / 血缘 / 信任」在话术里都叫 link，落到存储却是两层
   （`_links.json`=对端信任 vs `_link.jsonl`=节点血缘）。**先判「这是同一件事吗」再决定复用还是另立**——
   G8 若照原裁定复用 `links.py`，就会把演进血缘写进信任台账，事后无法区分。另立层时必须把
   「与谁不同」写进 `catalog`（本条即 `distinct_from` 字段的来源）。
15. **写路径的校验只允许「不阻断」形态**：派生关系名非法、来源节点不存在、台账 IO 失败——三者都不能让
   节点写入**假失败**。要严格校验就挪到**显式 API**（`normalize_relation`），写路径只做
   **回退默认值 + 降级留痕**；且「留痕」必须真的留下（`.fail` 台账），否则「降级」等于「静默吞掉」。
16. **「不回填」需要在重建路径上同样成立**：`rebuild_ledger` 若按「扫描全库反推血缘」实现，
   就等于借重建之名行回填之实。正确做法是**只重放已有的显式声明**——重建的输入必须是
   **声明**（frontmatter）而不是**推测**（id 前缀 / 相似度）。
17. **复测口径必须先自检「对改造敏感」**：§七 冻结的 P95/全局截断率，对「在 `GLOBAL_CAP` 之内重分配额度」
   的改造**恒不敏感**（delta ≡ 0）——这不是「改造无效」，而是「口径测不到」。**先证明口径能测到被改的量，
   再看差值**，否则复测只是形式合规（与纪律 9「抽检单位先于抽样」同构：**量具先于测量**）。
   落地形态：`compare` 显式回 `insensitive_keys`/`sensitive_keys`，把「差值恒 0」标成**正常**而非沉默。
18. **同一逻辑的两条实现路径必须双路验收**：`MdCG.search` 与 `MdCGOS.search` 各有一份 T2/T3 截断点；
   只测一条（P43 只走 `MdCGOS`），另一条漏改会**静默存活到生产调用**（本轮即 `NameError`，由跨模块回归批次抓出）。
   改动落在「共享搜索骨架」时，验收必须**枚举所有实现类**，否则「全绿」只覆盖了一半。
