## 判定

**缺口 ＝「情绪/情感读数 → 决策」的结构化通路：本系统的情绪读数（信息差二阶）与情感读数（信任二阶）**齐备且有落盘，但全部止于「读数/卡字段/建议」；唯一被消费处（`consistency.py:751` 的 L2 递归调度、`autonomy.py:177` 的提案评分）是**附带的、未以情绪命名的、且明文不参与信任/资格计算**。即「读数已长成，结构未长成」。

逐条差距（既有机制 vs 理论要求）：

1. **有情绪（`emotional_bias`），但只调度流程**：`approaching` 时跳过 L2 递归（`consistency.py:751`）——改的是「补不补算 `recursion/missing`」，不是判定/资格；且明文「不参与信任/资格计算」。
2. **有情感（`affect`），但只是卡字段**：`self_state` 的 `affect`＝信任二阶（`:397`），**0 处显式消费**——不参与任何决策/排序/判定。
3. **有 §2.9 公式（`E_weight`），但在编译层**：`name_checker.py:184`（总评公式）、`:400-418`（上限）、`condition_vm.py:66/192-200`（寄存器）——**声明/校验面**；系统自身对协作者信任的二阶计算（§2.9 语义）**无落地**，`links.py` 仅一阶 `P_trust`。
4. **有 `|d2|` 进评分（`autonomy.py:177`），但未以情绪命名**：信息差二阶幅值作提案评分权重——**最接近「二阶信号→决策」**的一处，但作用于 autonomy 提案面，不触及写入/资格/检索。
5. **情绪/情感不是检索维度**：`self_state.DIMENSIONS = ("task","person","session","time","trust")`（`self_state.py:86`）——**无 `emotion`/`affect` 维**，情绪/情感不可作为 `self_state.index` 的检索维度。
