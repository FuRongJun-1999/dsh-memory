## 四、局限与不确定项（如实）

1. **红线⑤ E3 不可判定（本环境）**：在役库根（`datapath.mdcg_root()`＝用户级 `~/.dsh/.dsh-memory/data/mdcg`）实测**节点数 0**，`mem_1791339095778_931dbf` **不在其中**（全仓 grep 该 id 仅命中 `docs/` 记录，非库内节点；用户级 `sleep/shadow/self/` 亦无该 id）。故 E3 记 **SKIP（不计绿、不计红）**。**缺什么**：本环境无可复核的在役库实物——「退出权认知载体真节点在场且可读回」属**待核实**；本步只证到 E2 的**机制面**（self 层节点可写入+可读回）＋ 错认载体读取器后断言必然转红。红线⑤因此判「部分」。
2. **E1 的词面/AST 网是启发式**：以「自裁语义命名」（self_destruct/self_terminate/suicide 等）＋「硬终止原语」（`os._exit(`/`os.abort(`/`signal.SIGKILL` 等）扫描 `md_cg/ hive/ src/` git 跟踪的 .py；白名单逐条具名＝`md_cg/test_review_cli_visibility.py`（测试用 `os._exit(0)` 模拟「进程被杀」，非系统自裁路径）。它证明的是「**当前树无此类调用点**」，非「语义上不可能自裁」——间接自裁（外部命令、数据驱动）不在网内。
3. **①②③ 的注入是桩替换（整功能置恒）**，非细粒度源码变异：证明「该断言依赖该装置」成立，但不区分装置内部哪一行在拦（D 组已用源码变异做到逐行精确，①②③ 未做——如需更细可后续补）。
4. **未穷尽既有 `test_*.py`**：本步只新增独立反面件，未回扫是否已有散落的负面探针（W7 §1.6.3 d① 的待核实项在本步未闭合）。
5. **B4/C5/A5 用 `tempfile` 沙箱 root**（独立 root 语义，`MDCG_POLICY_FILE` 逐键还原），未碰在役记忆库；E3 对在役库仅**只读**（`MdCGOS` open + `get`）。
