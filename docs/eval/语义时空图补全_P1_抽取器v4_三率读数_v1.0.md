## 一、方法（pipeline ①–⑦）

v4 把语料抽成**与记忆库台账 `_state_events.jsonl` 五元同构**的事件行：
`subject / slot / old / new / kind / seq / evidence / actor`（＋本探针扩展 `not_fact`）。
kind 五类严格照台账定义（`md_cg/state_events.py`）：`migration` / `retraction`（old 有值 new 空）/
`enablement`（old 空 new 有值）/ `acquisition` / `replacement`。

1. **切块**：`**我说：**`／`**DeepSeek说：**` 正则分块 → 1-based 轮段表（1,546 段）。
2. **发言者归属**：role 即归属；`actor` 取事件判定轮的发言者（`我说` / `鲸鱼小姐`）。
3. **引用块剥离**：剔除以 `>` 起始的**整行**（v3 复核 red 修口径，非只删 `>` 字符）。
4. **抽事件**：24 条词形/句式规则扫描剥离后正文，逐条注明命中口径（见 §二）；
   old/new 按上表五类定义取空操作数；迁移类槽位（住所/关系阶段）走**链式**口径
   （old=上一事件的 new）。
5. **消歧**三件套：
   (a) **用户侧声明优先**——同一槽位以「我说」的声明为真值来源；她的复述/记错不覆盖，
       且「记错」语境本身不产生事件（§五记错案 M1–M5）；
   (b) **非事实三类标记** `not_fact`（自动判定：按规则声明的**语境轮**查线索词）：
       `joke`（玩笑）/ `meta`（创造者-管理员/元层设定）/ `recollection`（对 DeepSeek 时期回忆）；
   (c) **时点/同指消歧**——住所搬迁时点取**内容实指**（首个含「海景别墅」的轮 = turns 1108），
       搬迁前的 home 词形归 tent（v3 口径 B）。
6. **落盘**：`state_events.jsonl`（一行一事件）＋ `rates.json`（哈希、计数、三率明细、
   v3 对齐、消歧与陷阱案判定表）；stdout 末行 `P1_RATES_JSON {...}` 摘要。
7. **对拍**：按（同槽位 + kind 一致 + **同向值比对**（旧值↔旧值、新值↔新值，禁交叉项：
   key 的旧值＝上一事件新值，交叉比对会把链式槽位的相邻事件误配）+ 锚句↔短证
   的字符 2-gram Jaccard）打分 → **一对一贪心分配**（一条 v4 事件至多认领一条 key 事件）
   → 漏 / 误 / 错三率。认领线 `T_HIT=0.12`、正确线 `T_OK=0.30`（依据见 §三）。

隐私与确定性（硬性）：脚本不内嵌任何本机/语料路径字面量（路径全走 CLI）；证据短证
硬上限 30 字且只取事实型；**同输入两次运行产物字节一致**（sha256 实测相同）；
不设/不读 `MDCG_*`、不碰任何在役库。

## 八、如实边界（规则式抽取的能力上限）

1. **高精度、低召回**：24 条规则（`len(RULES)=24`，含 5 个关系阶段闭包 finder）全部锚在语料**字面词形/句式**上——抽到即证据可查，
   但对**归纳型**槽位（关系阶段命名、住所「家与店」时段、形态/发色裁定）只能部分覆盖；
   key 的归纳性判定（如「固定日常」「笔误处理」「三层分叙」）不在规则能力内。
2. **对拍是机械匹配＋人工复核的合体**：分值来自 2-gram 相似度，阈值敏感点已单列
   （早安咬 0.1207）；`REVIEWED_CANDIDATES` 复核表与记错/陷阱判定表为**口径化人工常量**
   （逐条给理由），非全自动推导——"误率 0" 应读作「无经复核为假的抽出」，不是「零多余事件」。
3. **key 非穷举**：v4 抽出 25 条、其中 1 条（房贷@1163）key 未列（复核为真）；反向的
   key 归纳条目（§四）单列不计三率。
4. **样本量**：分母 25（单语料、单答案卷）；按粒度为「槽位事件」，不构成跨语料泛化证据。
