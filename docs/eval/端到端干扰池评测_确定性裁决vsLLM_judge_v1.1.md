# 端到端干扰池评测：确定性裁决层 vs LLM-as-judge v1.1

> **日期**：2026-09-23 · **基线**：`main@30afc94`（灵枢 v0.5.0）
> **评测问题**（外部建议口径）：此前全部实证是「零干扰池检索命中率上界」；本报告补上缺失的三面——
> **pinpoint**（干扰下 LLM 能否抽取正确事实）、**answerability**（该拒答时是否拒答）、
> **decision-making**（裁决层是否改变下游行为），并把「确定性裁决层」与「LLM-as-judge」正面对比。
> **一句话结论**：词法候选健康时（`MDCG_UNIFY_QUERY=0`）三臂检索持平（hit@1 94-96%）而
> **防火墙与 LLM 裁决对无标记干扰均无增益**（REJECT 恒 0 / LLM 误杀 gold ~14%）；
> 端到端 QA **43.3%（零干扰）→ 40.0%（全干扰）**，对抗题正确拒答仅 3/27——
> answerability 是最大短板；另附**统一归一层 A/B**（批次 15 边界反馈）：
> 归一开在 CCG 卡 + RRF 融合形态下 **−11.7pp**，根因是 query 拆原子与 doc 侧原子面缺位的形态不对称。
>
> v1.1 变更：用户质询「语义归一化做了么」触发归一层 A/B——v1.0 的「防火墙负增益 −2.5~−3.3pp」
> 判定为**归一层伪影**（详见 §4），主口径切换为归一关态，全部三臂 + QA 已双态复测。

## 1 · 设计

### 1.1 数据与写入面

- 语料/题面：公开集 [`locomo-zh-500`](../../data/benchmarks/locomo-zh-500/)（567 turn / 500 题）。
- **gold 与合成干扰走同一 CCG 六要素写入函数**（公平性原则）：生效条件由节点自身字段机械合成
  （`主体=…；时间窗口=…；主题=…`），不接触题面；不适用条件一律诚实写「无」——
  **合成干扰不携带任何方便防火墙剔除的标记**。
- 全部节点过 `ccg_completeness` 断言（6 行缺一不可，杜绝 BLINDSPOT 面混入）。

### 1.2 干扰家族（每题合成，500 题全部注入、池全局共享）

| 家族 | 构造 | 威胁面 |
|---|---|---|
| **D2 实体互换** | 摘要中双方名字互换 + 主体换人 | 「谁说的/谁做的」答案错，词面几乎同款 |
| **D3p/D3m 时间错位** | 同一事实 ±1 年 | 查询不含时间词时原则上不可区分（诚实边界） |
| **D4 否定澄清** | 「澄清：此前所说「…」并不属实」 | 否认该事实，词面高度重叠 |
| D1 同话题硬负例 | 不合成——其余 566 条天然 turn 即干扰池 | 全 level 在场 |

**浓度梯度**：level ∈ {0,1,2,4} = 每题注入前 level 条（池 567 / 1067 / 1567 / 2567 节点）。
id 前缀 `x_`（字典序排在 gold 之后——平局兜底**偏向 gold**，对我方保守）。

### 1.3 三臂（检索裁决面）与 QA 管线

- **arm_base**：裸五路融合（`search_rrf`，lexical/bucket/entity/graph/fuzzy · sum）top-10。
- **arm_firewall**：同候选面 + 确定性裁决（`judge=True, judge_ranking=True` 证据防火墙）。
- **arm_llm**：同候选面 + deepseek-chat 逐卡资格裁决（qualified 优先重排，与防火墙
  keep/降权同构），temperature=0，两轮独立调用测自一致性。
- **QA 管线**（120 题 × level {0,4} × 候选臂 {base,firewall}）：reader（deepseek-chat）
  只据 top-10 候选卡作答（不足答「无法确定」）→ judge 对 gold 语义判等
  （correct / incorrect / refused）。
- **gold 答案来源**：上游 LoCoMo 原始标注——`mteb/LoCoMo@02e2c3de` 1976 题英文题面与
  `snap-research/locomo` `locomo10.json` 逐题文本精确匹配（**1976/1976 全中、零跨 scene 错配**），
  本仓 500 题答案覆盖 **500/500**；113 题 adversarial 上游 gold 为空 = **正确行为是拒答**。
- 采样：seed=7 确定性采样 120 题（qtype 分布与全集同构）。
- **归一口径**：主表 `MDCG_UNIFY_QUERY=0`（理由见 §4——归一开在 CCG 形态是净负效应，
  属批次 15 边界缺陷而非评测对象属性）；§4 给双态对照。doc 侧摘要正文不做词典归一
  （与主链路一致——主链路的标准词加工就是五槽「词」槽本身，本评测卡片在「主题=」行
  原样携带同一批派生标准词）；同义扩展经 fuzzy 路在场。

## 2 · 结果一：检索裁决面（hit@1 / MRR，120 题，归一关）

| level(池) | base | firewall | llm(r1/r2) |
|---|---|---|---|
| 0 (567) | 95.0% / 0.972 | **95.8%** / 0.977 | 94.2% / 0.967（两轮同值） |
| 1 (1067) | 94.2% / 0.968 | **95.0%** / 0.971 | 93.3% / 0.960（r2 同） |
| 2 (1567) | 95.0% / 0.972 | **95.8%** / 0.975 | 92.5% / 0.953（r2 同） |
| 4 (2567) | **95.8%** / 0.976 | **95.8%** / 0.975 | 95.0% / 0.969（r2 94.2%） |

- **三臂持平在 94-96%**，hit@10 = 100% 全线：干扰不把 gold 挤出候选池，胜负全在排序与裁决，
  而两种裁决器都**不能把 95% 的词法排序再抬高**。
- **确定性防火墙**：+0.8pp×2 档、持平×2 档（±1 题，噪声量级）——「微正但无实质增益」。
  四态分布（top10）：ACCEPT 68-71%、DEFER 29-32%、**REJECT/BLINDSPOT 恒 0**。
  诚实写入面下无负条件可命中，REJECT 路结构性缺席——`test_sem_noise` 的正增益依赖
  「否定节点声明负条件」这一前提，**词面条件裁决对无标记对抗干扰无免疫力**（可证伪结论）。
- **LLM 裁决器**：无增益（−0.8~−2.5pp vs base）——它会把 gold 判不合格（gold 获
  qualified 仅 82.5-85.8%）、全弃权 10.8-13.3%，误杀盖过其剔噪收益。自一致性
  （两轮独立）：**top1 一致 98.3-100%**、qualified 集一致 84-92%——排序面高度可复现。
- 合成干扰对 top1 的直接置换仅 **1-2/120**（D2，L1 起出现、不随浓度增长）；且均为
  **交叉冒充**——`scene_0_q_66` 被 `x_d2_scene_0_q_198`（另一题的干扰）压过、
  `scene_7_q_91` 被 `x_d2_scene_0_q_184` 压过。全局共享池下「别题干扰冒充本题」是真实威胁面。

## 3 · 结果二：QA 端到端（pinpoint / answerability / decision-making，归一关）

| 组 | QA准确率 | 常规题准确率 | 常规题拒答 | 对抗题正确拒答 | 对抗题被骗 |
|---|---|---|---|---|---|
| L0 · base 候选 | **43.3%** | 52.7% | 26/93 (28%) | 3/27 (11%) | 6/27 (22%) |
| L0 · firewall 候选 | 44.2% | 53.8% | 26/93 | 3/27 | 6/27 |
| L4 · base 候选 | 40.0% | 46.2% | 40/93 (43%) | 5/27 | 11/27 (41%) |
| L4 · firewall 候选 | 39.2% | 45.2% | 42/93 | 5/27 | 10/27 |

（归一开态对照：L0 base 40.8% / L4 base 39.2%——归一关略优 +2.5pp，格局不变。）

- **pinpoint**：全家族干扰下 QA 总准确率 −3.3pp（43.3→40.0），常规题 −6.5pp
  （52.7→46.2）且拒答 +14 题——reader 在干扰下**更保守但不更准**，退化以
  「该答不敢答」而非「答错」的形态出现。
- **answerability（最大短板）**：对抗题（gold=拒答）正确拒答仅 3/27（L0）→ 5/27（L4），
  被骗编造答案 6→11。被骗样例（L4·base）：`连帽衫`/`乌龟`/`Finding Home`——检索命中的
  相似记忆诱导 reader 拼出自信答案。《Why Johnny Can't Persist》指出的记忆系统通病
  （检索命中 → 编答案而非拒答）在本系统**端到端实证成立**。
- **decision-making**：firewall 候选与 base 候选的 QA 成绩无差异（44.2 vs 43.3；39.2 vs 40.0）
  ——**确定性裁决层不改变下游行为**。
- 常规题拒答样例（L0）：gold=`2022`/`Sunsets`/`Roast marshmallows`——多为时间推理与细节题：
  hit@10 虽 100%，**摘要卡信息密度不足以还原原始对话细节**，reader 宁拒答不猜。

## 4 · 结果三：统一归一层 A/B（批次 15 边界反馈 · 双态对照）

> 触发：用户质询「中文摘要按现有流程做语义归一化了么」。查证：`search_rrf` 入口
> `q = unify_query(q)`（`mdcos.py:1210`）默认开——**v1.0 全部数字即生产同口径（归一开）**。
> A/B 后判定 v1.0「防火墙 −2.5~−3.3pp 负增益」为归一层伪影，主口径切归一关。

### 4.1 三组对照（L0，120 题）

| 形态 | 归一开（默认） | 归一关 | 差 |
|---|---|---|---|
| **CCG 卡 + `search_rrf` 五路**（本评测）base hit@1 | 83.3% | **95.0%** | **−11.7pp** |
| 同上 · firewall hit@1 | 80.0% | **95.8%** | −15.8pp |
| **五槽裸串 + `cg.search` 阶梯路**（生产主形态，第三方 A_zh5 同款）hit@1 | 95.8% | 95.8% | **0（持平）** |

归一实际作用面：120 题中 39 题含拉丁字母（纯中文 query 按设计零变更），全部 39 题被改写。

### 4.2 根因（改写样例实证）

1. **形态不对称（主因）**：含拉丁字母的 query 被拆成单字标准原子
  （`绘画 作品`→`绘 画 作 品`）——`unify.py` 注释明示该形态与「doc 侧 `fm.semantic`
   原子面同构」；CCG 卡与五槽裸串均无该面 → RRF 词法路的加权覆盖被拆散形态破坏。
2. **撞词错译**：`Matt`→`哑 光`（CEDICT matt=哑光，人名撞词）、`hikes`→`健 行`
   ——README ④ 臂记录过的机械直译病在批次 15 重演。
3. **数字丢失**：`Gina 2023 时尚实习`→ 归一后 `2023` 消失——时间词丢失对 temporal 题致命。

阶梯路持平的解释：char-bigram 对「拆单字加空格」几乎无损（bigram 集合不变），
故生产主形态未现回归；RRF 词法路的**词级加权覆盖**对拆散形态敏感，故 CCG 形态崩。

### 4.3 建议（供批次 15 口径拍板人）

- 归一层加边界闸：**库内无 `fm.semantic` 原子面时跳过拆原子**（原样传 query），
  仅在 doc 侧原子面在场时启用形态归一；
- 英文普通词作用于中文题面时保持 unknown_keep（人名/普通词撞词错译 `Matt→哑光` 应拒译）；
- 数字 token（年份）不应被归一层丢弃；
- 回归口径补「CCG 卡 + RRF 融合路 × 中文题面含拉丁字母」形态（本 A/B 脚本可直接复用）。

## 5 · 归因链（三层证据合读）

1. **检索面（hit@10 100%）→ QA 面（43.3%）的 57pp 落差**：瓶颈不在检索在读写两侧——
   写入面（摘要卡压缩掉细节）与读出面（reader 无「证据不充分检测」）。
2. **两种裁决器都救不了检索面，也都不改变 QA 面**：词面条件（REJECT 恒 0）与语义阅读
   （误杀 gold ~14%）在「干扰与 gold 同款条件、同款词面」的对抗设定下均无增益——
   **裁决层的增益边界=干扰与 gold 之间是否存在可机读的差异面**（负条件标记 / 证据基底 /
   时间线冲突），这正是 bench_progressive 预告的「另案」方向。
3. **LLM 裁决器的价值是条件性的**：候选质量被归一层打崩时（v1.0 归一开态）它能捞回
   +5pp（88.3 vs 83.3）；候选健康时（归一关）无增益。**「LLM-as-judge 优于确定性裁决」
   不成立为一般结论，仅在低质量候选面上成立**。

## 6 · 诚实边界

- 本评测为 **CCG 化写入口径**（摘要卡 + 机械条件面）；生产主形态（五槽裸串+阶梯路）
  归一开/关已单独对测（§4.1），但三臂主表仅在 CCG 形态上运行。
- L0 base 95.0%（归一关）与主链路 94.6%（五槽口径）同量级——**量级对照，非逐位复现**
  （写入面与检索路均不同）。
- reader 同时拿中文关键词串与上游英文原题（真实用户问题面），记忆卡为中文，judge 对
  英文 gold 跨语语义判等——双语口径；judge 亦为 LLM（LLM-as-a-judge），边界例按 judge
  裁决计入、未人工复核。
- QA 43.3% 不能直接对标 Mem0/Letta 论文的 LoCoMo QA 数字（他们用完整对话原文做记忆、
  自然问句做查询）；本口径是「摘要卡 + 关键词面」的保守下界。对标前须换装完整对话记忆面重跑。
- 合成干扰为机械构造（名字互换/年份平移/否认包裹）；D3 在查询无时间词时原则上不可区分
  （两臂均无法免疫），如实计入。
- 120 题采样（seed=7）下 1pp ≈ 1.2 题；±3pp 内差异不构成结论。

## 7 · 复现

```bash
# 前置：DEEPSEEK_API_KEY；数据根默认 D:\program\test\e2e_judge（--data-root 可改）
# 主口径（MDCG_UNIFY_QUERY=0；归一开对照去掉该前缀即可）
MDCG_UNIFY_QUERY=0 python -X utf8 -m md_cg.bench_e2e_judge --quick      # 冒烟（确定性两臂）
MDCG_UNIFY_QUERY=0 python -X utf8 -m md_cg.bench_e2e_judge --skip-llm   # 全量确定性矩阵
MDCG_UNIFY_QUERY=0 python -X utf8 -m md_cg.bench_e2e_judge --arms llm   # LLM 裁决臂 ×2 轮
MDCG_UNIFY_QUERY=0 python -X utf8 -m md_cg.bench_e2e_qa                 # QA 端到端
# gold 答案映射（上游对齐，500/500）：D:\program\test\e2e_judge\upstream\answers_map.json
```

产物：`results/summary_*.json`（三臂指标+LLM 逐题）、`results/qa_*.json`（QA 逐题）、
`results/detail_L{lv}_n120_s7.json`（行级明细）。LLM 调用带缓存（`llm_cache/`、`qa_cache/`），
键含轮次与完整 prompt——双态复跑自然分键，两轮自一致性仍是真实独立调用。

## 8 · 结论与下一步（早暴露早修）

| 发现 | 状态 | 行动项 |
|---|---|---|
| 端到端 QA 43.3%（L0）→ 40.0%（L4），检索→QA 落差 57pp | **新基线数字** | 写入面细节槽（时间/实体保真），读写两侧补 |
| 对抗题正确拒答 3/27、被骗 6→11 | **最大短板** | reader 侧证据不充分检测 / 裁决器 BLINDSPOT 面扩展 |
| 防火墙与 LLM 裁决对无标记干扰均无增益（±1 题；REJECT 恒 0） | **可证伪双负结果** | 裁决差异面升级：证据基底 / 时间线冲突（bench_progressive「另案」落地依据） |
| **统一归一层在 CCG+RRF 形态 −11.7pp**（拆原子×doc 侧原子面缺位；撞词错译；数字丢失） | **批次 15 边界反馈** | §4.3 三条修复建议；回归口径补 CCG 形态 |
| LLM 裁决器增益是条件性的（低质候选 +5pp / 健康候选 −1~−3pp） | 一般结论证伪 | 混合架构仅按候选质量自适应启用 LLM 裁决 |
| D2 交叉冒充（别题干扰压过本题 gold） | 新威胁面 | 干扰敏感性：按题隔离池 vs 全局池对照（后续实验） |
