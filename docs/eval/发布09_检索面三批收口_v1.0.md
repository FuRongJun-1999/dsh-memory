## 三、必须连着读的披露

1. **双 flag 默认关**：`MDCG_STG_INDEX`/`MDCG_STG_QUALIFY` 缺省关闭——第 3 层索引的路径等价已机械验证（两臂逐位一致），但默认开关待单独讨论（先 flag 化、逐项验证、再讨论默认开启——检索契约 §7 口径）。
2. **面外残余（cons200 诚实边界）**：非同源形态（非合作写者直改 `.md` 不重建索引）下、落修前扫描面**之外**的纪律节点可能不被相关面捡到——修前亦检不出，不构成回归；已由 `truncated` 可观测＋docstring 边界声明覆盖。
3. **升级须重启的长驻进程**：在役 MCP 进程仍持旧字节码——cons200 的写链检测面与 stg 层改动须重启 MCP 后生效（既有运维前提，发布 08 已登记）。
4. **选面只影响超限分支**：cons200 的相关性排序只决定「候选超限时谁进精比面」；正常库（候选 ≤ limit）行为逐位不变（对拍含递归/exclude/哨兵等 11 个场景逐位一致）。
