# BM25 检索与 BEIR 本地实测（2026-10-10）

新增可选的生产 BM25 召回路，使用词频倒排、正 IDF、长度归一化和有界堆，替换逐文档的词法与模糊评分。默认检索配置保持原样。Python 的 `paths=("bm25",)`、默认 MCP 的 `cg(op=read,bm25=true)`，以及完整工具面的 `mdcg_recall(bm25=true)` 都可启用。使用边界见 [BM25 检索说明](../mdcg/bm25_retrieval.md)。

参数固定为 `k1=1.2, b=0.75`，采用常规默认值，无参数搜索。先运行 NFCorpus dev 的 324 条查询，再冻结源码和参数，运行完整 test。未引入模型推理或生产第三方依赖。

## 官方任务质量

两项任务都使用 BEIR 原始完整 corpus、原始英文查询与官方 qrels，文档为 title+abstract。只用 corpus 构建 Markdown，所有元数据统一，不按答案裁剪文档或写入查询词。由官方 BEIR evaluator / pytrec-eval-terrier 计分。

| 数据集 | 文档 / test 查询 | 原词法+模糊 nDCG@10 | BM25 nDCG@10 | 原 Recall@100 | BM25 Recall@100 |
|---|---:|---:|---:|---:|---:|
| NFCorpus | 3633 / 323 | 0.18832 | **0.30694** | 0.19981 | **0.21171** |
| SciFact | 5183 / 300 | 0.39363（上一轮） | **0.66168** | 0.75444（上一轮） | **0.87039** |

NFCorpus 的两条路径本轮完整重跑，共 646 次查询；SciFact 本轮 BM25 完整跑 300 次，旧路径质量引用上一轮已保存的完整 300 条结果，不能当作本轮重跑。原路径为 `lexical+fuzzy` 且字符候选索引关闭，新路径为 `bm25` 单路；因此这是检索配置的质量与速度对比，排序允许改变。

BM25 保留原 RRF 每路前 50 的限制，即使 `k=100` 也只输出最多 50 个节点；其 Recall@100 等于 Recall@50。旧两路融合最多能给出 100 个候选。这里没有修改 cap 使新路径获得额外优势。

完成默认 MCP 接线后，使用最终源码再次跑全量 BM25：NFCorpus 323 条与 SciFact 300 条，共 623 次，**0 运行错误、0 回退、0 不可用文档、0 排名差异**，质量指标完全一致。这是重复验证，不是新增 623 条独立测试样本。

## 实际延迟

规模测试使用实际 Markdown 文件，3 轮交替运行两条路径，共 84 次热查询，0 运行错误。BM25 的常见词、稀有主题和无匹配查询均通过独立的生成规则检查；不要求其排序与旧算法相同。池中上一阶段留下的写入探针使实际节点数比名义规模多 1。

NFCorpus 首查：旧路径 3.32 s，BM25 2.45 s。规模池 BM25 首查：10001 节点 4.85 s、100001 节点 **49.67 s**。最终全量重跑的 BM25 平均耗时为 NFCorpus 4.42 ms、SciFact 11.04 ms；这组重复计时不替换上表的同轮对照。

这里是官方任务的本地测评，**未向排行榜提交，没有官方名次**。参数与 IDF 参考 [Lucene BM25Similarity](https://lucene.apache.org/core/9_9_1/core/org/apache/lucene/search/similarities/BM25Similarity.html)，分词、索引格式和归一化实现不同，未复现 Anserini 的官方 BM25 行。英文文献检索不能替代中文长对话、多跳记忆问答或真实记忆分布；百万节点、并发、p99 服务 SLA 均未验证。元数据枚举/同步仍为 O(N)，高频词仍遍历大量倒排项，启动成本也仍需要继续优化。
