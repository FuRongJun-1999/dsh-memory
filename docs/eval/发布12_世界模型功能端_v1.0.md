## 二、世界模型功能端：事件是源、槽位是投影

### P1 · 状态事件抽取器 v4（真实语料跑道）

- 纯标准库、确定性（同输入跨目录逐字节一致）、零记忆库写入；`--out` 强制仓外 fail-closed。
- 24 条字面锚规则覆盖 11 槽位；三层消歧：**用户侧声明优先**（真源）、非事实三类标记（玩笑/元层/回忆转述）、内容实指时点（搬迁锚定首现轮而非词形首现）。
- 对拍答案卷三率：**漏 1 / 误 0 / 错 1（分母 25）**；与 v3 基线五项读数逐位对齐。
- 未覆盖清单如实单列（形态 / 发色与瞳色 / 米饭——裁定句在语料外或属元层撤回），不计入三率。

### P2 · 槽位寄存器投影 + stg 第五 op

- `md_cg/state_slots.py`：投影＝**查询时从 append-only 台账现算**（零落盘零缓存、不建第二真源）；字段表＝设计稿 §3 逐字（现值/退役/区间/变迁史/档位/备择/盲区）；撤回判据取 payload 不取 kind 标签；孤立撤回不编造起端。
- `stg(op=state_chain)`：第五 op，flag `MDCG_STG_STATE` **默认关**（与 INDEX/QUALIFY 同纪律）；关臂返回 disabled 体（不抛、不静默）；返回体沿 issue #52 截断可观测口径。
- 守卫 71 断言（A–J 含 MCP 接线面）＋定点变异；**四 op 语义零改动**（AST 级核验）。
- 真实语料读数：25 事件 → **11 槽位**（9 active + 2 退役：名字=孤立撤回、房贷=3 条变迁史 1123→1477）；撤回后复活（记忆特性 613→1475）正确；追加即变（无缓存）。

### P3 · 写侧记账口 +《秤》5.1 账本探针

- `cg(op=state_event)`：五元事件 append——权限**双闸**（映射既有 `write` 词，不给令牌面引入新 op 词）＋显式 `require_write`（台账直写盘面绕过库层写闸的缺口补齐）；`actor` 恒取令牌（防伪造）；kind 空串归 None；fail-closed 抛错原样上抛。
- `scripts/probe_c_ledger_integrity.py`（《秤》v2.1 §5.1 口径）：三读数——**事件覆盖缺口率 / 无账可辨率（不编造不反推）/ 变迁史可查率**；隔离 root、确定性、`--out` 仓外 fail-closed。
- 真实语料读数（鲸娘 25 事件 × 14 槽位清单）：**缺口 3/14**（形态/发色瞳色/米饭＝P1 已知边界）、**无账可辨 5/5**、**变迁史可查 11/11**。
- 文档：`docs/mdcg/世界模型功能端_使用与运维_v1.0.md`（全链/开关/授权/边界/复跑命令）。

## 三、DSH 会话归因治本（B）

- **双链根因**：启动脚本按目录 mtime 猜会话（DSH 只更新文件 mtime ⇒ 永久选旧会话）＋ md_cg `_declared_session` 环境权威否决请求级声明（env > 声明 > 进程身份）。
- **治本**：启动脚本去掉猜测（保留清空与校验根）；插件把**运行期会话注入写归因调用**——只注入写归因面（`mdcg_remember` + `cg(op=write)`），读面视图过滤/op 特化语义一律不动；未观测落 `unassigned` 显式占位。
- **真机端到端验收**：重启后经浏览器让 agent 直调记忆写入，读回 `session` = **当前会话真实 id**（非旧猜测桶、非随机值）。
- 冻结守卫逐字未动；一处实现偏离经 owner 裁定（实例级观测门，真机单实例与字面逐位等价）。
