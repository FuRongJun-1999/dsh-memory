## 二、先认一个事实：静态面当时是**全绿**的

修前的真缺陷形态：

```
抽取器本体在 scripts/state_extract.py
package.json 的 files 白名单只发 scripts/workspace_index.py
⇒ 装机侧根本没有抽取器

```

因此「发布闸全绿」与「L2 台账在生产环境里是断的」**可以同时成立**。这不是判据写错，
而是**判据落点选错**：静态面测的是「物件」，缺陷在「链路」。

## 三、S8/S9 怎么判

### S8（写侧，行为）

```
tokens issue --role recorder --ops-allow recent,write
  ↓ 拿到 token（注意：输出是缩进多行 JSON，不是单行——本轮踩过，见 §五）
真起 MCP：initialize → notifications/initialized
  → cg(op=recent, action=add, role=user, meta={session, turn})
  ↓
读 <MDCG_ROOT>/_state_events.jsonl
```

判据三条**同时**成立：文件存在、行数 ≥ 1、`actors` 里含 `state_extract`。

**刻意不钉**槽位名与值——把发布闸耦合到抽取规则表，会让「提高抽取精度」这类正常演进
误判发版。抽不到的回归由 `md_cg` 层守卫管（`test_state_extract` / `test_state_ledger_*`），
各管一层，不重叠。

### S9（读侧，与台账账实一致）

```
python -m md_cg.state_slots --status        → {"events": 2, ...}
stg(op=state_chain, subject, slot, history=True)  → count=1, history 有 old→new
```

判据两条同时成立：`slots.events == 台账行数`、`chain.count ≥ 1`。

**为什么要读侧单独一条**：只验写侧会漏「写进去了但读不回来」这一族（投影判据单点漂移、
查询面开关被关、history 被 limit 截断）。读侧这条把「账实一致」钉成可机读。

## 五、我在这一轮里自己错了三次（必须记）

### ① `tokens issue` 的输出是缩进多行 JSON，我按单行解析

第一版逐行 `startswith("{")` 再 `json.loads`——多行 JSON 每行都不是完整对象，
于是永远取不到 token。S8 报「tokens issue 返回 0 但取不到 token 字段」，
看起来像「签发面坏了」，实则是我的**解析器写窄了**。
修法：先整体 `json.loads(raw)`，失败再逐行兜底。

### ② 变异写成 `RULES = [] or [`——变异等于空转（假绿）

`[] or [A, B]` 的求值结果是 `[A, B]`，原列表照旧生效。当时三条 B2 红侧3 断言
**全绿**，我差点当成「守卫很强」——实际是**变异没生效**。
修法：改成 `RULES = []` + 另一个名字承接原表；并加「替换后文本必须变」的前置断言。

### ③ 修完之后又写成列表字面量里塞赋值语句 ⇒ 语法错

`MUT_OLD_RULES = [` 后面紧跟 `RULES = []` —— 这是语法错 ⇒ 进程起不来 ⇒
红项变成 S4/S5 **也红**。看起来像「守卫更强了」，实则是**我把包改坏了**。
修法：给变异加 `compile(se_new, se, "exec")` 前置校验，语法不过即报 ANCHOR-MISS。

**这三条是同一族**：**变异/探针本身失效时，会伪装成「守卫有效」**。
故本轮的收口原则是——**变异必须自证「它真的改变了被测对象」**：
文本确实变了 + 结果确实合法 + 红项恰好落在预期集合（集合相等，不是「包含」）。

### 附带发现：`_materialize_repo` 依赖 `git ls-files`，而本仓不是 git 仓库

`git rev-parse` rc=128（无 `.git`）⇒ B2 整组 ANCHOR-MISS。这本身是**正确**的 fail-closed，
但让行为面自证在本机永远跑不起来。修法：加回落路径——无 git 时改按 `package.json` 的
`files` 白名单材料化副本（**出货面本就由 files 决定，按它材料化反而更准**），
并补拷 `scripts/`（`prepare` 钩子要跑 `scripts/build_ui.py`，它不在白名单里，
缺它 `npm pack` 直接 rc=2）。
