### 1.4 连带缺陷：翻缺省才暴露的静默失效（同一根因的第二处）

### 1.5 修前两侧对「非 `"0"/"1"` 取值」并不同判（本报告实测，见 §四.13）

修前两侧对**第三个取值**（如 `"TRUE"`）判定相反：Rust `v == "0"` ⇒ 非 `"0"` 即**开**；Python `== "1"` ⇒ 非 `"1"` 即**关**。⇒ 契约「两侧三态判定必须一致」在修前对**三态之外**的取值不成立；修后两侧统一到「唯一开态 = `"1"`」（同为关）。新守卫只钉「未设 / `"0"` / `"1"`」三态，**未把该取值写成断言**（§六.E）。
