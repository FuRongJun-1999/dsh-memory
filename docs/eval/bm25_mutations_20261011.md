# BM25 定点变异自证

运行入口（仓库根，Python 3.12）：

```sh
python -X utf8 -m md_cg.test_bm25_mutations --output mutation-report.json
```

使用现有 `md_cg/test_bm25.py` 的 10 项运行守卫。每轮都在独立合成 Markdown
库上经过生产 BM25 / search_rrf 入口；不使用真实记忆库。源码锚点必须唯一，
否则退出 2。变异只执行内存中的源码副本，不改写生产文件。每项预先声明
失败测试名和失败断言原文，两者必须完全一致；异常、跳过、额外红项或存活均失败。
未变异基线和全部变异后的恢复轮也必须全绿。本模块由 `scripts/run_tests.py`
自动发现，默认运行完整变异流程。

| 变异 | 注入的缺陷 | 应点名报红的守卫 |
|---|---|---|
| M0 | TF 强制为 1 | 手算 BM25 分数；共享词项保留真实 TF |
| M1 | 块上界的最大值改为最小值 | 混合 TF/长度、末尾极值、编辑删除与穷举评分对拍 |
| M2 | 关闭块跳过 | 同分 top50 保持一致且确实减少评分访问 |
| M3 | 关闭复杂分布成本保护 | 不为复杂分布构建块表、选择穷举路径 |
| M4 | 候选资格缓存键省略身份 | 变更会话、权限后候选池先排除私有记忆，再进行评分 |
| M5 | 候选资格缓存键省略写代际 | 新写入记忆必须及时可检索 |
| M6 | 缓存依赖当前时钟的有效期候选池 | 有效期过滤每次重新计算候选 |
| M7 | 首建错误清除已有读缓存 | 已有缓存对象保留、失败读取可重试 |
| M8 | 每文档重新保留重复 TF Counter | 共享词项使用 tuple，真实 TF 仅在倒排中保存 |

完整断言及预期集合在 `md_cg/test_bm25_mutations.py` 固定声明，JSON 保存每轮
全部测试日志、失败断言、异常与跳过集合，以及当前 BM25 源码的 LF 归一 SHA256。
M2/M3 验证实际执行路径和工作量，M8 验证运行中的存储结构；不把这些守卫解释
为新增延迟或 RSS 测量。此处共 9 个定点缺陷，不能宣称全项目变异覆盖率 100%。

初轮 M4 曾存活：原测试只检查最终私有召回为空，后续读取隔离仍可挡住内容，
掩盖了候选池失效判据的缺失。现补充候选池在评分前必须随身份收窄的断言；
没有通过放宽预期红项来消除存活变异。该发现是守卫覆盖缺口，不是正常实现中
已经确认的内容泄漏。

本次补件只增加测试和说明。此前十万配对、百万规模与 BEIR 成绩仍按原测量提交
和原始日志引用，不因补件重新标为新一轮性能实测。维护者人审、跨仓登记和最终
难度认定由维护者完成。
