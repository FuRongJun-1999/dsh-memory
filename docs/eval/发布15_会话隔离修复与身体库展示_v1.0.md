## 二、issue #65 修复（本版核心）

外部报告（ducc239，对 v0.7.5 实测）——`session_recall` 的「③ 近期事件」段未按会话隔离：
③ 段调 `recent_events` 不传会话（`recent_events` 无 session 形参、仅 private/secret 档做
会话归属判断），recent 段恒为**全进程窗口**——多窗口并发时 A 窗口的注入包混入 B 窗口报文
（被模型当用户输入处理、可被压缩检查点记入，**静默污染**）。

**修前复现**（隔离库，MCP 真实入口与直调两路径读数一致）：假会话 id → 返回 3 条全库事件；
会话 A → 混入「会话B的第一句话」；缺 `meta.session` 的无归属事件在两会话下均漏入。

**修复**（`mdcos.py` ③ 段）：取 `evs` 后按会话过滤——真实会话 id → `meta.session` 严格相等
（缺 `meta.session` 者丢弃：最坏空窗口，杜绝错块）；显式 `session="*"` → 不过滤（跨会话汇总，
与 `stg` 的 `"*"` 同款语义）；falsy（None/""）→ 退回旧行为（全局窗口）；`strip` 防空白包裹
的星号。docstring 同步口径段（recent 跟会话走；notes 已跟；tasks/goals 有意跨会话）。

**验证**：守卫扩 `test_p45_session_identity.py` **R65 组 12 断言（42/42）**——含 MCP
`_session_call` 端到端、缺 meta 两态、`"*"`/`" "`/None/""、compact 回归、文档口径在位；
**定点变异自证六腿**（删过滤/删星号例外/去 strip/放行缺 meta/去 falsy 守卫/文档反转，
红项数 5/2/1/4/2/1 各恰等于登记值、每腿红集为唯一指纹）＋ ANCHOR-MISS 漂移探针 fail-closed；
**独立复核 ACCEPT**（双树对照、oracle 直读 `_recent.jsonl` 对拍、退化探针非空池防空转、
old/new 逐位、多实例形态）。报告见 `docs/eval/issue65_session_recall_会话隔离_核验与修复_v1.0.md`。
