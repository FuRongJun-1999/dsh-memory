# Memory-RSI：阶段性实验与探索（第五轮进行中）

**交付性质：阶段性的实验和探索，不是已验证成熟的 Memory-RSI 算法、最终研究结论或生产上线申请。** 局部正确性修复有隔离证据；经验巩固、反思和持续学习的净收益尚未被证明。第五轮验证与最终留出未完成。

本提交整理 CSRE 正确性修复、可关闭的离线研究原型、第一至第四轮实验，以及第五轮目前的审计和诊断。没有安装或更新生产 DSH 插件，没有操作正式记忆库，没有启用反思为默认，没有自动批准上线。实验性接口只在显式创建的研究 sandbox 使用。

## 做了什么

1. **CSRE 底层正确性**：负条件在 Top-K 前过滤并补位；空值/重复/标识符边界与局部否定有回归；索引绑定来源路径、schema、完整知识卡行和负条件；拒绝陈旧、跨库、损坏和旧格式索引；只读打开缺失数据库；显式构建/保存，原子替换且不用 pickle；导航缓存使用前重新检查。原隔离负条件违规 9/20→0/20，不宣称默认 RRF 提速。严格完整校验为 O(N)，成本增加。
2. **可选 CSRE 会话**：复用 SQLite data_version 观察和来源快照；验证恢复 mtime、WAL、跨库和有界重试。仅显式会话入口，保留完整检查与回退，不新增权威记忆库。
3. **离线经验研究原型**：沿用同一图、inbox 和审核权限；完整绑定 error/action/check、多个检查必须全部成功、条件归一、冲突暂缓、原始轨迹哈希与版本身份；不把模型笔记自动升级为验证知识。增加对抗性回归、真实工具轨迹和回滚验证。
4. **证据交付消融**：前缀、查询窗口、来源/时间/条件元数据、紧凑元数据；保存原始字符偏移、来源 hash 和估算预算。紧凑元数据没有证明净收益，未改默认交付。
5. **第一轮及早期迭代**：修复负条件与索引正确性，完成合成/公开检索诊断、延迟、真实工具与 stdio MCP 验证。原三组 20/20 只能说明天花板，不能据此证明反思有效或无效。
6. **第二轮**：6 个真实仓库缺陷×3 重复×4 组=72 次 DeepSeek Harness。A 原始7/18、B 底层修复10/18、C 始终反思10/18、D 条件反思11/18。D 总 Token 相对 C 约少6.65%，未缓存输入+输出仅少约0.75%；缓存收益不计为算法计算收益。
7. **第三轮身份与策略**：审计第二轮逐案例和61次反思事件；复现生成候选把撤销布尔缓存混给不同 token 的错误。逐 token 查表最小修复使误拒1/10、非法放行2/17→均0；主线原本已有正确机制，未重复声称产品身份缺陷。59个可导入候选的扩验为0/590合法误拒、0/1003非法放行，另1个SyntaxError单列。完成原生DSH→stdio MCP路径、8个新仓库缺陷×5组×3次=120有效试验（另2次余额中断保留）；A7/24、B9/24、C10/24、D/E11/24，未证明稳定净收益。
8. **第四轮经验巩固**：记录20个真实 A 会话，19个最终协议合格但20个行为检查通过；9个同源经验 capsule，缺合格来源的家族不伪造资格。receipt绑定、typed条件、不可变版本、冲突/过期暂缓、失败关联与追加式回滚，默认关闭。160次主对照：A无记忆30/40、B原始经验27/40、C巩固27/40、D条件反思27/40；C/B两胜两负、D/C三胜三负。D40/40触发，未缓存输入+输出比C多2.66%。另保留验证、规格补充与全部失败；三道规格不足题单独标记，原主分数不改。
9. **第五轮 P0/P1 已完成**：审计第四轮全部160次；逐项追踪11次“A成功、有记忆失败”（8个任务-重复配对），含写入、lexical单路RRF名次、条件、交付、声明、编辑、最终代码；40次B均有外层JSON截断。不能把正确拒绝、返回类型错误、缺失导入、容器别名都称为错误记忆迁移。D全触发来自“任一候选被拒或不足”的宽条件；17次仍有正文。
10. **第五轮评测质量修复和新集**：合成canary证实旧同进程评分器可暴露已编译隐藏常量；历史未发现利用证据，历史成绩保留。新父进程持真值、候选worker只见函数输入。10项边界反证通过。24个新A→B实例、6家族，分记忆必需/迁移/负迁移及开发/验证/留出；48个参考阶段通过、48个初始缺陷阶段失败，24项独立合同核验。24次DSH A会话全部通过。
11. **第五轮 A–F 诊断进行中**：A无记忆、B原始、C仅严格过滤、D仅交付A文档及完整来源/时间/条件、E仅A阶段Oracle、F等Token中性上下文。首开发36次：A4/6、B4/6、C3/6、D5/6、E5/6、F4/6。验证旧版本完成13次后发现工具schema没有声明decision枚举，保留并中止，另1次在途原件保留。新v1.2统一明确use/reject/defer，原truth不改；来源区分A会话事实与公共API参考。120项桥接预检通过、24项F响应Token精确配平、16项适用Oracle文档完整。**新验证与最终留出尚未运行，不能据开发成绩选算法或宣称第五轮完成。**
12. **研究参考**：核对ACE、Group-Evolving Agents、Mind the Gap、AIDE²、Hyperagents、RSI-Anything；只保留候选比较、外部反馈、独立验收、保留/回滚的可验证机制。未训练JEPA、未引入大型世界模型、未实现自动算法演化或无限自修改。
