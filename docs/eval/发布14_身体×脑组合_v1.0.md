## 二、身体×脑组合（本版主线）

**组合对象**：对外完整身体库 `FuRongJun-1999/lingshu`（灵×脑×身聚合仓，v0.0.1 骨架已入仓）。
身侧适配器 `lingshu/world/brain_store.py` 以 **MCP stdio 真进程**连本仓 `md_cg.mcp_server`，
**零改动对接** `scene_model` 既有两函数：

- **M1 读向（身体重建世界）**：`BrainStore.get_nodes_by_tag` → `cg(op=read)` 取候选
  ＋适配器侧 tag 过滤（裁定三：零脑改）→ `frontmatter.spatial.coords3d` 直存取坐标（裁定二）
  → 槽位投影（`stg(op=state_chain)`，slot=「状态」）取状态 → `load_world_from_memory(store)` 直接可用；
- **M2 写向（身体观测入脑）**：`BrainEngine.add_perception` → `mdcg_remember`
  （tags＋坐标直存）；状态写入经 `store.conn` 垫片翻译为 `cg(op=state_event)` **记账**
  （事件是源、槽位是投影）→ `ingest_scene(agent, desc)` 直接可用（含状态）。

**端到端读数（本版发布时点实测）**：

- 身侧件 `tests/test_brain_store.py`（隔离库）：**10/10 通过**——握手／写入 3 实体／
  世界重建实体集合／类别（`cat:` 标签）／坐标（coords3d 直存）／状态（槽位投影）／
  状态更新重载／tag 过滤在适配器侧（无 `spatial` 标签者不进世界）；
- 活体演示（隔离库，两幕＋断线重连）：身体感知写入 → 脑侧台账（3 槽位 active）→
  状态迁移（happy→excited，事件数 2）→ 世界重建（实体/类别/坐标/状态全对）→
  脑侧原始节点回读（tags 与 `spatial.coords3d` 直存形态）→ **重连续存**（世界仍在、状态取新值）；
- 组合冒烟 `scripts/body_e2e_smoke.py` 为发布门禁**第 12 腿**（本仓侧、身体侧视角
  MCP 全链：写口 3/3 入账 → 投影 2 槽位 → `stg(op=state_chain)` 查询）。

**安全与纪律**：连接缺省 fail-closed——子进程 env 剔除继承的全部 `MDCG_*`、`pythonpath`

## 三、状态追踪链（语义时空图核心能力成型）

## 五、issue #64 修复（外部报告）

外部报告（angel12538，对 v0.7.5 实测）两类指控 + 参数问题，逐条核验（对 HEAD 源码
与隔离库独立复现）后三类均成立并修复（`e5723d35`）：

- **B 类「空集当通行」**（主修）：`consolidate()` 主流程把 grounding 删光后的空 neg 传
  `replay_check`，命中其 `else: neg_separated = True` 短路——「负条件被删光/未产出」被
  错当「通过」，缺「不适用条件」要素的节点仍落盘并携带验证声明。修复＝**负条件两态拦截**
  （`neg_absent`＝候选未产出／`neg_dropped_all`＝写了被 grounding 删光；两态 REJECT，
  不进 verify、不落盘，reasons 分开记账）。
- **A 类①**（过严误杀）：`pos_recall` 的 `_neg_hit` 一票否决把「与生效条件共享领域主题词」
  的合格邻近情境负条件误杀（实测①为唯一杀手）；撤销该因子，自否定由 `no_conflict`
  覆盖率口径承担（复制品仍被拦，守卫反向腿钉住）。
- **参数问题**：`--max-tokens` 单值喂两角色、`timeout=120` 不可配——新增
  `--reflect/--verify-max-tokens` 与 `--timeout/--reflect/--verify-timeout`（缺省回落原语义）。

**验证**：守卫扩至 109 断言（含两态全链 REJECT 不落盘、撤销①正反腿、CLI 透传行为面）
＋定点变异自证六腿（还原任一处修复 → 红项数恰等登记值）＋独立复核 ACCEPT（HEAD 归档
对照＋212 例回放 oracle 对拍：202 全等、10 例分歧全部恰为旧式一票否决类、非法分歧 0）。
未采纳项 3 项（A 类②③宽严属判据设计边界、B 路无 E04x 签章闸、短流水计入 rejected）
如实登记于 `docs/eval/issue64_replay_check_核验与修复_v1.0.md`。

## 七、边界与如实声明

- **适配器属对端仓**：`brain_store` 在 `lingshu` 仓（身侧件进身仓）；本仓提供的是脑侧
  MCP 面（`state_event`/`state_chain`/`spatial.coords3d` 透传）与组合冒烟门禁腿。
- **组合验收为隔离库读数**：端到端演示与冒烟全部跑隔离根；在役权威库只读面不受影响。
- **鲸娘线产物落使用者私域**（语料预处理件/追踪图/思考档案），不入公开仓（纪律 9）。
- **状态追踪的语义边界**：七类中「因果」v1 以证据链承载（不做裸词形抽取，噪声依据存档）；
  分幕为事件间隔机械聚类，非情节判断。
- **issue #64 未采纳三项**：见 §五；其中 A 类②③若后续放宽，需带真实语料双向调参。
- **「身体」指对外完整身体库 lingshu**——本仓 README 中「AEIS 仅作可选身体能力后端」
  的历史表述不动（AEIS 为使用者私域身体实现；lingshu 为其对外完整版）。
