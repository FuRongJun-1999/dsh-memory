## 四、边界与如实声明

- **「承诺」类不做独立抽取**：词形 `答应|说好了|约定|拉钩` 全篇 **138 命中**——口语高频，
  独立抽槽必产噪声；v1 如实不做（候选读数存档，留待更专门的方法）。
- **「因果」类不做裸词形抽取**：`为了` 59 命中 / `因为` 225 命中，同为口语高频；
  v1 以**证据链**（每条事件的 quotes 轮号＋seq 时间轴）承载因果可查性——
  完整因果图属后续（可接 `cg(op=causal)` 边面，另立）。
- **「事件」类不建独立槽位**：每条五元事件本身就是事件记录（锚分类学的「追加类锚」），
  重复建槽＝第二真源，明确不做。
- 类别编目**不改 v4 槽位名**（与 P1 三率读数同源，零重命名零漂移）。
- 「时节」属背景事实类（非争议状态），首现轮来自角色侧叙述亦采——与 v4「用户侧=事实源」
  的政策面（争议状态）不同层，已注明。

## 六（v1.1 增补）· 状态追踪图：世界书 ＋ 大事记 ＋ 分幕大纲

使用者 2026-10-06：「整理出完整的状态追踪图……可以追溯故事的完整发展脉络和内容变化。
类似酒馆世界书或者是小说故事的大纲。」

**件** `scripts/whale_state_atlas.py`——一份 md 三视图同源（现有功能单点复用：事件经
库层 `state_events.append` 落台账 → `state_slots.project(include_retired=True,
history=True)` 投影出具**权威**现值/退役/变迁史；幕末快照按事件序现算）：

1. **世界书条目**（按七类分节）：每个槽位一张卡——**现值**／状态（active|retired）／
   **变迁史**（old→new、五类 kind、发生时点轮号、≤30 字证据短证可回原文核对）——
   即「酒馆世界书条目」的可追溯版（带变更链，而非静态设定）。
2. **大事记时间线**：全部状态事件按序一行一条（轮号｜类别｜槽位｜变更｜类型）。
3. **分幕大纲**：幕界＝事件间隔机械聚类（gap ≥ 60 轮）＋**单事件幕并入后幕**（机械
   规则，避免碎读）——本语料实测 **5 幕**：轮 136–613（定身份/背景/记忆澄清）、
   687–1040（宝物入账/搭档）、1108–1245（搬迁/规格修正/房贷撤回）、1308–1413
   （开店/新菜）、1475–1534（日记制度/晨间仪式/扩张）；每幕含事件清单＋
   **幕末状态快照**（该时点各槽位现值）——「每章末世界长什么样」。

**实测读数**：26 事件 → 12 槽位卡；md 7,447 字；产物落私域（`--out` 仓外 fail-closed）。

**如实边界**：本图是**状态骨架**（状态事件轴），非全量情节摘要（无情节抽取器）；
分幕为机械聚类非情节判断；证据短证 ≤30 字、含轮号。**可选后续**：导出酒馆格式
worldbook JSON（key=槽位/实体触发词 + content=现值与变迁——待规格确认后做）。

```bash
# 状态追踪图（读 v7 事件 → md；输出必须仓外）
python -X utf8 scripts/whale_state_atlas.py --events <state_events_v7.jsonl> \
    --out <仓外 .md 路径> [--act-gap 60]
```

## 七（v1.2 增补）· 通用常驻件：多主体状态追踪（核心能力定位）

使用者 2026-10-06 定位：「这个功能可以常驻，维护其他角色的状态追踪，这应该要作为
语义时空图的核心功能。」

**交付** `scripts/state_atlas.py`——**通用多主体**追踪图（与语料线两件并列）：

- **常驻形态＝查询时现算只读视图**（与 `state_slots` 同哲学，不存第二真源）：任何时刻
  调用即得最新；台账为唯一真源。**不依赖后台任务**。
- **多主体**：`--subject` 单取，缺省把库中**全部主体**各出一节（一份 md＝全角色世界书）；
  类别缺省按槽位「·」前缀推断，可 `--cat-map` 传映射表（鲸娘七类表即一例）。
- **三视图同款**（世界书卡／大事记／分幕）＋ 可选 `--worldbook-json`（酒馆风格
  `[{keys, content, subject}]`）。
- **库根解析与 zcode MCP 同源**（`--root`>env>`~/.zcode` 配置>缺省；复用一个 resolve
  单点）——**防双库分叉**的接线实测：不带 `--root` 运行时解析到权威库根（曾抓出过
  缺省根指向 C 盘遗留库的分叉缺陷，本件不再踩）。
- 只读；`--out` 一律仓外（fail-closed）。

**实测读数**：

| 项 | 读数 |
|---|---|
| 多主体演示（隔离库：鲸娘真语料 26 条＋合成第二角色 4 条，合成条已在演示脚本标注） | **2 主体 / 30 事件 / 15 槽位 / md 7,783 字 / worldbook 15 条** |
| 权威在役库实测（只读） | 台账 **0 条事件**、0 主体——机制全链就位、数据处女地；空库优雅退（171 字纯头） |
| 根解析同源 | 不带 `--root` 实跑解析到权威库根 ✓ |

**记账纪律（通用指引，从本语料线三层消歧口径提炼）**：状态变更发生时记账；用户侧
声明优先；非事实三类（玩笑/元层/回忆转述）如实标注不复盖；撤回＝old 有值 new 空。

**待裁（常驻自动化增强）**：是否在睡眠周期「整理」档挂「按主体预生成追踪图 md →
状态面」——现状按需现算已满足「打开即最新」，预生成仅为「打开就有文件」的缓存物；
改常驻循环属生产行为变更，须单独立项。

```bash
# 通用多主体追踪图（任意库、任意主体；输出必须仓外）
python -X utf8 scripts/state_atlas.py [--root <库根>] [--subject <主体>] \
    --out <仓外 .md> [--acts] [--worldbook-json <仓外 .json>]
```

## 八（v1.3 增补）· 会话链路接入：轮写入链第二步（使用者 2026-10-06 裁定）

> 「把这个功能作为会话的 10 轮信息写入，并在写入 mdcg 的时候做处理……每次写入
> 异步加了一些过程，但是好处是得到了可维护的状态……原始信息的关系追溯。」

**件** `scripts/state_extract.py`＋`sync_zcode_session.py` 接线（每轮写入链第二步）：

- **接线**：`sync_to_window`（zcode 端每轮——Stop 钩子/冷启动/压缩恢复共用）在写
  `_recent` 窗口的**同一循环内**，对同一轮调保守抽取 → `state_events.append` 进台账。
  钩子轮末子进程运行＝会话外处理（「异步」）；**逐轮 fail-soft**，抽取失败绝不影响
  窗口写入。
- **保守口径**：只抽用户轮（真人＝事实源）；仅两条高精度规则（`地点·所在` 迁移 /
  `情感·偏好`，负向显式记「不喜欢：」）；值剥句尾语气词；同值去重；证据
  `[auto] session=… turn=…`＋`actor=state_extract`（可整体甄别/清理）；开关
  `MDCG_STATE_EXTRACT` **缺省开**（=0 关）。
- **三层同源**：认知图（`_recent`/知识面）＋语义时空图（台账/投影/`state_atlas`）＋
  原文（会话 md 镜像/全量转写），evidence 互指——关系可追溯。
- **读数**：守卫 `scripts/test_state_extract.py` **10/10**（噪声三族「在看不抽/计划
  不抽/助手轮不抽」零命中、去重、变值成链 old→new、证据格式、开关、接线单点）；
  全量 **359/359**。
- **DSH 端**：同款接线在插件侧（TS），属后续件（须改插件并随包发布）；本批仅
  zcode 端在线。
- **已知边界（留裁决）**：「住在这里」类泛化词形会命中，收窄与否归使用者。
