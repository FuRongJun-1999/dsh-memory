## 一、起因与落地

**共同主线：读面损坏 UTF-8 家族**——单个损坏非 UTF-8 的节点文件即可让读取面裸抛 `UnicodeDecodeError`；本版把「读取面不得因坏字节崩溃」的口径从外部贡献的读取面扩展到全部同形态残余站点（跳过 / 结构化失败 / 计数可观测），并随版收口工程面。

1. **外部贡献 PR #54（贡献者 heimixieb）**：提交 `30e0580b`（健康检查跳过损坏 UTF-8 节点）＋ `ccef3bc0`（读取面跳过）——独立复核为双 worktree 红绿对照：改动前树上 `cg.get` 对坏字节裸抛 `UnicodeDecodeError`（复现红），PR 侧转绿；其 4 条全量红经改动前/主线同环境对照归因 PR 中性（新检出缺 rust release 二进制 fail-closed）→ 合并 `ed15a10e` 并回复（评论 5978111114，回复中含残余站点披露）。
2. **同形态残余加固（`c8cc4d4e`）**：`census.load` 与 `mreview.locate.load_node` 坏字节随 `OSError` 并入跳过（`md_cg/census.py:55` / `md_cg/mreview/locate.py:315`）；`mdcos.restore` 坏 trash 返回 `{ok:False, error:'corrupt'}` 且源原样保留（不删不移，`md_cg/mdcos.py:3023`）；`rollback.read_preimage` 坏前像抛 `RollbackError('preimage_unreadable')` fail-closed（不裸抛，`md_cg/rollback.py:178-180`）；`health()` 新增 `skipped_unreadable` 显式计数（跳过与不存在在统计上不再同形；代校验键集同步 20 键，`md_cg/mdcg.py:4791-4821`）；新守卫 `md_cg/test_corrupt_utf8_read_surfaces.py`（五断言面 29 断言 ＋ `--mutate` 五处定点变异红项 2/3/3/8/1 逐处命中、无跨面误伤）。
3. **随版工程面**：issue #53 三缺陷（密文假域标签 / 桶计数虚高 / 假 hash_drift，`377b84c8`）；CI 收口（PR #47 先构建 Rust/Hive 二进制再跑 Python 全量、套件并行改串行防共享临时目录竞态、charset 表与纪律指纹跨平台同判）；外部 v0.7.1 评测报告核验处置（`5b021410`：charset 跨版本三态、性能断言并行豁免、52× 规模前提补记）。

## 三、必须连着读的披露

1. **留池的同形态两站点**：白箱子系统自读面（`md_cg/whitebox_kb/wisdom/md_access.py` 的节点装载与边域枚举两处读盘）为同形态站点，不在本版覆盖——归档不适用条件已声明，留池。
2. **`skipped_unreadable` 属有意扩键**：与 `bucket_scope` 同构的扩键流程（纯增量、与既有键无冲突）——代校验键集 20 键对拍（18 既有 ＋ `bucket_scope` ＋ `skipped_unreadable`）逐字一致。
3. **restore 的「生效条件」契约行随行为同步**：`mdcos.restore` 的生效条件行与 `rollback.read_preimage` 的 docstring 随坏字节处理一并更新——行为与契约同一改动面。
4. **容器清单先绿后登**：本版补登两条坏 UTF-8 守卫进 Linux 容器清单（`scripts/linux_verify.sh`）——单跑与 `--mutate` 自证先绿后登。
