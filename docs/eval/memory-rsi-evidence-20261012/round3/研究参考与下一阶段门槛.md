## RSI-Anything：本项目值得保留的部分

论文把候选操作、预测目标、外部观测、策略版本、预测器版本和保留判定分开。预测可靠性只覆盖实际观测的候选范围；覆盖不足应标为 insufficient，不能当作可靠。更新数据、选择/保留数据与最终留出审计数据承担不同用途；组件通过也不等于策略与预测器组合后仍然通过。依据：[方法 §2.4–2.5](https://arxiv.org/html/2610.13912v1)。

原始 [RSI-Anything 仓库](https://github.com/Gen-Verse/RSI-Anything) 公开了候选生成、预测选择、外部评估和保留的流程及各领域适配说明。本轮仅阅读资料，没有下载模型、安装运行时、训练预测器或复现其论文成绩。论文其他任务的提升不能直接换算成 dsh-memory 的提升。

本项目的下一阶段门槛是研究推论：

1. B、C、D、E 在新任务上出现可重复的互补优势，而非单次胜负。
2. 简单规则对该选择确实不足；先与固定 B/D/E、轮换和随机选择的相同预算基线比较。
3. 特征只能来自行动前已有信息，不能使用最终评分或隐藏答案；按缺陷家族划分训练、门禁与最终测试。
4. 优先验证一个可解释轻量选择器。净收益必须同时计入预测开销、外部验证次数、未缓存输入/输出与延迟。
5. 预测准确率提升不能替代最终任务收益；预测器、反思策略、二者组合及身份正反回归都要独立验收。
6. 数据不够或组合验收失败时，保留既有版本，继续关闭反思；不把“缺少可靠性证据”写成“已可靠”。

当前公开状态链诊断显示，完整变更链的关键事件会被 top-k 丢失。该结果首先支持调查检索与证据交付，而不是证明需要预测器、ACE 或大型世界模型。最终是否进入下一阶段，以第三轮完整结果为准。
