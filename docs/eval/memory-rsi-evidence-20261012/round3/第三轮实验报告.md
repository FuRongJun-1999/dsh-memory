# dsh-memory 第三轮实验报告

本轮交付包括身份误拒根因与最小修复、第二轮 18 个配对案例和 61 次反思事件审计、8 个新仓库缺陷的 120 次 DSH 对照，以及独立的公开状态链证据诊断。生产插件与正式记忆库未操作，反思仍默认关闭。

## 核心结果

| 组 | 成功/24 | 成功率 | 三次重复成功数（各8题） | 3/3稳定通过的缺陷 | P50/P95 秒 |
|---|---:|---:|---|---:|---|
| A | 7/24 | 29.2% | 3/3/1 | 1/8 | 28.06/40.95 |
| B | 9/24 | 37.5% | 3/3/3 | 1/8 | 31.61/45.43 |
| C | 10/24 | 41.7% | 3/4/3 | 3/8 | 31.62/42.20 |
| D | 11/24 | 45.8% | 4/4/3 | 3/8 | 31.66/57.00 |
| E | 11/24 | 45.8% | 4/3/4 | 3/8 | 27.52/44.81 |

A 只恢复 Memory 适配器的旧 CSRE；B 为底层修复；C 为始终反思；D 为当前条件规则；E 只增加“当前候选通过独立检查后不反思”的 gate。五组的底层仓库模板、模型、资源上限和评分器相同。C/D/E 的反思为现有确定性模块，不是额外 LLM 思维模型。

统计单位是 8 个缺陷，三次重复相关。以下区间按缺陷聚类描述随机波动，不能作为统计显著或上线结论。

有效主样本为 normalized-results.json 的120个逻辑试验。期间2次 HTTP 402 余额不足中断，补充余额后以原配置各补跑一次，选择仅依据外生服务错误，不依据成败。controlled-v2 原始120份结果均未覆盖；service-replacements 保存2次替代运行，合计122次主实验尝试。原提示词哈希逐字一致；评分器、反思模块和冻结输入树一致，只有输出目录及驱动选择不同。中断发生在同一题 B/C 的第二次重复，补跑时间较晚，缓存与服务延迟比较仍有时间顺序影响。

## 身份正确性

错误源是第二轮 C 生成候选的布尔撤销缓存，当前候选主线已有正确逐令牌查表。原候选：合法误拒1/10、非法误放行2/17；最小修复和主线均0/10、0/17，全部30项通过。不同令牌表路径但相同mtime/size的补充边界也复现原候选错误放行；修复和主线均通过3项。

原生 DSH→stdio MCP 实际7次调用通过预期：有效和只读身份均读到公开节点，只读写入被拒。原生夹具的 info 单桶告警与 DEFER 验证状态单独记录；未将其误判成认证失败，也未将 internal 读链当作 private/secret 解密验收。

旧六题以原评分器在修复版和当前主线上均通过，共12个任务级回归。不可读令牌表保留旧兼容契约，未纳入“非法身份均拒绝”的分母；这不是完整 fail-closed 保证。详细根因、调用路径和边界见《身份误拒根因与修复.md》。

## 数据质量与无效批次

## 公开状态链与证据真实性

公开语料固定版本，排除旧现值题与前20题，用 qid 哈希选择25道历史/时点/状态/变更/缘由题。两次graph会话检索排序25/25一致，无预算超限；5道完整变更链均未取齐必要事件，平均必要事件cid召回率约23.52%。历史与时点各5/5命中必要来源，状态题有正向事件的3题中2题命中，缘由5/5命中。这里只是必要来源覆盖，正文截断仍可能丢关键句，未执行 reader 作答，不报告官方答案分数。

该语料此前用于检索诊断，新的是题目子集；其作者与被测仓库作者相同。提交序列跨度不等于真实用户跨月历史。它提供可复算的诊断，不能冒充独立第三方盲测或反思净收益。

进一步按必要来源数量核对：5道变更题分别需要27、7、27、5、2章；前三题超过k=6，完整覆盖在当前上限下就不可能。后两题即使k能容纳仍只召回1/5、1/2，说明还存在来源选择/交付不足。不能把0/5完整覆盖全归咎于排序算法；Token打包可能进一步少给章节。此为事后诊断，未改评分或重选题。

另13项运行探针确认：反思默认关闭；失败与模型自述的成功不形成经验候选；范围扩张与原始证据改写被拒绝；整理只提案，不自动提交知识，且可回滚。MemoryRSILab 的哈希/动作绑定验证不认证外部来源。两条训练观察的来源由实验收集的外部预检与冻结日志绑定，模块本身不提供签名真实性保证。
