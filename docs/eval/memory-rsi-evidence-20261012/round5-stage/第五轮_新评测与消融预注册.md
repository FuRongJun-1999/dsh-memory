# 第五轮新评测与消融预注册

本轮先完成第四轮 160 次质量审计与 11 次配对退步归因，再冻结新评测。新集不是对旧成绩的修订。

24 个 A→B 软件任务实例，6 个家族。开发集 6 实例×1 重复×6 组=36，验证集 6×2×6=72，最终留出 12×2×6=144；加 24 次真实 DSH A 会话，共计划 276 次。实例和重复按家族聚类，不能称为 276 个独立任务。

|类型|家族|真值来源与成功标准|
|---|---|---|
|记忆必需|routing-registry|过去会话的项目专属不透明 route 映射/default；新会话组装独立配置且保留 False/0，当前题面没有映射值|
|记忆必需|retention-policy|过去会话的项目专属 TTL 常量；新会话按边界淘汰和深复制，当前题面没有 TTL|
|经验迁移|interval-ledger|过去的区间 union 经验迁移到窗口裁剪、补集、多步骤可用时段计算；所有半开/相接/无效区间规则公开|
|经验迁移|ownership-tree|过去的递归 merge 迁移到一连串独立状态快照；明确 None/False/0/list 替换及跨快照独立性|
|负迁移|timestamp-contract|过去按 UTC 实际时刻排序，新任务按本地显示日期/时钟分组排序；拒绝旧时间语义|
|负迁移|sentinel-contract|过去只把 None 当默认值，新任务所有 falsey 值均回退；拒绝旧 sentinel 经验，保留容器所有权|

这些是可公开复现的构造合同任务，参考 Python 3.12 官方 copy/datetime/stdtypes 文档。并非真实生产缺陷，也不冒称新公开 Benchmark。每个 split 有不同项目 namespace 和私有事实；各 split 的 A 记忆图隔离。B 会话不写共享经验。

A 无记忆；B 原始 raw recall；C 只在相同 top-4 候选上加严格 typed 条件过滤；D 只替换交付，保留 B 候选和顺序，用已有 evidence_delivery 交付图内 A 文档及完整 source/time/conditions；E 按 A 身份账本和公开当前 namespace 选择仍适用的 A 文档，禁止读取 B 真值/reference；F 按相同固定查询的虚拟 D 响应配平整段工具 JSON 的官方 tokenizer Token 数，用无任务语义的中性文字替代。

模型、提示词、执行预算统一；所有反思关闭。query 由公开 family/namespace/contract 冻结，使检索与交付消融不被 Agent 的自由查询差异污染。单次 raw recall 1000 项目估算 Token，正文交付 750 项目估算 Token，与原始 B 一致。另记录官方 tokenizer 与 API 实际 usage，不能把项目估算当计费 Token。F 报告每次实际配平误差；API 总输入差异还受后续行动及工具历史影响，不能将全程总 usage 称为严格等长。

新评分器父进程保存真值，只把函数输入传给候选 worker。工具仅允许读 solution.py/context.json；候选的文件/执行/网络审计是研究保护，并非经过认证的恶意 Python 沙箱。验收采用逐合同输出、异常、输入不变、返回容器/快照独立性，48 个参考实现阶段已通过，48 个初始缺陷阶段均失败。首次预检发现的评分器“给纯 ID 列表追加探针误判别名”已在付费实验前修复，失败记录保留。

memory_use 改为可选，project_edit 可同时记录证据 ID；可见 rejected ID 能声明拒绝，只有实际交付正文 ID 能声明 use。这是各组共同的记录接口修复，不是 Memory 算法改进，也不放宽身份权限。

在打开留出结果前，按 preregistration.json 的门槛仅从 C/D 选一项：验证集配对增益>0、至少两家族正增益、无类别成功下降、回归/权限没有新失败。否则保留 B，不制造新算法。最终留出仅确认或推翻该候选，不能据此调参。
