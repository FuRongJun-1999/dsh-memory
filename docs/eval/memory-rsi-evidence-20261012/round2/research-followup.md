# Memory-RSI 后续研究参考

资料于 2026-10-12 在本轮 72 次主实验完成后核对。当前测试集、触发策略和评分器没有因新资料改动。已核验六篇论文的元数据/摘要，以及 RSI-Anything 的部分方法段和官方仓库说明；没有复现这些论文的实验，也没有引入其代码或模型。

检索入口：[DAIR.AI Self-Improving Agents](https://academy.dair.ai/papers/collections/self-improving-agents)。以下方法解释采用原论文；迁移方案是本项目提出的待验证假设。

| 资料 | 已核验的方法要点 | 对 Memory-RSI 的单因素验证方向 |
|---|---|---|
| [ACE，v3](https://arxiv.org/abs/2510.04618v3) | 用结构化增量更新维护经验上下文，避免反复整体改写丢失细节。 | 固定检索和验证器，只比较逐条增量更新与整体重写；测条件保留、事实丢失、冲突及新任务成功率。当前输出截断不等于论文所说的上下文坍缩。 |
| [Group-Evolving Agents，v1](https://arxiv.org/abs/2602.04837v1) | 将一组候选作为演化单位，在分支间共享探索经验。 | 将候选数和总预算固定，只改变能否共享已验证、带失败记录和来源的经验；不先构建大型多代理系统。 |
| [Mind the Gap，v2](https://arxiv.org/abs/2412.02674v2) | 将生成与验证能力的差距作为研究自改进的核心量，分模块研究验证、过滤与后续学习。 | 先测验证器的误接纳/误拒绝。当前 C 组一个候选通过原验收，却误拒绝另一有效身份，是最直接的本地证据。不能因判定器能读懂日志，就认为它能可靠判断泛化正确性。 |
| [AIDE²，v1](https://arxiv.org/abs/2609.26457v1) | 对自己的代码提出修改，通过独立隐藏评估选择保留版本，并检验未参与选择的任务。 | 固定提案器，只允许一个模块的小改动；开发反馈、选择验证、最终留出验收分开。复用现有 inbox、版本哈希和回滚机制。 |
| [Hyperagents，v1](https://arxiv.org/abs/2603.19461v1) | 把任务代理和可编辑的元改进过程结合；任务能力与改进能力的对应关系并非在所有领域成立。 | 先单独比较一种反思触发规则，验证它在新缺陷上是否改善；不同时开放验证器、记忆准入和元改进代码自修改。 |
| [RSI-Anything，v1](https://arxiv.org/html/2610.13912v1) / [官方代码](https://github.com/Gen-Verse/RSI-Anything) | 用预测选择需外部评估的候选；将实际反馈关联到预测版本；在可靠性、数据量和预算满足条件时更新预测器，并验收策略与预测器的组合。 | 先离线比较固定规则与轻量候选排序，不预先引入大型世界模型。只有积累独立反馈后，再单独验证预测器更新。预测可靠性必须按版本、覆盖范围与当前策略分布评估，不能把未执行候选的预测当真实反馈。 |

RSI-Anything 的方法段还明确区分“可靠性不足”和“已证实不可靠”：覆盖不足不能证明预测器可靠，也不直接触发预测器更新。其讨论保留了持续联合改进的证据边界；不能将跨域结果直接当作 Memory 长期收益。[方法与讨论](https://arxiv.org/html/2610.13912v1)

## 根据本轮瓶颈确定顺序

先处理验证覆盖，暂不增加反思模块。当前证据是：六个历史参考修复在原评分上全部通过；扩展验收仍检出一个原“成功”候选的有效身份误拒绝。原验收只有三个身份行为检查，未覆盖多个身份共享缓存的场景。应该复用现有身份、索引和一致性回归，增加跨状态/跨身份验收，保留独立最终留出集；这一步不能用本轮六个缺陷反复调到满分后声称泛化。

验证器覆盖稳定后，先做一个反思消融：在新的真实缺陷上，比较仅修复、同样的纠错清单、带历史证据的反思。固定模型、可编辑范围、预算和验收。这能区分收益来自一般提醒，还是来自经验内容。本轮 C/D 同时包含清单和历史观察，无法唯一归因。

条件策略也存在可研究的问题：D 在 18 次任务中触发了 16 次，事件数仅比 C 少 1 次。证据不足这个信号较宽，而且在独立检查已经通过时仍可能保留。下一次可以只改变“是否在行动已通过后停止反思”这一项，使用新的留出任务验证；本轮策略保持原样。

ACE、经验共享与预测排序按后续数据决定，不同时加入。当前只有两条经过独立复现的历史经验，且检索域预先给定，尚不足以判断大规模检索、长期上下文坍缩或预测器训练的收益。Hyperagents 保留为能力边界参考；无限循环、自主改变评分器和生产插件更新均不在本轮实现范围。

后续保留一个原则：外部证据最多支持已观察的动作和适用范围；是否成为可复用记忆，还需独立新任务验证。候选代码通过窄测试、哈希未变、论文报告正结果，都不等于已经建立持续净收益。
