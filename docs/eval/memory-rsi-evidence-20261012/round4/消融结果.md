本轮模型能够声明拒绝这些明显条件不匹配的经验，因此工程过滤减少了错误范围的交付，但未证明提高终局成功。仅3个验证家族、每题1次，不能泛化为条件闸永远无用或无风险。

另有零API的证据认证负对照：两份伪造source=tool且passed=True的自标记录，在真实验签回调下0/2被接受、巩固暂缓；把回调故意替换为accept-all后2/2被接收并生成source-supported candidate。这个不安全回调仅在隔离负对照图中出现，不进入产品或主实验。此结果证明接口信任边界的重要性，不是B迁移成功率，也不是一般知识真实性证明。

重复同一来源不能刷支持数、缺来源/失败来源/相反checked_claims均暂缓，属于工程边界检查。没有通过删除这类门槛提高主评分；来源实例相关性另行披露。

D对C是条件核对提示的组合对照；主B/C同时比较来源绑定、限定条件和胶囊交付这一最小链，不能从总分分离每个组件的独立收益。反馈版本化有真实失败轨迹重放演示，但未开展B1→在线反馈→B2的长期成功率实验，不能把版本链正确当作持续学习效果已成立。
