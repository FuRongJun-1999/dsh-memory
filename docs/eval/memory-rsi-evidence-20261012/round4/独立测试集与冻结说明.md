# 第四轮独立迁移测试与冻结

## 划分与统计单位

开发试运行6对、3个家族，先建立原始经验基线，再实现最小适配层。正式候选算法哈希为 `8af142463ec5b0d0384dddf063635d8eda08eebf0d5d6b452a2808b9d704fc1b`；随后构建独立验证6对、3个新家族，以及正式最终测试20对、10个家族。三部分任务文件、源A会话和记忆图均分开。正式20对每组重复2次；重复和同一家族两个实例不视为独立任务家族。

样本是依据公开Python/API契约及明确应用策略独立编写的最小可执行复现，**没有冒充真实上游Issue检出或第三方官方Benchmark**。同一家族的两份A大多为函数名不同的相关实例，不能因不同task_id把支持数当作独立验证置信度。本轮20对的统计信息量是10个广义家族，不是20或40个独立缺陷。

每个家族有两个A来源；B1具有适用条件相同、接口/操作不同的正迁移机会，B2是条件或目标不同的不适用经验机会。两组机会标签在模型运行前确定，不把“机会”直接称为已经发生的迁移收益。

| 正式家族 | A经历 | B正迁移机会 | B不适用机会 |
|---|---|---|---|
| dependency-version | PEP 440比较 | 多依赖锁版本验证 | 不透明厂商标签按显式优先级 |
| api-parameter-migration | HTTPX 0.28参数迁移 | HTTPX配置合并与falsey值 | Requests仍使用proxies复数 |
| configuration-root | YAML mapping根 | JSON mapping及隔离默认值 | YAML sequence根 |
| data-structure-protocol | Mapping抽象接口 | 只读Mapping与输入保护 | 一次性键值对迭代器 |
| permission-conjunction | 私有资源权限合取 | 操作、租户及权限联合判断 | 公开只读允许匿名 |
| stale-event-knowledge | 最新版本状态 | 多键最新状态与同版本边界 | 完整历史保留及重复事件 |
| multi-step-url-encoding | 原始path component编码 | 路径、列表query与空query组合 | 已签名URL字节保留，仅改fragment |
| historical-policy-conflict | None-only覆盖规则 | 多字段继承与falsey覆盖 | 锁定策略禁止覆盖 |
| insufficient-evidence | literal True及真实tool来源 | 全部必需检查、缺失及重复 | 可选metrics不承担批准作用 |
| failure-safe-publication | 序列化失败保留旧快照 | 完整JSON替换 | JSONL追加，不可覆盖历史 |

独立验证为timezone（instant与wall-clock）、text/bytes（人类文本与二进制）、iterator（有限快照与有界流）三个新家族。验证只检查固定候选的表现和实验完整性，不以其结果修改算法或挑选正式题目。

## 真值与运行契约

每个A/B包含缺陷源码、参考实现、公开context和不可变的外部行为检查。全部题目的缺陷版必须失败、参考版必须通过，先编译再执行。正式环境80个变体、验证环境24个变体均在任何对应模型调用前通过此核验。早期草案的缺依赖和字符串转义错误保留在draft-v1/v2与preflight记录；修正发生在正式付费调用之前，没有据模型表现更改真值。

Python 3.12.10，HTTPX 0.28.1；其他依赖完整锁定在runtime-setup/requirements-lock.txt。使用E盘独立venv，不改共享旧venv。评分器限制读写边界、子进程和网络，候选只能编辑solution.py并通过固定工具查看公开源码；这不是经过认证的恶意Python操作系统沙箱。

基础模型固定 `deepseek-official/deepseek-flash`，reasoning off，每请求输出上限2048。正常DSH命名profile，provider自动重试0。A学习预算12模型请求、18工具、120秒；所有B组统一8请求、14执行工具、120秒，记忆公共返回预算约1000估算Token。A学习预算对四组共同，不与B预算混比。

A=无跨任务记忆；B=现有图原始经验（显式读取tool-output工作角色）；C=同图原始经验加带认证来源回执的限定条件胶囊；D=C加条件触发核对提示。D的触发为无充分记忆/候选被拒，或连续两次外部检查失败；每个B最多一次。提示不增加外部事实，不单独调用另一模型，也不代表完整的生成式反思算法。条件字段由评测提供给所有组，本轮不声称学会从自然语言中自动识别完整条件。

B/C/D获得**同一批实际A原始轨迹**，C/D只增加其独立重放与签名回执及来源胶囊。A聊天不直接带到B；每次B全新DSH会话和独立图副本。正式B运行顺序按题目和重复轮换ABCD以缓解顺序/缓存混淆。主实验不让B写共享经验，避免前一B答案泄漏到后一B。

## 冻结与计分边界

正式源代码快照、控制器、评分器、题目、依赖锁、模型设置及DSH提交逐一哈希；每次运行前后复查，最终B另外冻结全部A经历与主记忆图。独立验证结果完整落盘后才生成validation-gate.json并允许正式B启动。这个门代表实验完整性检查，不代表验证集胜率达标或模型批准上线。

主要计分要求真实DSH工具链有效、未超时、正常结束或预算阻塞、最终独立行为检查通过。API格式错误等完整会话故障与行为检查失败分列；不重跑挑最好成绩。正式A一次出现MALFORMED_RESPONSE：行为检查已经通过，但会话完整性失败，因此原始失败轨迹保留、巩固器保守排除该条。相应URL家族只有一份会话成功证据，未生成胶囊。其他组仍得到这条原始经历。

使用声明只证明模型显式说过use/reject/defer。分析另查实际交付、编辑和外部结果，不把来源可追踪当作语义正确，不把“声明采用且成功”当作已经证明因果收益。未声明时记录采用未知；无召回不算拒绝，不适用范围拒绝不等于认证/授权拒绝。

最终数据按广义家族聚合配对差异，并报告每次重复、缓存桶、未缓存输入加输出、调用次数及P50/P95。若结果存在天花板或家族数不足，明确保留不确定性；退化bootstrap不能证明新任务上的真实效果为零。实际扣费记录不可取得时不编造人民币成本。
