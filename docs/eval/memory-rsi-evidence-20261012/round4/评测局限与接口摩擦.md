# 评测局限与接口摩擦

这些问题在查看原始轨迹时发现。本轮不修改已冻结题目、评分、控制器或模型预算，不重抽样挑选成绩；以下分析属于事后诊断，不能当成预注册的独立效应检验。

## YAML序列题的异常类型规格

`configuration-root-2` 的公开问题要求YAML sequence、非空字符串成员、拒绝非法根和成员，但没有明确所有非法成员必须抛TypeError。固定评分器只捕获TypeError；某些候选对非法成员抛ValueError，随后依据失败反馈尝试修正，可能耗尽预算或产生不完整编辑。

参考实现和预检查通过只能说明评分可执行，不能消除题意不足。保留原主评分，但这一题不宜用来证明算法对一般异常处理的优劣。后续新评测应在模型运行前明示公共错误契约，或接受公共规格允许的等价拒绝行为。不能在本轮看过答案后放宽评分。

## 权限题未公开完整字段契约

`permission-conjunction-1/2` 的固定评分使用actor的`ops`列表来表达write capability，但公开题面只说“write capability”，缺陷源码和context均未给出`ops`。候选因此使用`capabilities.write`、`can_write`等不同约定；这些并不能单独证明推理能力不足。公开读取还有部分策略约束需要从自然语言推断。

本家族仍能暴露某些明确的角色/租户错误，但整体0分不能当作可靠的知识迁移失败率，也不是生产MCP授权的误拒/越权证据。此前将其全失败直接理解为能力边界过早；原始成绩保留，两个任务标为字段规格不足。它们连同异常类型歧义题不用于强能力结论。

为避免用规格不足样本凑20对，新增3对完全不同的B：PEP440版本窗口、Mapping浅分区、带tombstone的单调版本视图。字段、边界、返回类型、复制语义和错误契约都在公开问题中明确；缺陷/参考预检查6/6通过。算法、20份原始A经历和B预算完全不变，3对×4组×2重复=24次额外DSH会话。该批作为事后补充证据单独报告，不改原定20对成绩，也不把组合后的结果冒充预注册主结果。

## 可见拒绝元数据与使用声明的约束

C/D的工具返回包含`retrieved_ids`及带ID的REJECT/DEFER元数据，但`delivered_ids`只包含真正交付的胶囊正文。固定memory_use接口仅允许引用delivered_ids，连reject/defer声明也受此限制。

模型若尝试声明“拒绝已显示的rejected ID”，会收到`Only actually delivered memory IDs may be referenced`，随后改用空ID声明。这是记录接口的约束与可见元数据不一致造成的摩擦，**不是认证/授权误拒**。例如configuration-root-2重复1的C有一次此错误，消耗固定预算后最终留下SyntaxError。

所有原始参数和错误保留；case-paths中统计declaration_error_count。C/D的终局变化包含包装器交互成本，不能全部归因于经验规则质量或巩固算法本身。后续可单独验证：use仍限定正文交付ID，reject/defer允许可见的拒绝元数据ID；必须新建实验，不能修改本轮记录后重新称为原对照。

## 范围过滤、截断和反馈

精确字段条件只保证不超出来源记录的验证范围，并不等于学会识别语义适用条件。部分子结论可能在不同条件下仍可迁移，但整胶囊过滤会一起抑制；这需要独立子结论验证，不能简单放松身份权限或把未知默认当真。

公共记忆文本可能被截断，内部pack不等于模型收到的完整经验；实际交付ID只证明该条目在文本中出现，不保证其尾部动作/条件全部到达。相关截断与路径指标单独统计，未据此改运行中的预算或检索器。

真实反馈演示中，B因未隔离嵌套值而失败，时间转换经验可能完全正确。保守追加disputed是失败关联的隔离行为，不是已确定“旧知识错误”。没有开展在线B1→反馈→B2成功率对照。

## 数据、模型和费用边界

20对正式题来自10个广义家族；每家族两个A是相关构造实例，主要为函数名及B操作变化。它们不是20个独立上游缺陷，也不是正式第三方Benchmark。HTTPX/PyYAML等使用真实锁定依赖，其余多为标准库/应用契约最小复现。依赖版本语义题不等于完整pip解析器的真实仓库冲突；逻辑事件版本题不等于数月在线陈旧知识的长期试验。

模型ID、reasoning、输出上限、重试、工具、请求次数及DSH源码提交固定。温度未显式覆盖，沿用同一SDK/服务端默认；无法锁定远端权重版本或服务负载。完整日志与重复运行支持重新检验，不保证重新调用API逐字复现。

成本取DSH已报告usage。实际账单不可取得，流式错误若没有usage可能存在未计入的调用成本。1000是检索包的估算预算，条件提示另计真实usage；不冒称Tokenizer硬输入上限。模型会话P50/P95不包含一次性安装、A学习及离线巩固，不能作为全生命周期成本。

这些限制要求结论保持在“当前实现与当前固定协议未建立稳定收益”，而非“经验巩固普遍无效”。本轮允许负结果和不确定结论，机制继续默认关闭。
