# 第四轮研究方法对照

核对日期2026-10-12。使用原论文与作者代码仓库；Hugging Face的MindMemOS Markdown入口未提供可读正文，改读arXiv HTML。未下载模型、安装论文系统或改动灵枢世界模型。下表“可用原则”是本项目研究推论，论文成绩不作为本项目收益。

| 方法与原始来源 | 问题与核心算法 | dsh-memory已有部分/差异 | 候选收益与成本 | 必要独立验证 |
|---|---|---|---|---|
| [ACE 2510.04618v3](https://arxiv.org/html/2510.04618v3)；[作者代码](https://github.com/ace-agent/ace) | 用生成、反思、策展产生小条目增量，结合helpful/harmful计数及去重；避免反复整体总结丢细节 | 已有图节点、提案和演化账本。缺的是跨真实任务的规则适用和效果证明，非缺playbook存储 | 追加而非全量覆写能保源；低工程成本。LLM策展可能额外消耗，不能不计学习成本 | 与原始经验比较B任务成功；版本历史完整性；去掉条件或证据门的消融 |
| [MindMemOS 2608.12428v1](https://arxiv.org/html/2608.12428v1) | entity–property–time表示；Dreaming先找局部问题再规划保守修改；反馈区分临时/场景/长期；技能按真实轨迹和版本更新 | 现成condition_space、时间轴、归纳、影子周期与反馈。无需复制第二套存储或整套技能云服务 | 借鉴限定范围、保留来源及反馈版本，工程成本中等。自动改schema和技能演化暂不移植 | 失败反馈只能影响对应版本和范围；跨会话复用；原始证据不丢失；B1→反馈→B2须独立分析 |
| [Engram 2601.07372v2](https://arxiv.org/html/2601.07372v2)；[作者代码](https://github.com/deepseek-ai/Engram) | 模型内部N-gram多头哈希查表，结合隐藏状态门控和局部卷积；查表与条件计算互补 | 外部认知图不修改模型内部层。已有条件检索和缓存，不能把普通字典索引称为Engram | 只借鉴“快速寻址仍需当前条件确认”。移植神经模块成本高且不适用本轮 | 若将来优化寻址，先比现有索引/简单规则，并测任务结果和真实延迟，不用查找速度替代迁移收益 |
| [RSI-Anything 2610.13912v1](https://arxiv.org/html/2610.13912v1)；[作者代码](https://github.com/Gen-Verse/RSI-Anything) | 固定任务接口/预算/验收；候选动作预测与真实观测绑定，策略和预测器分别更新，再做组件及组合保留验证 | 已有离线候选与检查，本轮尚无可靠操作选择训练集，也未证明策略互补性 | 借鉴反馈绑定和独立保留门，低成本；预测器与JEPA不实现 | 先证明B/C/D跨任务互补；再与固定/随机/简单规则选择比较；总成本含学习、选择和验证 |

[DAIR.AI合集](https://academy.dair.ai/papers/collections/self-improving-agents)只作导航。其“从经验学习”与“改进改进器”的区分适用于本轮：我们研究持久经验与新任务表现，不把写了记忆或改了规则自动称为递归自我改进。

本轮只选择一个工程候选：在既有图、CCG、签名器及原始经历之上，增加带来源回执的增量经验巩固与条件确认。先验证它能否帮助独立B任务，不同时接入自动schema搜索、神经寻址和预测控制器。
