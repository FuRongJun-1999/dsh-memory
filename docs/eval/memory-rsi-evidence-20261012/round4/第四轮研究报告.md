## 这轮证明和没有证明的事

证明了：同图保存完整经历、真实执行回执绑定、带明确条件的检索交付、拒绝超出已验证范围的胶囊、追加反馈与回滚可以在真实DSH入口工作。没有证明：模型总结已成为一般正确规律、条件能够自动从任意自然语言提取、声明采用等于因果采用，或在线持续学习能长期提高成功率。

候选胶囊persistent verification_state保持unverified，knowledge_verified=False。模型总结和负条件原样保存在原始经历，未自动晋升。来源签名认证本机控制器及绑定内容；真正可信的是检查覆盖内的A执行，不是所有未知B的普遍真理。

失败反馈演示暴露出归因边界：B因嵌套复制遗漏失败，相关时间规则本身可以正确，但保守机制仍追加disputed版本。反馈应优先改进“具体子结论与具体失败的证据绑定”，不应由模型自述或一次相关失败直接判定规则错误。

测试样本是公开接口/应用契约的独立最小复现，并非真实上游Issue检出或官方Benchmark；同一家族A多数为相关实例。公开context由评测提供给所有组，不能将精确条件过滤包装成学会了条件识别。未执行生产MCP安装或正式用户记忆库验证。

事后审计发现YAML序列题未明确非法成员异常类型，两份权限题未公开ops字段契约；C/D还有可见拒绝ID不能用于reject声明的接口摩擦，会消耗同一执行预算。原评分和日志不改，因而不能把所有差异纯归因给巩固算法。详见评测局限与接口摩擦.md。

D的条件提示在40/40个正式会话中触发，因为任一无关候选被拒也会触发。在本数据中它退化成每次提醒，未证明具有条件触发节省成本的能力；不能将这个结果扩展为所有反思方法无效。

## 决策

保留前三轮底层正确性修复；第四轮适配层保留为默认关闭的实验代码，不进入生产。暂不进入预测模型训练或JEPA/世界模型阶段。后续优先使用真实仓库缺陷、信息更完整的外部反馈及预先声明的知识子结论验证；先与简单条件规则比较，逐项验证，不同时增加多模块。
