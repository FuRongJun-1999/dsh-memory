独立分支的现状审计已经输出。使用同一DeepSeek Harness正常profile、deepseek-official/deepseek-flash、reasoning off。6个A任务均通过外部行为评分，并各自产生一份候选经验说明；没有把A聊天上下文直接带入B。

6对试运行来自三个公开Python契约的独立编写复现：缓存身份、None与falsey边界、嵌套对象所有权。每家族两个A实例相关，不声称是六个独立缺陷或真实上游Issue检出。每家族有一个正迁移机会和一个不适用经验机会。

保存A全部实际工具观察、候选编辑、最终检查与经验说明至同一contextual图。原始经验组的B仅通过现有MdCGOS.recall获取这些数据，经验仍为unverified。无跨任务长期记忆组返回空记忆。B均使用新DSH会话、同一题目与评分、12模型请求/18工具/120秒上限、每请求2048输出Token。

最初pilot-controlled-v2中无记忆A组6/6、原始经验B组6/6，但事后审计发现B实际召回为空：现有默认候选过滤器排除了tool-output角色。该批完整保留，计入研发消耗，不能作为已经发生经验复用的基线。

pilot-controlled-v3通过现有recall接口显式指定contextual、include_work=True、judge=False及lexical路径来读取原始执行经历，没有修改权限或把经历认证为事实。先进行6次零API非空召回探针，再把A/B均重新配对运行。更正后的A、B各6/6，随后C、D也各6/6。该结果有满分天花板，只证明存储、全新会话、召回和评测链路可以运行，不证明经验巩固有效或无效。正式测试另建，不以这六题的答案调最终测试。

在开始任何B调用前发现公共工具结果会同时输出预算文本与原始pack，造成重复交付。已保留原控制器，并在pilot-controlled-v2仅输出预算文本，将完整pack存入独立审计文件；未产生受影响的付费B试验。六份A轨迹完全复用，无需重跑。controller-correction.json记录哈希与映射。
