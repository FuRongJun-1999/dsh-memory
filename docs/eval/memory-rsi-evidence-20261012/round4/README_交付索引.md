## 不消耗API的重放

使用Python 3.12及`formal/runtime-setup/requirements-lock.txt`依赖，工作目录为解压后的证据根。指定一个不存在的E盘输出目录；旧文件不覆盖：

```powershell
& $r4py -B -X utf8 .\research\replay_source_evidence.py .\formal formal 'E:\lingshu\work\round4-replay-new'
& $r4py -B -X utf8 .\research\analyze_campaign.py .\formal formal
```

第一条重新执行原A行为并在新图签发新回执，不调用模型；第二条重算派生统计，不重跑DSH或改原始结果。模型重抽样须新campaign及新哈希，使用相同DSH提交、模型设置和预算；API随机性、服务端默认温度及权重版本不能保证逐字重现。

实验分支 `codex/memory-learning-round4-20261012`。原工作区HEAD、Git状态/diff和27项旧研究文件均保持；新增组件显式启用且默认关闭，追加版本回滚保留历史。没有系统文件删除。
