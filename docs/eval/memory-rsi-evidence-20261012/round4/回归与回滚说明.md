## 禁用与回滚

组件默认 `enabled=False`，必须在现成离线sandbox标记及明确验签器下才能显式启用；生产MCP/调度器没有接入它，保留现有Memory路径即可禁用。已生成的胶囊可调用 `rollback(current_capsule_id)` 追加rolled_back版本，后续召回不交付该头版本；所有原始经历和历史版本保留，不删除系统或用户文件。

真实失败反馈演示在单独图副本中完成：validation的时间排序C失败被独立重放，再追加disputed v2和rolled_back v3，原始来源及v1完整。这个失败来自B的嵌套复制遗漏，不能证明原来的时间规则错误；保守标存疑会误撤正确经验，是下一步应研究的反馈归因边界。主实验图未被反馈演示修改。

交付包不包含API Key或本地签名私钥。跨机器复现须安装锁定依赖与相同DSH版本，并在新的E盘目录重新执行原A候选、建立新测试权威；新签名/胶囊ID会改变，旧证据和旧freeze不改写。普通SHA清单证明文件一致性，不提供第三方可信执行证明。
