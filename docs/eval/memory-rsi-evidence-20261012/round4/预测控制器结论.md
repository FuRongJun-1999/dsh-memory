# 是否进入预测驱动Memory-RSI

结论：暂不训练预测器，不接入JEPA或世界模型；第四轮新机制和反思仍默认关闭。保留离线候选、原始证据、底层正确性修复和可回滚版本链。

正式C/B净成功变化+0/40；D/C净变化+0/40。这说明不同运行可能各有胜负，尚不足以形成可靠的“任务条件→最佳操作”训练真值。20对构造任务只有10个广义家族，重复与相关A不增加独立信息量。

当前可见瓶颈包括：部分A虽已修复却因DSH参数解析失败没有完整经历；多源门槛保守地留下知识空缺；精确字段条件限制了子结论迁移；原始与胶囊交付可能截断；新B的额外要求未被旧经验覆盖；失败反馈往往没有明确指出失败子条件；可见拒绝ID的声明接口不一致；核对规则因无关候选被拒而每次触发。预测器不能替代这些证据缺口。

下一步若研究操作选择，应先预注册简单规则：无充分来源则暂缓；相同已验证条件则交付；明确冲突或连续失败再核对；身份权限始终由原系统判定。随后在真实仓库新缺陷上比较固定操作、随机选择与规则选择，计入选择/验证全部成本。只有确认稳定互补、任务特征不泄漏答案且具有足量真实反馈，才考虑轻量预测器。

关于反馈，先验证“失败的具体检查→相关知识子结论”证据绑定；对于与经验无关的新要求失败，保留旧经验并另记局部疑点可能比全面标存疑更合理。但这只是后续候选假设，未在本轮改实现或用最终答案调规则。

RSI-Anything可借鉴候选/外部反馈/组件独立验收原则；ACE可借鉴增量保源；MindMemOS可借鉴限定范围和版本化；Engram不属于本轮外部记忆模块。依据在前沿方法对照.md，不将论文结果当作本项目效果。
