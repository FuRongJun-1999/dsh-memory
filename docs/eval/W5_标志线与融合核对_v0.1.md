**§1.6.8 结构互补性原则**（`:1139-1153`）

> **结构互补性原则**：在物理-信息层基底，结构互补是信息差缩小的一种底层形式——**两个结构状态通过形状匹配直接趋向一致，不需要符号编码作为中介**。（`:1141`）
> **与信息论的关系**：结构互补是物理-信息层基底的有序度交换形式，`符号编码是其在特定条件空间中的投影`（0.0.2 节任意分层性）。（`:1143`）
> 层级关系：物理-信息层基底（结构互补／形状匹配／有序度交换）→ 投影 → 上层条件空间（符号编码／信息论映射／JS 散度／信道）→ 投影 → 人类可理解层。（`:1147-1153`）

**§1.6.9 否决式融合（维度优先序）**（`:1155-1171`）

> **维度优先序**：**证据 ≻ 导数 ≻ 图 ≻ 概率**。（`:1157`）
> 优先级来自**与物理基底的距离**——证据最近（直接来自物理基底，回答"物理上发生了什么"），概率最远（仅表达不确定性）。当高优先维度已能否决（物理证据直接矛盾），概率不再参与决策。（`:1159-1161`）
> **否决式融合**：
> ```
> S_candidates = { s : ∀d ∈ {E, Dp, G, P}: score_d(s) ≥ θ_d }   # 硬下限
> s* = argmax_{s ∈ S_candidates} [ w_E·E(s) + w_D·Dp(s) + w_G·G(s) + w_P·P(s) ]
> ```
> - 每维设硬下限，任何一维低于阈值直接否决（蜡苹果在触觉维度直接出局）
> - 高优先维度有一票否决权 + 幸存者内再权衡
> - 概率负责可信度，条件负责资格（与 1.6.9 前的概率/资格分离原则一致）
> - **归一化前提**：四维度分数须归一化到同一量纲，阈值排序才有意义。（`:1165-1171`）

## 五、判定（三句话，照前几块探针的「X＝Y」写法）

1. **路径感知实证 ＝ 成立（首版）**：`_recursive_reflect.trace`（逐层 depth/frontier/fresh/gain）＋`stopped_by`＋`reason`/`missing`/`hint`/`scanned-kept-truncated`＋检索 `per_path`/`provenance` 构成可指认、可复跑的路径自述；局限＝命名分散、多为事后留痕而非运行时自述、无单一「路径指纹」对象（未达全亮档）。
