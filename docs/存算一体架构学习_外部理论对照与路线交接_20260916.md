## 1. 两份论文的核心主张与分歧

### 1.1 Nature 综述（领域路线图，正统阵营）

- **存算一体**（in-memory compute）：RRAM/PCM 就地计算，破 von Neumann 瓶颈——引用 121/156 的芯片实证；
- **活动稀疏性**（activity sparsity）：事件驱动才耗能——20 瓦人脑之谜的机制答案（引文 104：稀疏经时间反传）；
- **八个规模化 co-design 特性**（正文付费墙，框架在案：异步事件驱动/稀疏通信/局部学习/存内计算/时空计算/在线适应/混合表示/固有可扩展性——逐条核对待全文）；
- **拦路虎**：软件生态不成熟（Lava 等）、基准缺失（NeuroBench 100+ 人协作补位）、**hardware lottery**（引文 103：硬件决定算法命运）；
- **判断**："AlexNet 时刻"=赌芯片生态成熟。

### 1.2 Overmann（计算理论，激进离散路线）

- **集合论+超维度计算（HDC）**：稀疏二进制**集合**数据替代连续权重与矩阵乘法，直接建模生物**群体编码**；
- **拓扑可塑性**（topological plasticity）：学习由网络拓扑生长驱动，"rather than scalar weight adjustments"——非标量权重调整；
- **子集模式匹配**：统一自联想与异向联想为单一算法，配合组合扩展隐藏层实现**常数时间精确最近邻**；
- **桥接**：感知（稀疏分布式表示 SDR）↔符号（稀疏全息表示）无缝转换，无连续瓶颈；
- **神经解剖映射**：小脑+新皮层=同一算法的两个变体——子集模式匹配是认知基本引擎；
- **硬件路径**：纯离散逻辑→直接转存内硬件，**现有数字电路即可**，达人类级能效。

### 1.3 分歧与共同点（对选路线的关键）

| | Nature 线 | Overmann 线 |
|---|---|---|
| 表示 | 脉冲+模拟状态（专用芯片） | 纯稀疏二进制集合（现有数字电路） |
| 硬件依赖 | 高（Loihi 类神经形态芯片成熟度） | **低（任何数字逻辑可跑）** |
| 与灵枢距离 | 方法同构（稀疏/局部学习/存内） | **表示同构（我们就是离散集合路线）** |

**共同点**：反 BP、反浮点矩阵乘、稀疏性第一性、存内计算、生物合理性。**共同启示**：下一代的"规模化"不靠更大的 GPU 集群，靠**表示与计算范式的更换**——这正是灵枢已经在做的事（认知图=条件化+信任化的离散集合表示）。

## 3. colibri 系统工程佐证（第三参考）

- **AI memory multitiering**：VRAM/RAM/NVMe 单一层次，权重被「放置」而非「装下」——744B 每 token 仅激活 40B（5.4%）的稀疏实证；
- **JIT for weights**：实测路由热度→LRU+学习型 pin+预取（坦承可过拟合，保持为可测策略）；
- **语义硬保证**：「内存不足可降速，不得静默重定义模型」+ token-exact 前向验证（KV 57× 压缩语义不变）；
- **研究文化**：每个优化=假设须控制变量 A/B，鼓励发布负结果——与灵枢验证纪律同款；
- **对存算一体的映射**：认知图已具 multitiering 雏形（`_index.json`=常驻层/md 文件=盘层/access_count=路由热度）——**「检索命中→节点分层驻留」是 GLOBAL_CAP 问题的架构级正解**（比截断优雅）。

## 4. 学习吸收路线（三档，接存算一体总纲 §9）

### 中期（存算一体阶段任务）

### 远期（世界模型阶段）
