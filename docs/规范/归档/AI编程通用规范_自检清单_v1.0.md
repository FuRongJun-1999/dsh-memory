## 三、人工自查（每次交付前 5 问）

1. 验收标准我写了吗？做到了吗？
2. 我的依据能指到具体文档/代码行/读数吗？
3. 我说「做好了」的地方，证据在哪？
4. 有没有「应该/大概/可能」在冒充事实？
5. 这次做完，我留下了什么能让别人接着干？
