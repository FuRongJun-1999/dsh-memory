## 3. 可视化管线（7 步）

所有脚本**只读真源，不写回**。统一用 `--root` 或环境变量 `MDCG_ROOT` 指定认知图根，**不硬编码本机路径**。

### 执行顺序

```bash
# ① 导出（真源 → graph.json + edge_report.md）
python AEIS/tools/coggraph/export_coggraph.py --root <mdcg_root> --out AEIS/data/graph

# ② 关系显式化（graph.json → derived_edges.json + sample_check.md）
python AEIS/tools/coggraph/derive_edges.py

# ③ 会话串链（_audit.jsonl → session_chains.json）
python AEIS/tools/coggraph/session_chains.py

# ④ 命名审计（四问测试 → naming_report.json + .md）
python AEIS/tools/coggraph/naming_report.py

# ⑤ 同义归并（中文实词 → synonym_groups.json + synonym_report.md）
python AEIS/tools/coggraph/synonym_merge.py

# ⑥ 渲染构建（多源 → viewer_graph.json + index.html）
python AEIS/tools/coggraph/build_viewer.py --derived derived_edges.json session_chains.json

# ⑦ 本地服务
python AEIS/data/graph/serve.py 8788 AEIS/data/mdcg
```

### 各脚本职责

| # | 脚本 | 输入 | 输出 | 关键设计 |
|---|---|---|---|---|
| ① | `export_coggraph.py` | mdcg root | `graph.json` `edge_report.md` | 确定性导出；支持 `--layer`/`--bucket` 过滤 |
| ② | `derive_edges.py` | `graph.json` | `derived_edges.json` `sample_check.md` | **推导边绝不与显式边混淆**（`derived=true` + 规则名 + 权重）；R1–R5 规则（含 R5 分块正则，6,794 条） |
| ③ | `session_chains.py` | `_audit.jsonl` | `session_chains.json` | R6 顺序边；会话枢纽 `session:<id>`；同 schema 便于合并 |
| ④ | `naming_report.py` | 标题集合 | `naming_report.json/.md` | Kimi 框架**四问测试**：Q1 可连 / Q2 可对齐 / Q3 可复现 / Q4 规范标识；裁决三态（强规范锚 / 已锚定 / alias 候选） |
| ⑤ | `synonym_merge.py` | 中文标题 | `synonym_groups.json` `synonym_report.md` | L1 深度规范化等 / L2 语序变体 / L3 编辑距离 1（**只进待复核，不自动归并**）；忽略含 ASCII 的标题 |
| ⑥ | `build_viewer.py` | `graph.json` + 多个 `--derived` | `viewer_graph.json` `index.html` | **布局在 Python 端确定性预计算**（桶网格 + 黄金角散布），前端只渲染；hub 节点移到成员质心；`--derived` 可多次传入；cytoscape.min.js 首次运行自动下载 |
| ⑦ | `serve.py` | `viewer_graph.json` | HTTP :8788 | 纯标准库；`MDCG_ROOT` 可自动探测同级 `mdcg` 目录 |

### canonical.py 设计（2026-09-14 使用者四要素）

```
① 标准语义基准     = atoms.json（815 概念，唯一真源，本模块只读）
② 同义归一位置     = AI 写入侧（AI 自带翻译，传标准原子序列；
                     代码不维护同义表——职责收缩为「词表 + 校验」）
③ 归一产物         = fm.semantic 衍生层（可审查、可版本化）
④ 真源 + 原始双保留 = 正文原文无损，归一错误只污染摘要层，可重归一修复
```
三个纯函数职责：`atoms_zh()` 词表加载 / `oov_of()` OOV 审计（**警告不拒绝**）/ `pair_hits()` 组合窗口共现判据。

### 关键约束（勿违反）
- **字级原子库是真源**，`atoms.json` 里的复合概念需拆到字级
- **英文原子 = 语义整词/词组单元**，不做字符级拆分（`word` 不拆 `wo`）
- 纯音缀字（玻/璃/葡/萄，173 个）**不进词表**——它们无独立语义

### 白箱词法构造 A/B 评测（`bench_lexical.py`）

**语料：白箱知识卡 3,654 张 / 查询 2,401 条**。查询集由「术语：解释」结构确定性生成。

| 查询类 | 条数 | 最佳变体 | hit@1 | hit@5 |
|---|---|---|---|---|
| A 原样 | 150 | V0/V2/V3/V5 | 99.3% | 100% |
| B 口语化 | 150 | **V4_rrf** | **96.0%** | 100% |
| C 正文术语 | 150 | V3_idf23 | 25.3% | 96.7% |
| D 复合片段 | 1,951 | V3_idf23 | 90.0% | 98.6% |

**关键结论**：
- 口语化查询（B）：`V0_legacy` 41.3% → `V4_rrf` **96.0%**（+54.7pp）——四路 RRF 收益最大
- 正文术语（C）：所有变体 hit@1 ≤ 25.3%，**是已知天花板**（缺语义层）
- 综合最优：**V3_idf23**（2+3-gram DF-IDF）在 A/B/C/D 上表现最稳

> 复现：`python AEIS/tools/coggraph/bench_lexical.py`（结果存 `bench_result.txt`）
