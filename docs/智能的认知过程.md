# 智能的认知过程
## ——《白箱智能是什么？》续篇 · 智能如何运作

> 教学说明 v1.0 · 2026-08-28 · 灵枢（AEIS · Agent Engineering Implementation Specification，智能体工程实现规范）项目
> 上一篇回答了「白箱智能是什么」；本篇回答「智能如何运作」——用**认知过程**描述，而非「功能」：
> 功能是外在的产出清单，认知过程是内在的运作机制。

---

## 〇 一句话

**智能 = 一个认知过程：发现问题并识别条件 → 找到条件对应的知识、规则（递归进行）→ 精准执行 → 误差驱动结构更新（循环）。**

```
输入
 ↓
识别条件              ← 步骤①：发现问题，识别问题的条件
 ↓
寻找适用结构          ← 步骤②：找到条件对应的知识、规则（递归进行 ①②③）
 ↓
执行                  ← 步骤③：精准执行
 ↓
观察结果
 ↓
发现误差
 ↓
寻找遗漏条件          ← 反馈闭环（学习）：误差 → 结构更新
 ↓
修改/增加结构
 ↓
再次验证
```

**「不知道」不是认知过程的失败，而是它判断自己认知边界的正常输出**——正如上一篇的四态判定：条件不足 → DEFER（延后），无法归属 → BLINDSPOT（盲区）。

---

## 一 步骤①：发现问题，识别条件

认知的第一步不是「找答案」，是**确认问题是什么、在什么条件下成立**。

- 这个问题是什么类型？
- 它依赖哪些前提？
- 我（系统）有没有处理它的资格？

这一步落在白箱智能里，就是**四态判定**的入口：

| 判定 | 含义 | 认知语义 |
|---|---|---|
| ACCEPT（接受） | 条件满足 | 我有资格处理，进入下一步 |
| REJECT（拒绝） | 条件冲突 | 这个能力不适用，明确拒绝 |
| DEFER（延后） | 条件不足 | 现在不能判断，继续寻找缺失条件 |
| BLINDSPOT（盲区） | 无法归属 | 我不知道，不强行猜测 |

**为什么条件识别必须「白箱化」（由确定性机制承担）？** 这是「导航税」定律：条件判断是系统 2（慢思考、需要状态跟踪），生成是系统 1（快、自动）。大语言模型（LLM · Large Language Model）付不起导航税——它没有状态跟踪器，数不出「这是第几次尝试」。因此**条件识别必须外部化给确定性机制，LLM 只负责生成**。

> 认知过程的第 ① 步，本质是**把模糊的输入翻译成明确的条件**。

---

## 二 步骤②：找到条件对应的知识、规则（递归）

条件识别完成后，认知进入第二步：**用条件去路由知识**——不是找「最像答案的东西」，是找「条件满足的路径」。

### 2.1 条件路由

```
条件（海拔升高）
 ↓
知识 K1：海拔升高 → 大气压降低
 ↓
知识 K2：大气压降低 → 水的沸点降低
 ↓
知识 K3：标准大气压下沸点约 100°C
 ↓
结论：高原沸点降低，食物更难煮熟
```

每一步都有自己的知识和条件——**条件 → 知识 → 条件 → 知识 → 结论**，这就是条件路由图。

### 2.2 递归进行 ①②③（关键）

**「找到条件对应的知识」这个动作本身，也是一次完整的认知过程**：

```
我要找什么？          ← 发现问题（第 ①②③ 步的递归入口）
 ↓
它的条件是什么？      ← 识别条件
 ↓
哪条知识/规则匹配？   ← 再次路由
 ↓
找到 / 找不到 / 条件不足
```

这就是**递归**：知识描述知识，是条件路由图的子递归。**找知识时，系统在做和回答问题时完全相同的 ①②③ 认知过程**——认知过程不是一条直线，是层层嵌套的递归结构。

### 2.3 工程实现：两阶段收敛 + 注释索引

在灵枢里，第 ② 步落地为两阶段收敛检索：

1. **第一阶段**：问题条件 → 56 张学科卡 → 收敛到 14 个大域（并行打分）
2. **第二阶段**：在命中域内，沿**注释索引**（KCCS · Knowledge Card Comment Spec，知识卡注释规范）精确命中知识点

而「注释 = 图的索引」是这个工程成立的前提：中文注释是知识节点的可检索名，英文缩写补中文全称 = 同义词边（`BFS ↔ 广度优先搜索`）——没有中文注释，条件词就到不了节点，路由就会断裂。

---

## 三 步骤③：精准执行

找到适用的知识、规则后，认知进入第三步：**精准执行**——不是「模仿一个答案」，是**运行规则本身**。

这一步的裁决者是**物理基底**（真实论校准）：数学可以被扮演者自由生成，叙事可以被编造，但**编译错误就是编译错误，运行结果就是运行结果**——物理是认知主体唯一不可被自我叙事覆盖的观测，是认知的试金石。

```
执行规则
 ↓
物理基底裁决（编译/运行/断言）
 ↓
结果符合预期 → 结论成立
结果不符合 → 进入反馈闭环
```

> 精准执行的「精准」，来自**执行的是规则而非概率**——同样的输入 + 同样的条件 → 同样的结果（确定性）。

---

## 四 反馈闭环：误差 → 结构更新（学习）

认知过程没有在「执行」结束——它观察结果，发现误差，然后**返回认知结构本身**：

```
发现误差
 ↓
寻找遗漏条件（我少了哪个条件？）
 ↓
修改/增加结构（把新条件写进知识结构）
 ↓
再次验证（用物理基底重新裁决）
```

**误差不是失败，是遗漏条件的入口**：

```
原结构：条件 A + 条件 B → 结果 X
实际观测：结果 ≠ X
 ↓
检查：是否遗漏条件 C？
验证：A + B + C → 结果 X ✓
 ↓
C 进入认知结构，成为理论的一部分
```

这就是认知过程的**学习环节**：错误 → 定位遗漏条件 → 结构更新 → 再验证。认知结构因此随经验演化——这对应灵枢的知识飞轮（验证 → 归纳 → 联想 → 蒸馏 → 推演）。

---

## 五 为什么用「认知过程」而非「功能」描述智能

| | 功能描述 | 认知过程描述 |
|---|---|---|
| 视角 | 外在产出（能做什么） | 内在机制（怎么运作） |
| 三步骤 | 像是操作清单 | 是认知结构（层层递归） |
| 误差 | 失败/缺陷 | 结构更新的输入 |
| 「不知道」 | 能力不足 | 认知边界的正确判断 |

**「发现问题 → 路由知识 → 精准执行」不是智能做的三件事，而是智能运作的三层结构**——它递归嵌套、误差驱动、随经验演化。这就是为什么用「认知过程」描述更精确：**智能不是一个功能集合，是一个过程。**

---

## 六 与白箱智能的关系（续篇收束）

上一篇说：**白箱智能 = 每步决策可回答「依据什么 / 什么条件下成立 / 错了怎么办」**。

本篇说：**智能 = 识别条件 → 路由知识 → 精准执行 → 误差驱动结构更新**。

两者合起来：

> **白箱智能，就是把「智能的认知过程」显式化、可验证化、可递归化——让每一步都落在可以审计的结构上，让每一次误差都成为结构更新的输入，让每一次「不知道」都是对认知边界的诚实声明。**

这也是灵枢选择白箱方向探索通用人工智能（AGI · Artificial General Intelligence）的原因：一个能长期自主运行的系统，必须可靠地知道自己为什么能做、什么时候不能做、犯错之后应该改变什么——**这正是认知过程，而认知过程是可以被白箱化的**。
