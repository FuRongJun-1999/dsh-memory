## 2 三条公设

**P1（任务原子性）**：认知任务本身原子；非原子展开发生在实现层（神经计算/底层计算图），不构成任务分解。推论：`非原子任务→任务分解→子代理` 链条在本文模型内删除。

**P2（条件投影可分性）**：同一任务可在多个相互区分的条件空间上建立独立投影，各投影可独立收敛。依据：D=D(C)——不同投影携带不同信息可得性；四维给出「区分」判据。P2 只主张「可建立」，不主张必有信息增益——增益是否非零是实验问题（§6 测度3）。

**P3（收敛带宽有限性）**：单次认知的收敛带宽受调用带宽约束（④三之「调用带宽」）；多投影提高有效观测容量，不消除信息差。依据：R>C ⇒ 可靠传递不可能（④二）。

**总纲**：**认知任务是原子的，认知收敛可以是并行的，神经实现可以是非原子的。** 三者分属不同层（§5），禁止互推。

## 3 认知代理的条件论定义

### 3.1 六元组

$$A_i = \langle C_i, S_i, G_i, O_i, K_i, R_i \rangle$$

| 分量 | 条件论含义 | 灵枢工程对应 |
|---|---|---|
| C_i 条件空间 | 该代理的四维观测边界 | 任务条件空间声明 / spec 任务边界 |
| S_i 状态 | 已收敛的局部认知状态 | 最小充分记忆注入 |
| G_i 目标 | 目标信息差态 D*：该投影要把哪段信息差缩到什么程度 | 验收标准 |
| O_i 观测 | 条件空间在时间窗内的投影（快照三问：投影+演化） | 观测通道（tools 白名单） |
| K_i 知识通路 | 调用带宽约束下的条件路由面 | lingshu_cg / 上下文预算 |
| R_i 结果 | 局部收敛产物，带四态资格 | result.json 终态 |

此定义不需要神经科学，也不需要「注意力」——注意力只是收敛带宽分配的一种实现假说（CA6，继承公设 A1 标注）。

### 3.2 CA-T1（代理边界 = 条件空间边界）

> **当**两个条件投影在四维上存在实质区分（任一维不同且该区分影响信息可得性）**时**，它们构成有资格独立存在的收敛单位；**当**投影完全相同时，建两个代理无信息增益，属冗余配置。「实质区分」由融合位以四态裁决与验证基底判定，不由相似度判定（②五）。

条件式双向判据，非「当且仅当」——前提满足才有判断资格，不满足时本文不作判断（吸收 P1 逻辑修正）。

### 3.3 CA-T2（Task ≠ Agent）

同一任务上可存在多个代理（支持 X 的证据 / 反对 X 的证据 / 预测 X / 检查条件缺失）：G_i 可不同，认知任务是同一个。**代理数由条件投影可分性决定，不由任务大小/复杂度决定。**

### 3.4 为什么需要认知代理（条件论回答，替代 v0.1 的神经科学基座）

> 由推论 3（局部不可知，③六）：任一单投影的收敛结果必然携带该投影特有的盲区；由 D=D(C)：不同投影盲区结构不同。故对单投影盲区敏感的任务，多投影独立收敛+融合在结构上可获盲区互补。

**CA-T2'（条件式）**：当错误代价对单投影盲区敏感、且投影间盲区结构可证不同时，多收敛组织有资格优先。投影同构时多代理退化为重复计算——一致不构成正确性证据，只有验证基底裁决才算（共识≠真相，③七）。

## 4 收敛结构

### 4.1 收敛事件的位置变化

并发与串行的差别不是任务被拆，而是**收敛事件的位置变了**：

```text
E-单线程（G_c=整任务）          多收敛（G_c 下沉）
Task                            Task
 └─ Expand                       ├─ 投影A ─ 收敛R_A
     └─ Expand                   ├─ 投影B ─ 收敛R_B
         └─ Expand               └─ 投影C ─ 收敛R_C
             ↓                            ↓
           Root（全压一点）            Fusion（更高阶收敛）
             ↓                            ↓
          Converge                  Higher cognition
```

②五「两阶段并行收敛」（大域并行→收敛→域内并行→收敛）即 G_c 在知识层下沉的既有实例，本文将其推广到代理层。

### 4.2 融合位本身是认知代理

$$A_F = \langle C_F,\ S_F{=}\{R_i\},\ G_F{=}\text{裁决},\ O_F{=}\{R_i\text{及证据}\},\ K_F,\ R_F \rangle$$

并发不是终点：并发产生局部收敛，必须存在更高阶收敛，否则只是并行计算不是认知系统。**融合位裁决纪律**：不得以「多数一致」代替验证基底裁决；R_i 的四态资格与证据是输入面，R_i 冲突（反题）是冲突检测信号面。

**五层置信概念映射**（承接补充资料《概念分层对齐表 v0.1》）：融合位的裁决面只用 L2 证据基底与 L3 四态资格；L1 信任（P_trust）只调节 R_i 输入权重、不作终裁依据；L4 可信度与 L5 共识是代理与群体层的产出面，**不得反哺为融合位裁决依据**——共识≠真相的裁决纪律在概念层的表现即「禁止 L5→L2/L3 的越层反哺」。

### 4.3 蜂群定义

$$Swarm = \{A_i\} + \mathcal{F}$$

蜂群不是「很多 Agent」，是**多个局部收敛过程 + 更高阶收敛机制**。𝓕 的功能分解=五大单元（记录/反思/验证/输出/维生，③十三）。

### 4.4 条件论七操作 ↔ 代理图边标注

| 七操作（③十二） | 代理图位置 |
|---|---|
| 识别 / 声明 | 投影 C_i 显式化 |
| 分离 | 一任务 → 多 C_i |
| 路由 | K_i 知识通路 |
| 收敛 | R_i 局部裁决 |
| 反题 | R_i 间冲突检测 |
| 组合 | 融合位更高阶收敛 |

条件论七操作即认知代理图的完整边标注语法。

## 5 CA-T3（收敛粒度下沉的信息论判据）——v0.1 定理 T 重述

> **当**任务的信息流宽度（展开面在 D=D(t,C) 下产生的待观测信息速率）**超过**单收敛位的调用带宽（CA5）**时**：整任务压入单一收敛位=把宽展开面压进窄调用口，信息差按 R>C 推论扩大；此时收敛粒度下沉到多投影，是把**容量瓶颈转换为协调成本**的结构响应。
> **当**前提不满足（信息流窄/协调成本高/存在串行契约），本文不作下沉判断，串行由该前提正当化（CA4）。

「宽」不再来自任务分解——它来自系统状态演化产生的信息流本身（快照三问：任何单点观测都是窄的）。这是「任何任务默认允许多投影收敛」的信息论根据，同时保留了串行的正当出口。

### 5.1 串行正当场景四分类（承接补充资料《单线程与注意力集中 v1.0》§3.2）

| 类型 | 触发条件 | 例 |
|---|---|---|
| 基座串行 | 后序任务需要前序任务产出才能开始 | 先检索后判定；先实现后测试 |
| 约束串行 | 外部条件强制单线（资源配额/实时系统/安全协议/串行契约） | 锁持有期内的操作 |
| 成本串行 | 协调成本 > 容量收益（B4 的量化形式） | 微小任务的开销摊不平 |
| 认知伪串行 | 仅因「按顺序写」习惯，无实际依赖 | 可并行化的顺序文件生成 |

前三类是 CA-T3「前提不满足」的具体形态，串行正当；第四类不构成串行理由。

## 6 原子性三分与三层模型

### 6.1 原子性三分（禁止互推）

| 层 | 原子性 | 状态 |
|---|---|---|
| 认知任务 | 原子（公设 P1） | 建模公设 |
| 收敛过程 | 一次局部收敛=一个裁决单位 R_i | 本文定义 |
| 神经/底层计算 | 非原子：认知原子操作在实现层可展开为多个相互依赖的计算单元 | 实现层描述，不要求任务有分解结构（CA1） |

### 6.2 三层模型

```text
条件论 / 智能论层：条件、信息差、信任、目标
        ↓
认知代理层：原子任务 → 多投影代理 → 局部收敛 → 更高阶收敛
        ↓
神经基底层：非原子计算、并行展开、局部串行瓶颈
        ↓
Runtime
```

神经科学的位置：仅提供工作假设与启发（如 4±1 为调用带宽的生物学投影），不作为工程架构证明——本文所有定理均不引用它们（CA1）。

## 7 实验纲领：认知并发基础验证

核心问题：**一个认知任务能否稳定产生多个独立收敛过程？**

| # | 测度 | 条件论表述 | 与既有实验衔接 |
|---|---|---|---|
| 1 | 投影独立性 | 各 R_i 是否满足四维实质区分（CA-T1） | 蜂巢 4 视角审查雏形 |
| 2 | 可复现性 | 同 C_i 重复执行 R_i 终态一致 | GridWorld 确定性口径 |
| 3 | 信息增益 | 多投影融合后的 ΔD 是否显著大于单投影（P2 检验） | 新实验 |
| 4 | 冲突可检测 | 反题信号是否在融合位可观测 | 蜂群同错检测协议 |
| 5 | 融合可靠性 | Fusion 结果是否优于任一单投影 | 新实验 |
| 6 | 盲区发现 | 融合是否发现单投影的 BLINDSPOT（CA-T2'） | 新实验 |
| 7 | 增益递减点 | 投影数增加时 ΔD 增益率何时衰减（可用 d²D 判定，③十一） | 新实验 |

## 9 可证伪声明

| 命题 | 什么结果推翻它 |
|---|---|
| P1 任务原子性 | 找到一个认知任务，其正确执行必然要求任务层分解结构（而非实现层展开） |
