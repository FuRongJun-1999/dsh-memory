## 2. 六项实现—理论张力（盘点实查，如实列出）

1. **载体/位置主动合并**：理论四元中「智能载体」无独立槽，与观测位置合并为 `observation_position`（保留未来拆分扩展位）——主动合并非遗漏。
2. **时间维双重身份**：`time_window` 参与四槽声明完整性，但不参与路由键（实测仅 3 种取值，进哈希键是纯噪声）与条件词面匹配——「参与声明、不参与匹配」。
3. **无情境 ACCEPT 兼容窗口**：query/context 全空时正条件段跳过可 ACCEPT（reason 诚实标注「未做正条件确认」）——v1 明确保留的决策，与「条件授予资格」强主张存在张力。
4. **条件路由仅覆盖 knowledge 层**：`BUCKETED_LAYERS=("knowledge",)`，contextual 层不路由——收益验证范围有限。
5. ~~**条件扰动实验工件不在库**~~（2026-09-13 已解决）：`md_cg/test_ccg_perturb.py` 36 断言入库，命题①-④全部可复现（见 §1 表 #5）。同轮偿债：judge v2 断言过期 5 处（test_p1/test_p26_refindex/test_p27_docindex 旧断言仍期待「条件未命中→ACCEPT」）已对齐 DEFER 诚实语义。
6. **实现残留**：mdcg.search 负记忆覆盖段重复实现未清理（子类 `_neg_coverage` 已替代）。
7. ~~**test_p44 白箱镜像漂移（新发现，未修）**~~（2026-09-13 已解决）：真因修正——非「api.py 未同步」（其 modified 仅为 preflight fail-closed 行为层，与 schema/数据无关），而是 md 语料真源 `_md_cg_wisdom_graph/` **空壳化**（10 个分层目录在、0 个 md 文件，gitignored 可再生产物疑被清理误删，MdCGOS 对空语料静默返回 0 节点）。修复：`migrate_wisdom_graph.export()` 重新导出（4355/4355 逐节点、L1 层级/L2 关系/L3 字段三校验全绿）→ test_p44 四面对齐全绿（结构 4355/2948 一致、候选集 20/20、端到端严格一致 19/20 + 同分并列 1 非数据差异）。防复发：test_p44 的 force=True 重建即守卫（空语料 0/0 vs 源库必 FAIL）；再生命令=`python -c "from md_cg.migrate_wisdom_graph import export; export()"`。
