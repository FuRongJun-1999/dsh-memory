### ④★P0 记忆演化 fork（最高价值——条件论反事实的实验场）

- **pi 机制**：会话是 entry 树，任意历史节点可 fork；两种 scope（`branch` 只拷贝某分支路径 / `tree` 拷全树），运行态一律不复制（`session/types.ts:562-602`、`jsonl/repo.ts:146-196`、`fork-policy.ts:56-63`）；被放弃旁支由 branch_summary 归档（2048 token 定长摘要，`branch-summarization.ts:87-118,274`），切回时提供上下文。
- **灵枢现状**：认知图是**单一演化线**（`_evolution/ledger.md` 2,650 行账本），没有假设分支。条件论的「负条件/反事实显式化」在记忆层没有实验场。
- **建议落点**：`md_cg/mdcg.py` 新增 fork 层（节点 frontmatter 加 `branch_id`/`branched_from`；派生索引记分支 tip），`stg.py` 支持分支时间线；新增 `branch_summary` 节点类型（复用 `NEG_MEMORY_MARKS` 式的必填 MARKS 模式）。语义：大规模改写/遗忘策略变更前先 fork 推演，验证通过合并回主支（合并=按 `derived_from` 溯源回写），失败归档 branch_summary 教训节点。
- **验收**：fork→改写→合并后主支节点 `derived_from` 链完整可回溯；放弃分支不污染主支检索（召回主支时 branch 节点零命中）。
- **落地状态（2026-09-16 · CodeBuddy 端）：✅ 已落地**（commit `419305c`）。落点 `md_cg/branches.py`（新，分支真源）+ `md_cg/test_branches.py`（新）+ `mdcg.py`/`mdcos.py`/`mcp_server.py` 接线。语义：`BRANCH_MARKS` 教训必填 + 命名守卫；`fork`（副本 nid=`<主支>@<bid>`，layer/tags/importance/cs 继承旧 fm，`derived_from=[主支]`/`relation=split_from`，fm 落 `branch_id`/`branched_from`/`branch_note`）；`rewrite` 为**分支改写的唯一正路**——关键机制发现：`add` 是**全量重建 fm**（非增量更新），裸 add 改写分支节点不重传 `branch_id` 会让副本在索引退化成主支、实验内容泄漏进主支检索，故 `rewrite` 强制归属/血缘从旧 fm 继承、同名 extra 键剥离、override 快照留痕；`merge` 分支级合并（逐节点按 `branched_from` 溯源回写，主支缺失 `skipped` 不炸）；`discard`（require_admin→MARKS 校验→`branch_summary_<bid>` 教训节点入 knowledge→文件 `os.replace` 移冷区 `_branches/<bid>/`→索引摘除→audit）；`list_branches`。检索**一处过滤全链路生效**（`mdcg.search/_stage/_scan_nodes` 与 `mdcos._candidates` 加 `branch=None`：分支节点仅主支+本 branch 可见，与 session 过滤正交）；`mdcos` insight 增六分支 act。
  **偏离建议**：实现落**新模块** `branches.py` 而非文档建议的内联进 `mdcg.py`（`stg.py` 分支时间线未做）。**边界（如实）**：分支节点**不出库**（冷区 `_branches/` 在 root 下 LAYERS 外、索引隐身——永不删除但检索不可见）；`merge` 是分支级而非节点级。验收：`test_branches` **41/41** 全绿（含主支零污染，断言口径=分支 nid 不在命中集而非结果为空）、回归 10 套件 292 断言全绿、cogmap check 绿、lint 0。
