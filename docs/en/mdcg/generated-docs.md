# Generated documents

> **Languages:** [中文](../README.md) · English

Two documents under docs/mdcg are generated from source code and are intentionally not translated:

- docs/mdcg/cogmap_ops.md, generated by scripts/cogmap_sync.py from the registered cogmap operations.
- docs/mdcg/功能调用映射表_v0.1.md, generated from the same source of truth.

They are listed under generated and exclude in docs/en/TRANSLATION_MANIFEST.json. The audit rejects any pair that tries to translate a generated document, because a hand translation would drift the next time the generator runs.

To read these documents in English, use the generated Chinese page together with the tool reference in docs/en/mdcg/ccg.md and docs/en/mdcg/mcp-tool-names.md. If an English generated view is needed, extend scripts/cogmap_sync.py to emit it and regenerate, rather than editing the Markdown by hand.

Regenerate the source documents with:

    python scripts/cogmap_sync.py

Then rerun the translation audit:

    python scripts/audit_translation.py --check
