## 一、命题

**观测位置只是条件空间的一个坐标轴，不能冒充生效条件。**

一条知识的生效条件，严格说是它「处于哪个条件空间」的完整声明：

| 维度 | 槽位 | 含义 |
|---|---|---|
| 载体/位置 | `observation_position` | 谁在观察、在哪个尺度/视角（理论对齐《智能的公理化基石》第 121-123 行） |
| 时间 | `time_window` | 该结论成立的时间窗口 |
| 方法 | `observation_tool` | 用什么工具/方法得出 |
| 约束 | `existence_constraint` | 成立所依赖的存在性约束 |

结论不进生效条件——结论就是「功能名」本身。四条合起来才是「什么载体、在什么时间、用什么方法、在什么位置、受什么约束」。

**修正前**：`backfill.derive_fields` 取 `condition_space.observation_position` 单槽，前缀「观测位置：」，冒充 `# 生效条件`。真实库因此落了 **109 条**弱等价行（留痕 `basis=frontmatter.condition_space.observation_position`）。

## 二、规范：唯一来源与渲染格式

### 2.1 唯一合成入口

所有 `condition_space` → 文本的渲染，**必须**经 `md_cg/nodefile.py:condition_space_text(cs, require_full=True)`，不得存在第二套拼法。

```python
CONDITION_SLOTS = (
    ("observation_position", "载体/位置"),
    ("time_window", "时间"),
    ("observation_tool", "方法"),
    ("existence_constraint", "约束"),
)
```

| 消费者 | 用法 |
|---|---|
| `backfill.derive_fields` | 生效条件的合法来源链：`comment.生效条件` → `condition_space_text(cs)` → `""`（不再有单槽回退） |
| `chain.conditions_text` | 边/节点条件可读化，懒导入复用同一 formatter |
| `mdcos._slot_overlap` | 召回打分**不动**（本就四槽计权，position 权重 2.0），仅共用槽名常量 |

### 2.2 渲染规则

- 格式固定：`载体/位置：…；时间：…；方法：…；约束：…`，缺哪维不写哪维。
- 判定阈值：双主槽 `observation_position` + `observation_tool` 必在；四槽全缺 → 不写、登记待补。
- 多值槽用「、」连接，不裸数组入正文（避免词面召回误命中）。
- **全时窗是合法声明**：`time_window=[0.0, 9999999999.0]` 渲染为「全时窗（任意时刻成立）」，不是空占位。
- 可读化时间：具体窗口渲染为 `YYYY-MM-DD HH:MM～YYYY-MM-DD HH:MM（UTC）`。
- 占位护栏：槽值命中 `is_placeholder_text`（`骨架锚点`/`内容待填充` 等）不渲染为事实，仅登记 `placeholder_fields`。

真实库样例（`kp_archaeo_1787279493983`）：

```
# 生效条件：载体/位置：知识考古补全；时间：2026-08-21 02:31～2027-08-21 02:31（UTC）；方法：前沿既有知识（审核后）；约束：数学/信息论/动力学/信号处理标准定义
```

## 四、存量清洗与全库接线

### 4.1 弱等价行清洗（批次 `cond_fix_v01`）

- `fix_conditions_plan`：legacy=109，全部 `rewrite`，drop=0，conflict=0。
- `fix_conditions_apply`：**rewritten=109 / dropped=0**。
- 复算：`verify_conditions` → `legacy_position=0`、`from_synthesis=109+`。
- 幂等：再预演 `rewrite=0 / drop=0`（无候选；`conflict` 仅表示「当前值已不等于当年写入值」，fail-closed 不覆盖人工修改）。
- 回滚：`fix_conditions_rollback(batch="cond_fix_v01")` 按「当前值 == 写入值才撤销」。

### 4.2 全库接线（批次 `cond_full_v01`）

- `plan(include_partial=True)`：planned=1953，字段分布 `生效条件 1808 / 功能名 741 / 不适用条件 402 / 验证方式 1`。
- `apply`：**written=1953 / skipped_drift=0 / skipped_locked=0**。
- 复算后再预演 `targeted=0 / targeted_missing_conditions=0` → 幂等。

### 4.3 不变量（边界不动）

- 只经 `derive_fields` → `plan` → `apply` → 留痕 → `rollback`，禁止直接改盘。
- 留痕 `basis` 记 `frontmatter.condition_space(四槽合成)`；回滚仍按「当前值 == 写入值才撤销」。
- 跳过边界不变：`crypto.is_encrypted`；`SKIP_LAYERS=("rejected","unresolved","goals")`；`SKIP_TAGS=("gap_hint","scene","reconstructed","concept","insight")`；`INTERNAL_LAYERS=("anchor","self")`。
- 异常只记节点 id 与字段名，不 dump 正文（正文可能含私有/密文内容）。

## 六、纪律条目（可复用，来自本轮蒸馏）

1. **禁止单槽冒充**：不得把 `condition_space` 的任一单槽（尤其 `observation_position`）直接当生效条件；生效条件必须是四槽合成的声明。
2. **条件空间优先于文本**：能由四槽合成时，以合成为准；`comment.生效条件` 是人类显式声明，优先于合成，但两者若冲突须登记 `conflict`，不得静默择一。
3. **缺则待补，不发明**：补不全就登记待补，并在判定上落 DEFER/BLINDSPOT；不得用默认值或猜测把缺项「填满」。
4. **留痕驱动清洗**：存量修正只认 `_backfill.jsonl` 的 `basis`，且只改「当前值仍等于当年写入值」的节点，防覆盖人工修改。
5. **口径单一**：条件空间→文本只有一个入口；召回打分与文本渲染共用槽名常量，不得各写一套。
