## 0. 一句话结论

**灵枢不是从零开始，但也不是已就绪。** 五层中：**L0/L1/L3 三层已有可复用骨架**（其中 L1 的「冲突显式化」由 v1.0 暴露的 S1 缺口修复补强——代码修复 2026-09-12 `ce55c048`、2026-10-04 隔离库重测确认；L3 的「候选≠提交」在 2026-10-04 由变更确认档首次活库验证）；**L2 有退役与生命周期的半套件，缺「主体×谓词槽位寄存器」**；**L4 推演层几乎空白**（仅单点雏形）；**L5 缺「叙事/证据双层」的组装**。另有一组**低风险高收益的口径收口**：把现有件对齐到「断言元组十元」与「四条跨切纪律」。

## 1. 架构核心（评估基线，原文照录）

- **命题**：故事演绎／历史推演／因果推理／角色扮演＝同一问题类——信息不全下维护「带出处、可退役、可分档」的多主体世界模型＋受约束推演。
- **一个原语**：断言 `(主体,谓词,值,[t_from,t_to],精度,来源链,档位,断言者,断言时间,检验强度)`；事件/状态/承诺/否定/盲区皆为断言；**断言≠事实**。
- **一个引擎**：四态裁决器（accept/reject/defer/blindspot）；`D_norm = 0.30·U_trust + 0.25·U_behavior + 0.30·U_connection + 0.15·U_prediction_error`；`E_reduction=(D_A−D_B)/D_A`；**两条机械维度（来源档位×冲突时长）可驱动、可零 LLM**（CD-WHALE-01 回放 5/5）。
- **五层栈**：L0 记录 → L1 断言 → L2 状态 → L3 裁决 → L4 推演 → L5 呈现。
- **四条跨切纪律**：事件必记账／出处不升级／退役不删除·失效≠证伪／未决不进二值；统一时间核 `1−exp(−λt)`。
