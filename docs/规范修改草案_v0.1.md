## 二、建议改动（有证据）

### 改动 1 · 第 2 条加限定语

**证据** E3/E4：第 2 条（全面处理）在三个臂里**全部 0/4**，正例一律被判给第 11 条（历史查询优先）。

```
原文  2.全面处理：读任务要求→读工作记忆→查相关任务→(有成果:复用 | 无:设计+调研)
问题  第 11 条是其下位且更具体 ⇒ 上位概念永远输给具体条款，本条实际失效
改后  2.全面处理：读任务要求→读工作记忆→查相关任务→(有成果:复用 | 无:设计+调研)。
      当已有更具体的条款适用时，以具体条款为准；本条仅在其不适用时生效。
```

### 改动 2 · 触发条件写成「什么算做好了」的具体流程

**证据** E4（67%→78%→85%）+ E5（16/16 选具体，位置互换仍 16/16）。

**做法**：把「重要项目」「需求模糊」这类词换成可指认的门槛或动作序列。

```
改前  13.访谈澄清  触发：重要项目 / 需求模糊 / 新任务启动
改后  13.访谈澄清  触发：需求中至少有一项关键要素未定（对象/范围/验收标准），且任务非单步小改
      排除：明确单步小改动、聊天
```

### 改动 3 · 「命中即声明」改为「只引最相关的一条」

**证据** E2：27 份里只有 4 份只引 1 条，平均引 2.0–3.3 条。

```
改前  命中后原样输出该条声明
改后  只引最相关的一条 + 一句「其余条款为何不适用」（各不超过一行）
理由  引 3 条时读的人无法判断哪条在起作用——可审计性 = 能指认唯一依据
```

### 改动 4 · 新增「材料前置」判据（并入第 2 条）

**证据** E1：J4 盲评，材料依赖型任务无上下文时 **0/3**；抽象任务无材料仍 3/3。
**证据** E1：J6，135 份无上下文样本对目标仓的具体断言 **0**（本来就做得到）。

```
新增  材料依赖型任务，先确认材料可得。不可得时：
      ① 说明缺什么 ② 给力所能及的判断并标明哪部分没材料 ③ 不用相似材料顶替
```

## 七、改动 6 · 补「冲突裁决」总则（有无对照观测，非实验）

**证据**：2026-11-20 另一会话实测。思考面板显示，它显式权衡了「命中即声明」与「用户要求只做一件事、不要格式标记」，
自行裁决 **用户指令优先** 并有意不输出声明。原文：「指令优先于纪律声明。」

**问题**：

```
19 条之间没有任何优先级，与用户指令冲突时也没有裁定条款
该裁决是合理的，但**无依据、且不留痕**——对了没人知道，错了也没人知道
```

**改后（新增总则，置于 19 条之前）**：

```
优先级：① 涉及安全与不可逆损害的条款（第 9 / 14 条）
        ② 使用者的明确指令
        ③ 纪律的声明形式（引述格式、命中即声明）
让步规则：② 可让步 ③ 的形式，**不得让步 ①② 的实质要求**
留痕规则：凡做优先级裁决，须写出一句理由；不写视为未裁决
```

**边界（诚实）**：本条来自**单次观测**，无对照实验；但「冲突无规则」是结构性缺失，不依赖实验成立。

## 八、更正：第 8 条并非「总失效」

同一会话的思考面板显示：**该次思考全程中文**，并做了逐字数字数校验（14 / 15 / 14 字）。

```
原判断  第 8 条几乎不能约束成功（连我自己都没做到）
更正    不稳定，而非失效；有时生效且做了实质核对
```

因此改动 5（删句式强制）**保留原结论但降低强度**：仍是「保留中文书写、删固定句式」，
但依据从「不可执行」改为「不稳定且固定句式在交付面不出现」。

## 九、改动 5（正式版）· 第 8 条改为「理由进正文」

> 本节**取代**第三节表里「第 8 条删句式强制」那一行。文件名仍是 v0.1；
> 待真正改真源时随版本一并升号。

**促成这段改动的事实（都是观测，不是推测）**

```
① 思考面板是否显示、显示成什么语言，不由我可控，也不可自查——只能由使用者观察
② 同一会话中：有一次思考全程中文并逐个数字数（生效）；另一次强约束任务未出现可见思考（不稳定）
③ 使用者要求：理由写进正文，这样它在正文里**可读**
```

**改后条文**

```
第 8 条 中文书写与理由可读

触发：任何面向使用者的回答

动作：
  ① 面向使用者的文字用中文；标识符、代码、引用保留原文
  ② 有理由时，把理由写进正文；**至少给三种形态，不得只给一种**：
     · 理解式：我把它理解成 A 不是 B，因为你说了 X 没说 Y
     · 不确定式：我拿不准的只有 Z，若 Z 相反则结论要改
     · 依据式：我按 M 处理，依据是材料里的 N；若实际不是 N，这条要推翻
  ③ 该理由必须**可被反驳**——说不出错在哪的理由，视为没有理由
  ④ 没有理由时不硬凑；不套固定起始句式

排除：需要英文编写的场景、英文环境、英文文档、国际接口
```

**删除项（原条文的两处）**

| 删除 | 理由 |
|---|---|
| 「推理开篇即中文锚点」 | 不可观察、不可自查——它要求约束没人看得见的一层 |
| 「复杂用『我们需要』/ 简单用『让我』」 | 交付面实测 **0/10** 出现；且固定句式本身是复读风险 |

**与改动 3 的关系（同源）**

改动 3 要求「只引最相关的一条 + 一句为什么其他条款不适用」——**后半句正是理由形态**。
两条合起来是一个方向：**从「引条款」转向「说理由」。**

**可检验的地方**

```
机检   ① 面向使用者的文字是否为中文
       ② 是否出现固定起始句式（防退化）
人工   ③ 理由是否可被反驳：随便挑一条理由，问「如果这条不成立，结论会变吗」
```

**边界（诚实）**

- 第三节原写法「删句式强制」的依据是「不可执行」；本节改为「改成可读的理由」，依据是**可观察性**。
- 这是形态替换，不是新增要求——**不增加条目数**。
- 长会话里「理由」会不会退化成套话（新的复读燃料），**未测**；这是下一个要盯的地方。

## 十、示例数量的实测依据（reason_form_v2）

> 本节解释第九节 ② 为什么写「至少三种形态」。**一句禁令不够，得给形态；但只能给多种，不能给一种。**

**实验**：3 臂 × 2 链 × 6 轮 = 36 份，同一基任务，只改「示例数量」。

| 臂 | 理由段 | 开头唯一率 | 相邻复用 | 判定 |
|---|---|---|---|---|
| 单示例 | 12/12 | **5/12** | 0.21 | 不合格（固化） |
| **三示例** | 12/12 | **12/12** | 0.18 | **合格** |
| 无示例 | **1/12** | — | — | 不合格（不写） |

**读法（三种情形说的是同一件事）**

```
给 1 种   它当成唯一格式，12 条全以「我把它理解成」开头
给 3 种   它得挑，挑的过程让开头自然变化
给 0 种   它不写（12 轮只 1 次）
```

**合格线（写进条文，供以后改措辞时验）**

```
① 理由段存在率 ≥ 10/12   —— 防「干脆不写」
② 理由段开头唯一率 ≥ 8/12 —— 防固化（主判据）
③ 相邻轮理由段 Jaccard ≤ 0.4 —— 防套话
三条同时满足才算合格；只看②会鼓励「不写」
```

**一项与「不作假」的对照（值得记住）**

| 行为 | 要不要教 | 证据 |
|---|---|---|
| 不编造看不到的东西 | **不用教** | 135 份无上下文样本，具体断言 0 |
| 写理由 | **必须教** | 无示例时 12 轮只 1 次 |

**可教育性不同，写法就不该相同。** 前者写成红线即可；后者必须给形态。
