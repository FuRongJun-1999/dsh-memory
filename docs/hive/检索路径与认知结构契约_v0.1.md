# 检索路径与认知结构契约 v0.1

> 立约动因：外部审计（2026-09-19）发现「认知结构全部入库，但检索路径不调用它们」——
> 五条偏差经本侧逐行核对**全部成立**（证据见 §1）。缺的不是能力，是**「结构如何参与检索」的契约**。
> 本文件就是把这份契约写下来，作为重接线路（retrieval rewire）的判据。

## 2. 目标形态：检索 = 六阶段逐级收敛（而非全扫后过滤）

```
情境输入(query, context)
  ↓ S1 大域先验收敛      terms → big_domain_classify → 域集合；候选 = 该域节点 ∪ ORPHAN 兜底
  ↓ S2 条件空间前置门控  condition_space 硬槽（time_window/observation_position/存在约束）不匹配 → 不进候选
  ↓ S3 图扩散激活        以 (S1∩S2) 命中为种子，沿 edges 双向扩散 N 跳、按跳数衰减；不走全表
  ↓ S4 层级激活优先级    anchor/self 初始激活值加成（认知优先级，不是过滤）
  ↓ S5 负记忆抑制        rejected/unresolved 命中 → 对相关正候选乘性降权（抑制信号）
  ↓ S6 一致性交叉验证    对最终 top-k 做 crosscheck（复用 md_cg/crosscheck.py）
输出: 激活子集 + 分阶段审计计数
```

**每一步都在缩小范围**：触碰节点数应从「N(全库)」降到「域内 ∩ 条件匹配 ∩ 邻域」。

## 3. 各阶段契约（输入 / 输出 / 不变量 / 失败模式）

### S1 大域先验收敛
- 输入：`terms`（`expand_query_terms` 结果）、节点 frontmatter 的**域标签**
- 输出：`domains`（top-1 或 top-m，由 `big_domain_score_breakdown` 阈值决定）
- 依赖：**节点侧域标签**。现状只有 query 侧分类器，节点侧无域字段 → 需写入侧推断并持久化 `big_domain`（内容 → `big_domain_classify`），历史节点由回填器补齐
- 不变量：域收敛**不得丢召回**——ORPHAN/未标域节点必须留在兜底池；域内候选 < `min_results` 时自动放行兜底
- 失败模式：域分类错误 → 兜底路径必须能救回

### S2 条件空间前置门控
- 输入：`condition_space`（每节点已存）、`context`（调用方情境）
- 输出：通过门控的候选（**不读正文**即可判定：只用 frontmatter）
- 只前移**可判定的硬槽**：`time_window` / `observation_position` / 存在约束；语义类判定仍留 `judge_qualification`（后置，因需正文）
- 不变量：只剔除「明确不匹配」；**信息不足一律放行**（宁多勿漏）

### S3 图扩散激活
- 输入：种子集合、`edges`（出边在 `fm.edges`；白箱 KB 的 `edges` 表按 source/target 双索引）
- 输出：激活集合 + 激活值（种子 1.0，第 n 跳 × 衰减^n）
- 不变量：扩散**不得引入未通过 S2 门控**的节点；边方向/关系类型权重可配
- 失败模式：图稀疏（实测 142 节点 / 87 边）→ 覆盖不足，必须保留域内 LIKE 兜底

### S4 层级激活优先级
- 初始激活值加成：`anchor`/`self` > `structural` > `knowledge` > `contextual`（顺序可配）
- 不变量：只影响初始值/排序，不把不合格节点拉回

### S5 负记忆抑制
- `rejected`/`unresolved` 命中查询 → 对与其 `edges` 相邻或词面高度重叠的正候选乘性降权（`w ← w × (1-λ)`）
- 保留现有行为：负记忆仍作为结果条目返回（便于调用方感知），但不再与正候选同权

### S6 一致性交叉验证
- 复用 `md_cg/crosscheck.py`；对 top-k 输出 verdict 摘要，不进主排序

## 4. 开关与回退（缺一不可）

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `MDCG_RETRIEVAL_PIPELINE` | **0** | 总开关；关 = 与现状等价（回归必须全绿） |
| `MDCG_GATE_S1_DOMAIN` | 0 | 大域收敛 |
| `MDCG_GATE_S2_COND` | 0 | 条件前置门控 |
| `MDCG_GATE_S3_SPREAD` | 0 | 图扩散（`MDCG_SPREAD_HOPS`、`MDCG_SPREAD_DECAY`） |
| `MDCG_GATE_S4_LAYER` | 0 | 层级优先级（`MDCG_LAYER_BOOST`） |
| `MDCG_GATE_S5_NEG` | 0 | 负记忆抑制（`MDCG_NEG_LAMBDA`） |

规则：**默认关**；每阶段可单独开，便于逐项验证与归因；总开关关时 `search()` 走原路径。

## 5. 验收判据（每阶段都要过）

1. **等价性**：开关关 → `scripts/run_tests.py md_cg` 全绿，且返回与现状一致（快照对比）；
2. **有效性**：开关开 → `meta.scanned` 显著下降（阶段目标：S1 ≤1/10，S2 再砍，S3 只碰邻域），既有召回用例不劣化；
3. **可审计**：`meta` 增加分阶段计数（`domains/gate_in/gate_out/spread_hops/activated/suppressed`），供编外复核端逐项核对；
4. **落地判据不变**：内部独立复核 ACCEPT ∧ 零删除 ∧ 干净树回归绿 ∧ 逐候选可回退提交。

## 6. 里程碑与分支纪律

- 每阶段独立分支、独立复核、独立落地；落地后在 `origin/main` 打 `core-*` 标签；
- 探索分支随任务完结即回收（≤10 条，见 `hive/interop/note-branch-discipline.md`）。

## 7. 边界（不做的事）

- **不**用 FTS5/倒排表替代认知路径（那会让灵枢退化为普通搜索引擎，并掩盖机制失效）；倒排只可作 S1/S3 之后的**候选内**加速；
- **不**改写入侧语义（只补 `big_domain` 域标签这类检索所需的最小元数据）；
- **不**在默认路径上启用新行为（先 flag 化、逐项验证、再讨论默认开启）。

## 8. 首期范围（S1 + S2）

1. 写入侧：`add()` / `_write_node` 存 `big_domain`（内容 → `routing.big_domain_classify`）；新增幂等回填器 `md_cg/backfill_bigdomain.py`（支持 `--dry-run`）；
2. 读路径：`search()` 增加 S1 收敛与 S2 门控（flag 控），输出分阶段审计计数；
3. 测试：等价性快照 + 收敛率（`scanned` 下降）+ 召回不劣化；
4. S3~S5 依次跟进（各自独立落地）。
