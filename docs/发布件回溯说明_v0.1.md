# 发布件回溯说明 v0.1

> **一句话**：`@furongjun1999/dsh-memory` 的 **0.4.9 / 0.4.10** 两个已发布 tarball 夹带了
> 非追踪件（实验工作区 + 白箱 KB 运行时数据 + 认知图孤节点 + 字节码缓存），合计约
> **4009 件 / 28 MB**。该缺陷已由 `cee729a` 收口，**0.4.11 发布件为 1306 件**
> （本地门禁实测）；已发布版本按「不回溯」处置（§5）。

---

## 1 事实

| 版本 | 发布件数 | `docs/experiments` | 白箱 KB 运行时 | 孤节点 | `__pycache__` | 体积 |
|---|---|---|---|---|---|---|
| 0.4.9 | 4008 | 2434 | 474 | 6 | 1 | ~28.0 MB |
| 0.4.10 | 4009 | 2434 | 474 | 6 | 1 | ~28.0 MB |
| **0.4.11（收口后）** | **1306** | 0 | 0 | 0 | 0 | — |

**复算方式**：0.4.9 / 0.4.10 两行的件数与体积由第三方从 npm 镜像独立下载 tarball 后逐件
分类（**不调用本仓任何脚本**），结论与 `publish-artifact-check` workflow 头部的自述
**逐项一致**——即本缺陷属**如实披露**，非隐瞒。

**0.4.11 一行的口径**：为**本地门禁实测**（`npm pack --dry-run` 清单 1306 件、
非追踪件 0）。第三方报告在其基线 `1087ae4` 上测得 1302 件——该基线尚未包含后续提交的
增量件，加之统计口径差异，故与本行不逐位相等；**此处以实测为准，不沿用引用值**。

## 2 根因

`package.json` 的 `files` 白名单包含 `md_cg` 与 `docs` 两个**目录**，而 npm 在存在
`files` 白名单时**整体忽略根级 `.npmignore`**——只有「白名单目录自身的 `.npmignore`」
才生效。于是白名单目录内、被 `.gitignore` 排除的运行时产物（实验脚本 / `result_*.json` /
`_store` 数据目录 / 白箱 KB 的库与索引 / 认知图孤节点 / 字节码缓存）随包分发。

**为什么本地自检没拦下**：门禁脚本的历史版本只校验「发布件清单 vs git 追踪件」的
一致性，而这些目录属 `.gitignore` 忽略的**本地数据面**——它们在「非追踪件」判定里
出现过，但当时未按严重度阻断发布。

## 3 收口（`cee729a`，2026-09-20）

改用**子目录级 `.npmignore`**：`docs/.npmignore` + `md_cg/.npmignore` +
`skills/.npmignore`（共 54 行），覆盖三类：

1. **认知图运行时状态**：`_keys.json` / `_keys.*.json` / `*_audit.jsonl` /
   `_access.log` / `_index.json` / `_index.json.lock` / `_index_log/` / `_refindex.json`
   —— 与 `_keys.json` 同级别的凭据信封与审计留痕，**绝不入包**；
2. **Python 字节码缓存**：`__pycache__/` / `*.pyc` / `*.pyo` / `*.pyd`；
3. **实验工作区与含沙箱绝对路径的文档**：`docs/experiments/`（可重跑再生产物）等。

`md_cg/.npmignore` 同时排除白箱 KB 运行时数据与本地记忆面；`skills/.npmignore`
排除纪律模板的中间产物。

## 4 门槛（防复发）

- `scripts/check_publish_artifact.py`：跑 `npm pack --dry-run --json` → 按规则分类 →
  非追踪件白名单审阅 → `VERDICT=PASS / FAIL`；`--selftest` 覆盖清单解析健壮性与判据自身
  （含 `prepare` 文本污染 stdout 的场景、数组与对象两形态）。
- `.github/workflows/publish-artifact-check.yml`：本地模式 + registry 后置核验两种口径。
- 判据形态：**红着即拦下一次发布**（0.4.11 门禁实测：清单 1306 件、非追踪件 24 = 允许
  上限 24，`VERDICT=PASS`）。

## 5 处置裁定：已发布版本不回溯

- npm **不允许覆盖同版本号**，撤回（unpublish）会打断已安装用户的依赖解析——代价大于收益；
- 已发布件不含凭据（`_keys.json` 从未入包，此项经第三方逐件复算确认）；
- 措施落在「拦下一次」，并对本事实在此**留痕**，供使用者与审计者追溯。
