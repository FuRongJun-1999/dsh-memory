> **2026-09-30 更新（v0.6.1 发版核验）**：门禁链已由 5 条扩至 **8 条腿**——接入
> `check_unreachable.py`（死代码扫描）与两条 **Rust 腿**（`gate_rust_crate_test.py` /
> `gate_rust_parity.py`，批次 91 的 R-7「门禁转正」）。下表逐条与本机 `package.json`
> 的 `scripts.gate` 实读对齐，不是复述历史文档。
>
> **2026-10-01 更新（出货面冒烟腿转正）**：门禁链再由 **8 条扩至 9 条腿**——新增

## 三层防线

| 层 | 触发 | 跑什么 | 行为 |
|---|---|---|---|
| 本地 pre-commit | `git commit` | `python scripts/cogmap_sync.py build` | **自动重挂**行号，并把两份投影文档一并暂存 |
| 发布链 | `npm publish` | `prepublishOnly`：build → test → **`npm run gate`**（九道门禁，见下） | 任一步失败即阻断发布 |
| CI | push / PR | `cogmap-check.yml`：`cogmap_sync.py check` + `link_check.py` | 远端兜底红灯 |

## 为什么本地钩子跑 build 而不是 check

行号锚只能由管线从真源 AST 现算（`cogmap_sync.py` 纪律：**禁止手工书写行号锚**）。
v17-1 实证：真源位移按区域取 +8/+9/+15/+18/+37/+56/+87（**不是常数**），手工施加位移必然翻车——
那一次 32/32 处统一偏 −1，把 CI 门禁踩红。故本地做「**自动修**」（build 重挂），
发布链与 CI 做「**报错拦**」（check）。

## 安装（一次性 · 仓库级本地配置 · 不入库）

```bash
git config core.hooksPath scripts/git-hooks
```

撤销：`git config --unset core.hooksPath`

钩子真源：[`scripts/git-hooks/pre-commit`](../../scripts/git-hooks/pre-commit)
（该文件必须为 LF，已由根级 [`.gitattributes`](../../.gitattributes) 钉死）。

## 发布门禁清单（`npm run gate`）

`prepublishOnly` 在 build + test 之后调用 `npm run gate`，九道门禁与 CI **同形但不完全同覆盖**：

| # | 命令 | 守什么 | 对应 CI |
|---|---|---|---|
| 1 | `python scripts/check_unreachable.py` | 控制流终止语句之后的不可达代码（拦过 s5 负记忆段与 V21-4 通道 B 两族整段静默失效） | **无**（仅本地/发布链） |
| 2 | `python scripts/check_publish_artifact.py` | 发布件内容政策（凭据 / 私有数据 / 隐私文本 / 非追踪件） | `publish-artifact-check.yml` |
| 3 | `python scripts/check_publish_smoke.py` | **出货面冒烟**：真 pack → 空沙箱真装 → 从装好的目录真启动 MCP → 真发 `initialize` + `tools/list`，断言工具面 == 缺省面 `['cg','stg']` | **无**（仅本地/发布链） |
| 4 | `python scripts/cogmap_sync.py check` | 认知图行号投影与真源一致 | `cogmap-check.yml` |
| 5 | `python scripts/link_check.py` | 全库 md 相对链接可达 | `cogmap-check.yml` |
| 6 | `python scripts/workspace_index.py --check` | 工作区索引不陈化（第 18 条） | `workspace-index-check.yml` |
| 7 | `python scripts/verify_discipline.py --allow-missing` | 纪律真源 ↔ 各端产物一致 | `discipline-check.yml` |
| 8 | `python scripts/gate_rust_crate_test.py` | `cargo test` @ `rust/`（Rust 侧口径漂移的回归保障） | **无**（`hive-check.yml` 只跑 `hive/Cargo.toml`，`rust/` 至今零 CI） |
| 9 | `python scripts/gate_rust_parity.py` | `scripts/rank_parity.py` 逐位对拍（Python `search_rrf` vs Rust `mdcg-eval --serve`） | **无** |

> **第 3 道的位序不是随意的**：它紧跟第 2 道（同为「发布件面」），且**必须在第 4 道
> `cogmap_sync.py check` 之前**——前者的 `npm pack` 会触发 `prepare`（= 本仓的 `tsc` 构建，
> 会重写 `lib/`），越靠近链首越能让「包面自检」与「包已定形」两件事挨着发生；塞在链尾则
> 成了跑完一圈 Rust 之后才验包，失败反馈距离最远。位序由
> `scripts/test_publish_smoke_guard.py` 的 C2 断言钉死（挪到链尾即红）。

### 为什么需要第 3 道（同类缺陷已漏两次）

第 1–9 道里的**任何一道都拦不住「仓库里在、包里不在」**：第 2 道 `check_publish_artifact`
扫的是**包内件的内容政策**（凭据 / 私有数据 / 隐私 / 非追踪）——一个必要件**整体缺席**时
它没有任何可扫的对象，照样 VERDICT=PASS。实测两次同族事故：

- **#38**：`scripts/` 与 `hive/` 整目录未被 `files` 收录（源码树工具在包里不存在）；
- **issue #48**（0.6.1）：仓根 `utf8_boot.py` 未被 `files` 收录 ⇒ 装机后
  `python -m md_cg.mcp_server` 在 `from utf8_boot import ensure_utf8` 处 ModuleNotFoundError，
  **装机即挂**（修法= `files` 加 `utf8_boot.py`，提交 `52677077`；修完之后**仍无任何机器检查
  能拦住同类**，本道即该缺口的机器化收口）。

第 3 道的判据面（`S0`–`S6`，名字即机器读面，详见 `scripts/check_publish_smoke.py`）：S1 出货清单**点名**
含仓根 `utf8_boot.py`（缺则打印「修法：files 加 utf8_boot.py」）、S2/S3 装好的目录里点名
`utf8_boot.py` 与 `md_cg/mcp_server.py`、S4 真握手拿到 `serverInfo`、S5 `tools` **等于**
缺省面 `['cg','stg']`、S6 策略来源来自**包内** `data/policy.json`（只记录不判负）。
沙箱缺省 `tempfile.mkdtemp()`（跑完清理）；env `MDCG_GATE_SANDBOX_DIR` 给定时改用该目录并
**保留不删**（便于人工复核）。npm 解析复用 `check_publish_artifact.resolve_npm()` 单点
（Windows 命中 `npm.cmd`，不经 `cmd /c`）；探不到 npm 即 fail-closed 退出码 1，**不静默 SKIP**。

> **诚实边界（第 3 道不覆盖什么）**：不覆盖 DSH 桥侧（`dsh/` 插件与 MCP 客户端的接线）、
> 不覆盖真实 DSH 安装路径（装的是空沙箱里的 `node_modules`）、不覆盖 peer 依赖解析
> （安装加 `--legacy-peer-deps` 跳过 peer）、不覆盖 `MDCG_MCP_SURFACE=full` 的多工具面
> （只测缺省面）、不覆盖 TypeScript 侧 `lib/` 的运行时行为。

> **依赖提示**：第 7 道经 `render_discipline` 解析 `docs/discipline/harnesses.yaml`，需要
> **PyYAML**（CI 里显式 `python -m pip install pyyaml`）。本机缺 PyYAML 时 gate 会硬失败——
> 那是门禁正常工作，装依赖即可，不是误报。

> **诚实边界（勿读成「CI 全兜底」）**：第 1、3、8、9 道**没有对应 CI workflow**——远端不跑、
> 只有本地与 `npm publish` 会拦。Rust 侧的回归保障目前只存在于发布链这一处；
> 若要远端兜底，须新增 workflow（`rust/**` 触发 + 装 cargo 工具链）。

发布前可单独跑 `npm run gate` 自检。

## 不适用条件

本地钩子依赖 `core.hooksPath` 一次性配置；**未配置时该层不生效**，此时仍由发布链
（`prepublishOnly`）与 CI 两道兜底。本页不覆盖：非 md 文档的行号（本链只管认知图投影）。
