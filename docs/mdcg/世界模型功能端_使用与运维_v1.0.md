## 一、一句话

**事件是源、槽位是投影、查询走 stg**：

```
记账（写口）        台账（源）                    投影（物化视图，查询时现算）      查询面
cg(op=state_event) → <root>/_state_events.jsonl → md_cg/state_slots.py        → stg(op=state_chain)
（MCP 面）            append-only、不截断            （只读台账、不落盘、不缓存）        （默认关）
                                                                            ↘ CLI：python -m md_cg.state_slots
```

四个面各有单点真源，互不复制：写口只做权限/归一/落盘（`md_cg/mcp_server.py`），
台账只管追加（`md_cg/state_events.py`），投影只管回放（`md_cg/state_slots.py`），
查询面只管开关与返回体成形（`md_cg/stg.py`）。

## 二、台账（源）在哪、长什么样

| 项 | 内容 |
|---|---|
| 位置 | 库根下 `_state_events.jsonl`（与 `_recent.jsonl`、`_write_2pc.jsonl` 同级） |
| 性质 | **append-only**：只追加、不读改写、不截断（窗口滚动面 `_recent.jsonl` 不可作一等记录，故单立此账） |
| 一行一条 | `{t, subject, slot, old, new, kind, seq, evidence, actor}` |
| `kind` 五类 | `migration` 迁移 / `retraction` 撤回 / `enablement` 启用 / `acquisition` 获得 / `replacement` 替换；**未分类（None）合法** |
| 撤回语义 | `old` 有值、`new` 空 ＝ 值作废、无新值；启用＝old 空、new 有值；迁移/替换＝皆有值 |
| 坏行 | 容忍 ≠ 静默：跳过时计数 + 有界样本 + stderr 告警（`state_events.BAD_ROWS` 可读） |
| 多进程 | 跨进程文件锁（`FileLock`），崩溃不留半截文件（flush+fsync） |

**记账不判语义**：`kind` 只是检索面标签，不进判据；「不是事实」的言语（玩笑/元层/回忆转述）
之消歧标记（`not_fact`）**不在本批**（见 §八 边界）。

## 三、写：MCP 记账口 `cg(op=state_event)`

### 用法

```
cg(op="state_event", subject="鲸娘", slot="住所",
   old="别墅", new="小屋", kind="migration", seq=1108, evidence="r1108")
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `subject` | 是 | 事件主体（谁的状态）；去空白后为空即报错 |
| `slot` | 是 | 事件槽位（哪项状态）；同上 |
| `old` / `new` | 至少一个 | 变更前/后值；**双空非法**（空事件无意义）。撤回＝`new` 留空 |
| `kind` | 否 | 五类之一；缺省/空串/纯空白 → 归一为「未分类」（None）；其它值报错 |
| `seq` | 否 | 轮或序号（回指语料位置用） |
| `evidence` | 否 | 出处（短证/轮号/文件路径皆可，回查用） |

返回体：`{"ok": true, "event": {…落盘记录…}}`（`event` 即 append 落盘的那一行）。

### 失败口径（fail-closed，不吞）

| 情形 | 结果 |
|---|---|
| 缺/空 `subject`、缺/空 `slot` | `ValueError`（点名缺哪项） |
| `old` 与 `new` 双空 | `ValueError` |
| `kind` 非法值 | `ValueError`（列出允许五类） |

以上都是**原样上抛**的 `ValueError`（不是包装过的错误），客户端按普通错误处置即可——
**失败即不落盘**。

## 四、读：投影与查询

### 1. 查询面 `stg(op=state_chain)`（默认关，见 §五）

```
stg(op="state_chain", subject="鲸娘", slot="住所", include_retired=true)
```

返回体沿 stg 既有口径：`count`（条件命中总数，截断前）/ `items`（前 limit 条）/
`kept` / `truncated`。单元字段：

| 字段 | 语义 |
|---|---|
| `value` | 现值（撤回后为 null，直到下一个带值事件复活） |
| `state` | `active` / `retired`（**退役不删除**；缺省查询剔除 retired，`include_retired=true` 可见） |
| `t_from` / `t_to`、`seq_from` / `seq_to` | 生效区间与序号：`*_from` ＝最后产生当前值的事件；`*_to` ＝覆盖它的下一条事件（未被覆盖＝null＝仍有效／未闭合） |
| `tier` | 来源档位（台账行顶层 `tier` 透传；未带＝`unspecified`，**不编造**） |
| `history` | 该槽位全部事件原样七字段（`t/seq/old/new/kind/evidence/actor`）；`history=false` 时不带该键 |
| `alternatives` / `blindspots` | 结构在场、**恒空列表**（判定口径后置，见 §八） |
| `event_count` | 该槽位事件条数 |

**投影是物化视图不是第二真源**：查询时从台账现算，不落盘、不缓存——台账追加一条，
下一次查询结果即变。

### 2. CLI 人工入口（`md_cg.state_slots`，**恒可用**）

```
python -X utf8 -m md_cg.state_slots --status
python -X utf8 -m md_cg.state_slots --subject 鲸娘 [--slot 住所] [--include-retired] [--no-history]
```

数据根取 `MDCG_ROOT`（缺省走 `datapath.mdcg_root()`）。本 CLI 与 `MDCG_STG_STATE`
开关**无关**——那把开关管的是 MCP 读面；CLI 是只读人工排查入口（不改任何状态）。

## 五、开关

| 开关 | 缺省 | 管什么 |
|---|---|---|
| `MDCG_STG_STATE` | **关** | MCP 查询面 `stg(op=state_chain)`；关臂返回 `{"error": "disabled", "hint": …}`（**不是异常**——「没开」与「没命中」必须可分辨）；与 `MDCG_STG_INDEX`/`MDCG_STG_QUALIFY` 同纪律 |
| （无开关） | — | `cg(op=state_event)` 记账口**恒可用**（受权限闸约束，见 §六）；`md_cg.state_slots` CLI **恒可用** |

## 六、授权口径（与既有令牌面零新词）

- **`state_event` 走 `write` 词映射**：`cg` 面 op 作用域闸按 `write` 判定——
  凡 `ops_allow` 白名单含 `write` 的角色（或用 `"*"` 的设计者令牌）可记账；
  guest/只读令牌照拒。令牌面**不引入新 op 词**（角色白名单与派生收窄面零改动）。
- **`actor` 恒取令牌**（请求参数不生效）：落盘 `actor` 永远是令牌身份（无令牌形态为
  `"system"`）——客户端不得改写归属（沿本仓既有防伪造口径）。
- **写闸双保险**：台账是直写盘面的 append-only 文件、**绕过库层节点写闸**，故记账口
  另显式补齐 `require_write("internal")`——`can_write` × `theory_ok` × 密级三态各自生效
  （只读令牌、版本层校验未过、clearance 不足 internal 都会被拒且不落盘）。

## 七、读数与复跑：探针 + 守卫

### 1. 账本完整性探针（《秤》5.1 口径）

```
python -X utf8 scripts/probe_c_ledger_integrity.py \
    --events %TEMP%/state_events.jsonl --expect-slots 住所,房贷,名字 \
    [--out %TEMP%/probe_c_out]
```

| 读数 | 口径 |
|---|---|
| ① 事件覆盖缺口率 | `--expect-slots` 清单中「台账无任何记录」的槽位占比（分子/分母都打印） |
| ② 无账可辨率 | 对「无记录槽位」＋固定合成不存在槽位查询 `state_chain`：`count==0 且 items==[]`（**不编造、不反推**）的通过比例 |
| ③ 变迁史可查率 | 有记录槽位中 `state_chain`（`include_retired=True`、`history=True`）返回的 history 条数合计 == 台账该槽位记录数 的比例 |

`rates.json` + `probe_c_slots.jsonl`。

## 八、边界（如实）

- `alternatives`（同期未决值）/ `blindspots`（声明缺口）判定口径**后置**：本批结构在场、
  恒空列表，**不臆造填充**。
- 「不是事实」的言语（玩笑/元层/回忆转述）之**消歧标记**（`not_fact` 等）不在本批
  （P1 事件行无该信号）。
- 探针只测**账本面**可辨性；**生成器级「无账强答」未测**——那需要接生成器侧读数，后置。
- 槽位按**标签面精确匹配**（slot 名相等），不做同义归并/模糊匹配。
- `state_chain` 无 `time_axis` 语义：台账事件行只有落账时间戳 `t`，无第二轴（**不伪造**）；
  需要轴语义请走 `stg` 的 timeline/relation/anchors。
- 单库＝单台账：跨库/多租户合并不在此。

## 九、退役纪律：节点生命周期 `archived`（默认检索剔除）

> 《秤》v2.1 §5.2「退役纪律」口径的落地页。**先分清两个「退役」**（同名不同物）：

| 说谁 | 字段 / 参数 | 谁管 |
|---|---|---|
| 台账**槽位单元**的生存态（§四） | 投影单元 `state` = `active`/`retired`，查询参数 `include_retired` | `md_cg/state_slots.py`（查询时现算） |
| **节点**（md 记忆条目）的归档态（本节） | frontmatter / 索引 `lifecycle_state` = `archived` | `md_cg/lifecycle.py` 状态机 + 读面剔除 |

### 1. 语义（写定，逐档可对拍）

| `lifecycle_state` | 默认读/注入面（检索面 · stg 面 · 会话续接包全段） | 说明 |
|---|---|---|
| `active`（**缺键或非法值同此**） | 参与 | fail-open：存量节点零迁移、不误剔 |
| `converged` | 参与 | **降权轴**（同构聚合定型），不是退役 |
| `demoted` | 参与 | **降权轴**（弱化），不是退役 |
| `archived` | **默认剔除** | 退役不删除：节点文件仍在、可显式恢复 |

### 2. 判据与落点（判据单点，三个消费面）

- 判据单点：`lifecycle.is_archived(e)`（`md_cg/lifecycle.py`）≡ `state_of(e) == "archived"`；
  全部消费点共同引用，不各写一份口径。
- 消费点 ①（**cg 检索面**）：`MdCGOS._candidates`（`md_cg/mdcos.py`）——**检索类** cg 读 op
  （`route` / `read` 的检索分支与 `budget_tokens` 预算召回分支 / `search` / `search_rrf` 及其
  内含的 lexical·bucket·entity·graph·chain·temporal 各路）都经这一个候选池；
  `MdCGSecure._candidates` 经 `super()` 在其上叠加读可见性，判据同源。
  注意：cg 的读 op 并非全走候选池——见消费点 ③（会话续接面自持取数面）。
- 消费点 ②（**stg 扫描面**）：`stg._scan_one`（`md_cg/stg.py`，`_scan` 的逐条实现单点）
  ——`timeline` / `anchors` / `consistency` 三 op 的候选面同点覆盖，索引子集
  （`MDCG_STG_INDEX=1`）与全量遍历两条分支逐位一致。`relation` 是显式 id 直读、
  `state_chain` 走台账，两者都不经候选面（不受本节约束）。
- 消费点 ③（**会话续接注入面**）：`MdCGOS.session_recall`（`md_cg/mdcos.py`）的
  **四个取数段**——会话要点 `_session_notes`、活跃目标 `goals`、任务台账 `tasks`、
  未解问题 `unresolved`（`goals`/`tasks` 经 `_retired_by_id` 按 id 回查索引后交同一
  判据）。`cg(op=session, action=recall)` 自持取数面（不经 `_candidates`），它把节点
  内容装配成「续接包」回给调用方/注入上下文（＝注入面），故同接本判据。台账两段
  取**全量窗**（`_LEDGER_WINDOW`）过滤后截断 `_PACK_ROWS=5` 条，故退役剔除不会让
  包「不足额」；`tasks.active_total/done_total` 随之取**剔除后**的全窗计数（与列表
  同源自洽）。`recent` 段是事件窗口（非节点）、`self_state` 是只读快照卡，不涉退役。
  （独立复核 2026-10-06 两轮实测：接线前 archived 要点摘要、未解问题正文、活跃目标
  与任务卡均经该 op 照旧回出；现由守卫 R1.12/R1.13/R3.5/R3.6/R4.6 钉住。）

### 3. 不受限面（「退役不删除」的另一半）

- `cg.get(node_id)` 直读、`cg(op=audit)` 证据审计视图：archived 期间**照常可达**；
- 工程台账面（`goal` / `task`）与统计面（`health` / `whoami` / conformance）：直读索引，
  不受本节约束；
- **生命周期恢复**：库层入口 `MdCG.set_state(node, "archived"→"active")`
  （`md_cg/mdcg.py:2619` → `lifecycle.set_state`，走合法迁移表、逐级不跳级）；恢复后
  读面/续接面重新可见。**MCP 工具面没有独立生命周期入口**（`mcp_server.py` 全文无
  `set_state` / `lifecycle` 字样）——「显式恢复」是库层调用面。
- 与 `op=restore` 的区别（易混，写明）：`op=restore` 是 `op=forget` 的 `action=restore`
  → `cg.restore`（`md_cg/mdcos.py:3029`）＝把**已遗忘**（软删除进 `trash/`）的节点放回，
  是**删除轴**，与生命周期状态机无关；且放回时 `lifecycle_state` 按新节点（`active`）
  起判，`active→archived` 跳级被拒 ⇒ **不透传（落 `active`）**（既有行为，本轮未改）。

python -X utf8 scripts/probe_d_retirement_discipline.py    # 《秤》v2.1 §5.2 探针

### 5. 边界（如实）

- 只剔 `archived`。要让 `converged`/`demoted` 不参与，请走既有其他维度
  （`role` / `view` / `layer` / `session` / `validity`）——不得把它们并进退役判据。
- 台账单元退役（§四 `retired`）与节点退役（本节 `archived`）**各自独立、互不联动**。
- **面的判据（写死，供后续接线照此归类）**：**默认读/注入面**＝调用方给查询/意图/会话视图，
  **节点集合由库自选**且结果直接回给调用方或注入上下文 ⇒ 必须消费 `is_archived`；
  **定向/管理/统计面**＝调用方给出**显式节点选择键**（`node_id` / `subject:*` 标签 / 前缀 /
  层 / 状态）或面本身是诊断·统计·写面 ⇒ 直读，不受本节约束。
- 已接线消费面（3 处，4 子面）：检索面 `_candidates`、stg 面 `_scan_one`、会话续接注入面
  `session_recall` 的**全部四个取数段**（要点 `_session_notes` + 活跃目标 + 任务台账 +
  未解问题；后两段经 `_retired_by_id` 按 id 判据）（§2）。
- **已枚举但归入「定向/管理/统计面」（不受限，逐条申报）**：`cg.get` 直读、`op=audit`
  证据审计、**工程台账的显式管理查询面**（`cg(op=goal, action=list)` / `cg(op=task,
  action=list)`——直读台账，archived 期间照样列出，守卫 R1.13c 钉住这一侧）、
  `health`/`whoami`/`_role_counts`/`_sensitivity_counts`/`conformance`/`census`/`insight`
  统计、`review_records` 审核记录、`export`/`evidence` 导出与证据面、`crosscheck`/
  `ghostref`/`consistency` 诊断面、`backfill*`/`writelimit`/`freshness`/`forgetting`
  维护写面、`mreview/govern` 治理面、白箱 KB 工具面。
  **注意别与消费点 ③ 混读**：同一份 goal/task 台账，**注入面（续接包）剔除 archived、
  管理查询面直读**——这不是矛盾，是判据两侧的分工（守卫同时钉住两侧：R1.13b 剔除、
  R1.13c 直读）。
  其中**会回内容且集合由库自选**的一个代表面如实点名：`identity.profile`
  （`md_cg/identity.py:310`，按 `subject:<id>` 标签自选并回锚点正文摘录）——实测 archived
  锚点仍回出（取证：`identity.profile` 返回的 `anchors[0].content` 含归档节点正文标记）；
