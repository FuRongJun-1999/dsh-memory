## 一、一句话

**事件是源、槽位是投影、查询走 stg**：

```
记账（写口）        台账（源）                    投影（物化视图，查询时现算）      查询面
cg(op=state_event) → <root>/_state_events.jsonl → md_cg/state_slots.py        → stg(op=state_chain)
（MCP 面）            append-only、不截断            （只读台账、不落盘、不缓存）        （默认关）
                                                                            ↘ CLI：python -m md_cg.state_slots
```

四个面各有单点真源，互不复制：写口只做权限/归一/落盘（`md_cg/mcp_server.py`），
台账只管追加（`md_cg/state_events.py`），投影只管回放（`md_cg/state_slots.py`），
查询面只管开关与返回体成形（`md_cg/stg.py`）。

## 二、台账（源）在哪、长什么样

| 项 | 内容 |
|---|---|
| 位置 | 库根下 `_state_events.jsonl`（与 `_recent.jsonl`、`_write_2pc.jsonl` 同级） |
| 性质 | **append-only**：只追加、不读改写、不截断（窗口滚动面 `_recent.jsonl` 不可作一等记录，故单立此账） |
| 一行一条 | `{t, subject, slot, old, new, kind, seq, evidence, actor}` |
| `kind` 五类 | `migration` 迁移 / `retraction` 撤回 / `enablement` 启用 / `acquisition` 获得 / `replacement` 替换；**未分类（None）合法** |
| 撤回语义 | `old` 有值、`new` 空 ＝ 值作废、无新值；启用＝old 空、new 有值；迁移/替换＝皆有值 |
| 坏行 | 容忍 ≠ 静默：跳过时计数 + 有界样本 + stderr 告警（`state_events.BAD_ROWS` 可读） |
| 多进程 | 跨进程文件锁（`FileLock`），崩溃不留半截文件（flush+fsync） |

**记账不判语义**：`kind` 只是检索面标签，不进判据；「不是事实」的言语（玩笑/元层/回忆转述）
之消歧标记（`not_fact`）**不在本批**（见 §八 边界）。

## 三、写：MCP 记账口 `cg(op=state_event)`

### 用法

```
cg(op="state_event", subject="鲸娘", slot="住所",
   old="别墅", new="小屋", kind="migration", seq=1108, evidence="r1108")
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `subject` | 是 | 事件主体（谁的状态）；去空白后为空即报错 |
| `slot` | 是 | 事件槽位（哪项状态）；同上 |
| `old` / `new` | 至少一个 | 变更前/后值；**双空非法**（空事件无意义）。撤回＝`new` 留空 |
| `kind` | 否 | 五类之一；缺省/空串/纯空白 → 归一为「未分类」（None）；其它值报错 |
| `seq` | 否 | 轮或序号（回指语料位置用） |
| `evidence` | 否 | 出处（短证/轮号/文件路径皆可，回查用） |

返回体：`{"ok": true, "event": {…落盘记录…}}`（`event` 即 append 落盘的那一行）。

### 失败口径（fail-closed，不吞）

| 情形 | 结果 |
|---|---|
| 缺/空 `subject`、缺/空 `slot` | `ValueError`（点名缺哪项） |
| `old` 与 `new` 双空 | `ValueError` |
| `kind` 非法值 | `ValueError`（列出允许五类） |

以上都是**原样上抛**的 `ValueError`（不是包装过的错误），客户端按普通错误处置即可——
**失败即不落盘**。

## 四、读：投影与查询

### 1. 查询面 `stg(op=state_chain)`（默认关，见 §五）

```
stg(op="state_chain", subject="鲸娘", slot="住所", include_retired=true)
```

返回体沿 stg 既有口径：`count`（条件命中总数，截断前）/ `items`（前 limit 条）/
`kept` / `truncated`。单元字段：

| 字段 | 语义 |
|---|---|
| `value` | 现值（撤回后为 null，直到下一个带值事件复活） |
| `state` | `active` / `retired`（**退役不删除**；缺省查询剔除 retired，`include_retired=true` 可见） |
| `t_from` / `t_to`、`seq_from` / `seq_to` | 生效区间与序号：`*_from` ＝最后产生当前值的事件；`*_to` ＝覆盖它的下一条事件（未被覆盖＝null＝仍有效／未闭合） |
| `tier` | 来源档位（台账行顶层 `tier` 透传；未带＝`unspecified`，**不编造**） |
| `history` | 该槽位全部事件原样七字段（`t/seq/old/new/kind/evidence/actor`）；`history=false` 时不带该键 |
| `alternatives` / `blindspots` | 结构在场、**恒空列表**（判定口径后置，见 §八） |
| `event_count` | 该槽位事件条数 |

**投影是物化视图不是第二真源**：查询时从台账现算，不落盘、不缓存——台账追加一条，
下一次查询结果即变。

### 2. CLI 人工入口（`md_cg.state_slots`，**恒可用**）

```
python -X utf8 -m md_cg.state_slots --status
python -X utf8 -m md_cg.state_slots --subject 鲸娘 [--slot 住所] [--include-retired] [--no-history]
```

数据根取 `MDCG_ROOT`（缺省走 `datapath.mdcg_root()`）。本 CLI 与 `MDCG_STG_STATE`
开关**无关**——那把开关管的是 MCP 读面；CLI 是只读人工排查入口（不改任何状态）。

## 五、开关

| 开关 | 缺省 | 管什么 |
|---|---|---|
| `MDCG_STG_STATE` | **关** | MCP 查询面 `stg(op=state_chain)`；关臂返回 `{"error": "disabled", "hint": …}`（**不是异常**——「没开」与「没命中」必须可分辨）；与 `MDCG_STG_INDEX`/`MDCG_STG_QUALIFY` 同纪律 |
| （无开关） | — | `cg(op=state_event)` 记账口**恒可用**（受权限闸约束，见 §六）；`md_cg.state_slots` CLI **恒可用** |

## 六、授权口径（与既有令牌面零新词）

- **`state_event` 走 `write` 词映射**：`cg` 面 op 作用域闸按 `write` 判定——
  凡 `ops_allow` 白名单含 `write` 的角色（或用 `"*"` 的设计者令牌）可记账；
  guest/只读令牌照拒。令牌面**不引入新 op 词**（角色白名单与派生收窄面零改动）。
- **`actor` 恒取令牌**（请求参数不生效）：落盘 `actor` 永远是令牌身份（无令牌形态为
  `"system"`）——客户端不得改写归属（沿本仓既有防伪造口径）。
- **写闸双保险**：台账是直写盘面的 append-only 文件、**绕过库层节点写闸**，故记账口
  另显式补齐 `require_write("internal")`——`can_write` × `theory_ok` × 密级三态各自生效
  （只读令牌、版本层校验未过、clearance 不足 internal 都会被拒且不落盘）。

## 七、读数与复跑：探针 + 守卫

### 1. 账本完整性探针（《秤》5.1 口径）

```
python -X utf8 scripts/probe_c_ledger_integrity.py \
    --events %TEMP%/state_events.jsonl --expect-slots 住所,房贷,名字 \
    [--out %TEMP%/probe_c_out]
```

| 读数 | 口径 |
|---|---|
| ① 事件覆盖缺口率 | `--expect-slots` 清单中「台账无任何记录」的槽位占比（分子/分母都打印） |
| ② 无账可辨率 | 对「无记录槽位」＋固定合成不存在槽位查询 `state_chain`：`count==0 且 items==[]`（**不编造、不反推**）的通过比例 |
| ③ 变迁史可查率 | 有记录槽位中 `state_chain`（`include_retired=True`、`history=True`）返回的 history 条数合计 == 台账该槽位记录数 的比例 |

特性（硬性）：只读输入；隔离 temp root（把 `--events` 拷为该 root 的
`_state_events.jsonl`）——**零记忆库写入**；`--out` 必须落在仓外（fail-closed）；
**确定性**（同输入两次运行 stdout 与 `--out` 产物字节一致）；
stdout 末行 `PROBE_C_LEDGER_JSON {...}` 摘要（机器可读），`--out` 时另落
`rates.json` + `probe_c_slots.jsonl`。

### 2. 写口守卫

```
python -X utf8 -m md_cg.test_state_event_op            # 全链/双闸/防伪造/归一/校验/回归
python -X utf8 -m md_cg.test_state_event_op --mutate   # 定点变异自证（每条机制必须能被断言钉红）
```

## 八、边界（如实）

- `alternatives`（同期未决值）/ `blindspots`（声明缺口）判定口径**后置**：本批结构在场、
  恒空列表，**不臆造填充**。
- 「不是事实」的言语（玩笑/元层/回忆转述）之**消歧标记**（`not_fact` 等）不在本批
  （P1 事件行无该信号）。
- 探针只测**账本面**可辨性；**生成器级「无账强答」未测**——那需要接生成器侧读数，后置。
- 槽位按**标签面精确匹配**（slot 名相等），不做同义归并/模糊匹配。
- `state_chain` 无 `time_axis` 语义：台账事件行只有落账时间戳 `t`，无第二轴（**不伪造**）；
  需要轴语义请走 `stg` 的 timeline/relation/anchors。
- 单库＝单台账：跨库/多租户合并不在此。
