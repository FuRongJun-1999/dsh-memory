# 环二·白箱填充流水线 v0.1（测试阶段记录）

> 分工（使用者裁定 2026-09-17）：**LLM 提供模板并做校验；白箱负责确定性填充**；先测试（自有文件）→ 再试点（10 符号）→ 后规模化。

## 一、流水线四段

| 段 | 产物 | 性质 | 位置 |
|---|---|---|---|
| ① 事实提取 | 逐符号 required/optional/externals/guards/returns/doc | **确定性**（ast） | `md_cg/cond_facts.py` |
| ② 模板 | 7 槽位 + 10 规则 + 12 条校验清单 | **LLM 单次产出**（job `h1789643186033_ba80bc`） | `md_cg/cond_template.json`（含 `_provenance`） |
| ③ 填充 | 中文功能级生效条件 | **确定性**（零 LLM） | `md_cg/cond_compose.py` |
| ④ 校验 | 逐条 PASS/REVISE/BLINDSPOT + 依据 | **LLM 单次复核**（job `h1789643407918_380037`） | 见本文件 §三 |

门禁：任一条生成文本须过 `md_cg/condition_anchor.judge`（`ANCHORED` 或 `BLINDSPOT`；`WEAK`/`REJECT_META` 不放行）。**锚点通过 ≠ 语义正确**，故必须有 ④。

## 二、测试结果（自有文件：`condition_anchor.py` + `cond_facts.py`）

- 事实提取 13 符号；白箱填充 13 条；确定性门禁 **13/13 ANCHORED**；0 BLINDSPOT。
- 样例：`调用 judge 时，必须提供实参 cond、src；可选 prefix=""、suffix="" 可省略；体内引用 META_MARKS、IDENT 需已定义；返回 out；功能：判定单条候选条件。…`

## 三、LLM 校验结果与两处归因

- 结论：**8 PASS / 5 REVISE / 0 BLINDSPOT**；5 条 REVISE 全部集中在同一处，另有 1 处真实缺陷。
- **受控偏离（非缺陷）**：校验清单 C6/C9 要求「guards 非空时必须把每个 guard 原文写入」，但 `guards` 含**函数内部分支**（如 `if hits:`、`if i == 0 and …`）——那是实现细节不是前置条件。填充器按 `early` 标记只保留「首条语句且含 return/raise」的早退式前置。修正口径：**模板/清单需增加 `early` 条件**（此处登记为模板 v0.2 待改项，改由 LLM 复核）。
- **真实缺陷（已修）**：`doc_head` 截断 60 字导致词被切半（`option` ≠ `referenced`），校验器 C9 以原文比对抓出。修正：超长按句读收口，不再截半个词。
