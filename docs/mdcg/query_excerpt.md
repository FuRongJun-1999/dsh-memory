# 查询相关原文摘录

2026-10-13

当预算不足以装下整条记忆时，`excerpt_strategy="query"` 从原文里选取与查询相关的片段，返回片段在完整正文中的字符位置。它接在检索排序之后，不改变边权、关系链计分、候选资格或读权限。

```python
result = cg.recall(
    "林岚的钥匙为什么不能使用？",
    budget_tokens=1200,
    max_item_tokens=250,
    excerpt_strategy="query",
)
```

MCP 的 `mdcg_recall` 支持同名参数；统一工具的预算读取也可传：

```json
{"op":"read","query":"林岚的钥匙为什么不能使用？","budget_tokens":1200,"excerpt_strategy":"query"}
```

缺省仍为 `prefix`，保留既有正文开头截取。`max_item_tokens=0` 继续关闭摘录；新选项只在原装包流程需要截断时生效，并不改变该参数原来的触发条件。

算法按段落统计查询词 IDF，降低文内常见词的影响，以边际词项覆盖选择至多四个原文窗口。重复词项的收益逐次降低；长段落围绕匹配位置取窗。输出按原文顺序排列，相隔的片段以 `\n[…]\n` 分开，标记本身也计入预算。生产运行不调用模型，不新建持久化索引或全局明文缓存。

被截断的条目会增加：

```json
{"excerpt":{"strategy":"query","spans":[[120,240],[800,900]],"fallback":null}}
```

`spans` 是 `cg.get(id)["content"]` **完整正文中的 Unicode 字符位置**，右端不含；不是 Markdown 文件的字节位置。每个区间都是原文连续子串。不能跨省略标记拼接为一条引文，片段可定位也不意味着它足以支持某个结论。

空查询、没有词面命中、预算太小等情况下回退原前缀摘录，并在 `fallback` 给出原因。该策略不做跨语言语义匹配，也不保证选中所有反例、否定条件或多跳所需依据；未验证百万条、并发或真实私域语料。

公开 92 题评测与原始结果见 [评测报告](../eval/query_excerpt_20261013.md)。目前保留显式启用：有证据保留和规则层覆盖收益，同时增加 CPU 时间，真实 reader 仍出现了一条不可定位引文。
