## 二、采纳的含义与边界

1. **标准 = 检索面的默认算法**：0.9 之后新做检索/召回收口时，默认以 RRF3 v1.1 + ChronicleDM 为参照实现；既有 `md_cos`/`mdcos.py` 路径在迁移完成前仍是**在役实现**，不得两套并行产出不同结论。
2. **不得单方面改动判据**：外部实现并入时必须逐模块对照本仓条件空间（层 / 会话 / 时效 / 密级 / 资格四态），差异清单先行、再改码。
3. **算法权威唯一**：本文件为唯一登记处；`darkline`/`contour_semantics` 等图像面算法不受影响（本条只覆盖**文本检索面**）。

## 三·补二 打分层替换接口契约（第 9 轮定，供未来落地用）

既然 ① 的结论是「不能整包并面、只换打分层」，那替换面必须写成可判契约，否则又是一次漂移：

| 面 | 契约 | 不可让渡项 |
|---|---|---|
| 输入 | `(query, pool_snapshot, condition_ctx)`：`pool_snapshot` 是本仓已按 **层 / 会话 / 密级 / 时效 / 权限** 过滤后的候选集快照 | 过滤必须发生在打分层**之前**；打分层不得自行扩大候选集 |
| 输出 | `[(node_id, score, why)]`，`score` 只用于**排序** | 不得输出 `state`；四态只能由 `judge_qualification` 产生（已由 `test_issue111_gate_order` 钉住） |
| 副作用 | 纯函数：不写盘、不改索引、不记审计 | 需要记账时只能经既有审计入口 |
| 失败语义 | 抛异常或返回空集 | **不得**静默降级成「全放行」 |
| 可观测 | 必须能在不回放 LLM 的前提下重算同一 query 的排序（含随机种子/时间依赖的显式声明） | 时间依赖必须显式传入，不许隐式取 `now()` |

**判定**：满足上表即「打分层可换」；任何一条不满足，就是整包并面（已由 ① 否决）。

**第 9 轮负结果**：外部臂的检索归档 `runs/*/retrieval/*.json` 的 `material` 是 **ChronicleDM 渲染后的记忆文本**（含版本链与状态），不是原始快照 id 列表 ⇒ 无法用它做「检索层 gold@k 的同口径对照」，④ 的检索层对照同样需要 reader。
