## 二、采纳的含义与边界

1. **标准 = 检索面的默认算法**：0.9 之后新做检索/召回收口时，默认以 RRF3 v1.1 + ChronicleDM 为参照实现；既有 `md_cos`/`mdcos.py` 路径在迁移完成前仍是**在役实现**，不得两套并行产出不同结论。
2. **不得单方面改动判据**：外部实现并入时必须逐模块对照本仓条件空间（层 / 会话 / 时效 / 密级 / 资格四态），差异清单先行、再改码。
3. **算法权威唯一**：本文件为唯一登记处；`darkline`/`contour_semantics` 等图像面算法不受影响（本条只覆盖**文本检索面**）。

## 三·补二 打分层替换接口契约（第 9 轮定，供未来落地用）

既然 ① 的结论是「不能整包并面、只换打分层」，那替换面必须写成可判契约，否则又是一次漂移：

| 面 | 契约 | 不可让渡项 |
|---|---|---|
| 输入 | `(query, pool_snapshot, condition_ctx)`：`pool_snapshot` 是本仓已按 **层 / 会话 / 密级 / 时效 / 权限** 过滤后的候选集快照 | 过滤必须发生在打分层**之前**；打分层不得自行扩大候选集 |
| 输出 | `[(node_id, score, why)]`，`score` 只用于**排序** | 不得输出 `state`；四态只能由 `judge_qualification` 产生（已由 `test_issue111_gate_order` 钉住） |
| 副作用 | 纯函数：不写盘、不改索引、不记审计 | 需要记账时只能经既有审计入口 |
| 失败语义 | 抛异常或返回空集 | **不得**静默降级成「全放行」 |
| 可观测 | 必须能在不回放 LLM 的前提下重算同一 query 的排序（含随机种子/时间依赖的显式声明） | 时间依赖必须显式传入，不许隐式取 `now()` |

**判定**：满足上表即「打分层可换」；任何一条不满足，就是整包并面（已由 ① 否决）。

**第 9 轮负结果**：外部臂的检索归档 `runs/*/retrieval/*.json` 的 `material` 是 **ChronicleDM 渲染后的记忆文本**（含版本链与状态），不是原始快照 id 列表 ⇒ 无法用它做「检索层 gold@k 的同口径对照」，④ 的检索层对照同样需要 reader。

**④ 两条收口路径（成本不同，需设计者选）：**
- **A｜结项留限制**：以「零成本部分成立」记入本文件，默认算法不切换。成本=0。
- **B｜带 reader 的同口径对照**：用外部包 `results/extractions/` 既有产物做基线侧 reader（不新增模型调用，但口径为「带模型」）。成本=一次口径认同 + 一轮对照。

**④ 收口裁定（设计者，2026-10-19）：取 A —— 以「零成本部分成立」结项，限制如实留档。**

限制原文（不得在后续引用中省略）：

> 本仓 bigram 基线与外部臂的**同题对照未做**：外部语料含叙事体（B 系），零 LLM 规则抽取器事件级召回仅 56.8%（8280 条 GT 事件），不足以充当基线；强行产出题级读数会把「抽取失败」算作「算法更强」。
>
> 故 ④ 只以**零成本可得的离线词法基线**为证据（history 0.8475→0.9266、chain 0.8036→0.9286，+7.9/+12.5pp；滞后 0.2766→0.0），该证据支持「编年判别不是词法能做出来的」，**不构成**「本仓基线与外部臂同口径可比」的结论。

**当前判定：已采纳（标准登记），未落地（默认未切换）。** ①②③ 达标、④ 受 reader 成本约束；后续任何「切默认」动作必须先过本表四项。

## 三·补四 A 系子集对照（补证据，非替代 ④）

**设计**：同一抽取器、同一 `cutoff`，两臂唯一差别是**选择快照的策略**——
`rule` = 取 `seq ≤ cutoff` 的最新快照（版本感知）；`lex` = 取 `seq ≤ cutoff` 中与问题 bigram 相似度最高的快照（词法）。

**前置**：抽取器在 A 系的事件级召回须 ≥95% 才允许出题级读数——实测 **96.8%（4590/4740）**（含「同一快照多事件」后由 90.3% 提升）。

| 类型 | n | rule | lex |
|:--|--:|--:|--:|
| 状态归属 | 51 | 51.0% | 27.5% |
| 历史 | 45 | 88.9% | 82.2% |
| 现值 | 15 | 60.0% | 26.7% |
| 变更 | 15 | 73.3% | 6.7% |
| 时点 | 15 | 0.0% | 0.0% |
| 缘由 | 15 | 0.0% | 0.0% |
| **合计（A 系 156 题）** | 156 | **55.1%** | **35.9%** |

**可得结论**：编年敏感列上「选择策略决定结果」（变更 +66.6pp、现值 +33.3pp、合计 +19.2pp）。

**不可得结论（限制）**：
1. 两臂共用**同一粗糙抽取器**，时点/缘由两类均为 0%（抽取器对这两类无能）⇒ **绝对数不可与外部臂的 0.9266/0.9286 比较**；
2. 仅 A 系 156 题；B 系 486 题事件召回 **48.0%**，仍维持「需 reader」的结论；
3. 本对照是 ④ 的**补充证据**，不替代全量 625 的同口径对照（后者仍未做，A 裁决的限制说明不变）。
