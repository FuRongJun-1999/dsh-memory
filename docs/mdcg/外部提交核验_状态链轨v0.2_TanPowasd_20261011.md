## 4 五处限定（不推翻结论，但引用时必须带上）

3. **keyed 运行自己声明未过校准门**：`keyed_readings.json.calibration = "No keyed control arms; no claim of passing the full calibration gate"`；「四条全过」出自**另一份 controls bundle**（本记录 §3 已独立复现）。
4. **链长单调原始读数 `monotone=False`**（0.9655/0.9412/0.9463），依官方 `_nonincreasing` 的相邻桶容差通过；提交方用 `inspect` 读的是**官方函数默认容差**，口径忠实。**注意口径已演化**：我方首轮 v1 的 `校准零号_v1.json` 把 c3 记作「不合格（仅灵枢单调非增）」，与官方判分器现行 c3（被测臂退化 + 短链下界 + 高出结构基线）不是同一表述。

## 7 核验过程中的一处自我更正（如实记录）

首轮用官方 `--gate` 独立复现校准门时得到 **`passed=False`（c1/c2 不过）**。根因是**我未给判分器传 `control_arms`**，而官方常量 `CONTROL_ARMS = ('versionblind','closed')` **不带 `llm_` 前缀**，与提交方臂名（`llm_versionblind`/`llm_closed`）不同 ⇒ 取不到对照臂。把对照臂目录按官方命名改名后重跑即 **`passed=True`**。**是我这一侧的参数问题，不是提交方的缺陷**——如实记此一笔，以免后人据首轮读数误判。
