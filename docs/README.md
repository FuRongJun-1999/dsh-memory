# docs/ 目录索引

> 按工程域分目录，与本仓 README「平台全景」五件套对应。新文档先归域、后登记到本页对应清单；跨域的横切件留顶层。改纪律真源路径前须核对引用面（AGENTS.md / 渲染管线 / md_cg 注释）。

## 目录结构

```
docs/
├── mdcg/      灵枢大脑 md_cg 工程（架构/工具表/发布/教程/护栏）
├── swarm/     蜂群运行时 swarm/
├── hive/      蜂巢并发引擎 hive/
├── world_model/  世界模型神经网络底层架构（hex 系列台账）
├── theory/    智能论与白箱智能理论（跨工程）
├── eval/      评测与第三方验证报告
├── plans/     项目计划 / 交接文档 / 实验规格（跨工程）
├── discipline/  工作纪律渲染管线（模板 / harness 矩阵）
├── promo/     宣传物料
├── experiments/ 实验区（gitignored，可重跑再生产物）
└── 工作纪律_认知图条目_v1.1.json   ← 全局真源（横切面，不属单一工程）
```

## 归域规则（新文档放哪）

1. **工程文档** → 对应工程域（`mdcg/`、`swarm/`、`hive/`、`world_model/`；rust / compiler 有专属文档时新增同目录）。
2. **跨工程理论** → `theory/`；**评测 / 第三方报告** → `eval/`；**计划 / 交接 / 规格** → `plans/`。
3. **横切全局件**（工作纪律真源等）→ 留顶层，移动前必须核对引用面并全量重写。
4. 入域后在本页对应清单登记一行；`discipline/`、`experiments/`、`promo/` 既有惯例不变。
