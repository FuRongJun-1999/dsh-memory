# 《秤》v2.1 —— 多主体世界模型评测规范（最终修正版 · 冻结）

> **版本性质**：v2.1 是《秤》的冻结版。在 v2.0（四簿七维）基础上吸收红队评审的四条 P0 与两条 P1，完成最后一次修正。**自此进入实证阶段，不再增加指标。**
> **红队立法理由**：评审方本轮的攻击目标从"指标够不够"转向"**构念效度与因果可识别性**"——你测得很认真，但还没有证明这些读数确实在测你声称要测的东西。v2.1 的全部修改都服务于这一句话。
> **术语政策**：全文不用英文缩写。所有对照条件与指标以中文命名，旧缩写（Z/O/S/Ro/CBP/W-L 等）仅在本表留档备查。

## 1. 双轨制（P0 · 红队意见①）

《秤》v2.0 把理论稿的四条纪律直接当作评分维度，这在验证架构理论时成立，但作为通用标准则是**构念耦合**——它测的是"系统是否符合《多主体世界模型》的架构"，而非"系统是否是有效的记忆系统"。一个只保存当前有效事实、不存退役历史与未决队列的系统，在"告诉我当前信息"任务上可能很好，却会在纪律轨上全面记缺项。

v2.1 拆为两轨，**报告默认呈现通用轨**：

### 通用轨 · 记忆核心（架构中立）

只测任何记忆系统都该做到的事，不预设任何架构哲学：

```
记住了什么 · 找到了什么 · 是否正确 · 是否有证据
更新后是否正确 · 时间变化是否正确 · 冲突是否正确处理
```

不要求四态裁决器、不要求双层呈现、不要求出处链。检索管道、摘要系统、全文数据库与五层栈在同一秤上。

### 规范轨 · 世界模型纪律（理论特异，预注册）

才测《秤》真正原创的部分：

```
事件必记账 · 出处不升级 · 退役不删除 · 未决不进二值 · 双层呈现 · 因果边界
```

**两条铁律**：①规范轨必须在预注册时声明启用，不得在看到结果后补报；②两轨读数并列呈现，**不得只报系统占优的那一轨**。通用轨给出跨系统可比的底线，规范轨给出理论主张的检验——两轨分工即治理。

## 2. 对照条件（六条件 · 去缩写重命名）

旧五臂扩为六条件，全部展开命名：

| 本规范用语 | 旧缩写 | 输入 | 归因作用 |
|---|---|---|---|
| 闭卷条件 | Z | 仅题面 | 生成器先验基线 |
| 原文参照条件 | O | 语料全文 | 全文直读参照（**参照非上限**） |
| 足量证据对照条件 | Ro | 该题备齐的证据集 | 证据不缺时生成器能做什么 |
| **呈现对照条件**（新增） | — | 系统真实检索结果，换标准呈现器重包 | 呈现层是否独立致损 |
| 系统交付条件 | S | 系统检索 → 系统呈现 → 生成器 | 被测对象实际交付 |
| 写入探针 | Wp | 直接抽查记忆库内容（不经生成器） | 写入与表示层的机械核验 |

**更名修正两条**：其一，"原文参照"取代旧"原文上限"——全文输入受上下文、注意力、提示词影响，是参照不是理论上界；其二，"足量证据对照"取代旧"oracle 检索臂"——证据是否充分由覆盖判据保证（§3.4），不靠名字暗示。

### 2.1 六条件如何拆开四个环节

被测链条实为四段：**写入 → 表示 → 检索 → 呈现**（生成器是公用测量仪器，不计入系统账）。六条件对四段的隔离：

```
闭卷          → 生成器先验（什么都不给）
原文参照       → 生成器+全文的联合上限参照
足量证据对照    → 隔离生成器（证据备齐，测它会不会用）
呈现对照       → 隔离呈现（证据同、呈现换，呈现差则此条件胜）
系统交付       → 写入/表示/检索/呈现 的合计
写入探针       → 隔离写入与表示（直接查库，不经生成器）
```

**表示损失**首次可测：原文"A 导致 B 但仅在 C 条件下成立"，记忆里只剩"A 导致 B"——这不是写入缺失（句子在），是表示变换丢了条件。写入探针的结构保真维（时间/否定/条件/来源字段）专测此损。

## 3. 题库与判据

### 3.1 题型（八类，配比）

单点事实 15% / 跨段关联 15% / 因果链重建 20% / 时间与状态更新 10% / 矛盾与冲突 10% / 反事实干预（边界子测试）15% / 拒答与不确定 8% / 来源与证据回溯 7%。

答案键统一字段：题号 / 题型 / 必要采分点（权重）/ 支持证据位置 / 完整依赖面 / 潜在冲突证据 / **禁言项**（不得声称的结论）/ 缓答规则 / 干预说明（干预题必填）/ 足量证据集。

### 3.2 三层判据（机械先行）

机械层（逐字可定位、回源、结构字段、退役泄漏字符串比对）→ 结构层（关系保留、两栖对照、截断一致）→ 语义层（采分点覆盖 ≥0.7、缓答判定；判官须过锚自证：正确率 − 多数类基线 ≥15 个百分点；分歧题第三判官终裁；一致率不达标整批判"不可测"）。

### 3.3 证据状态向量（非互斥诊断）

逐题记：未写入 / 写入但丢结构（表示损）/ 已写未检索 / 检索被干扰稀释 / 呈现丢失 / 证据足而生成器误用 / 证据不足无法判定 / 多环节并发。只报聚合计数与典型样例，不作逐题定罪。

### 3.4 足量证据的覆盖判据（P0 · 红队意见② · 替代性能自证）

**废弃**"足量证据对照须达原文参照 90%"的性能自证——那是用生成器表现反证证据充分，循环。改为**证据覆盖先行**：

> 足量证据集必须满足：答案键每个必要采分点，至少有一个独立、直接支持它、且可在原文逐字定位的证据片段。覆盖率 100% 方可入足量证据对照条件。

判据纯机械（采分点 ↔ 支持片段的位置映射在答案键预标）。**性能仅作事后验证**：若足量证据覆盖 100% 而生成器仍失败，才可归因"读出/生成阶段"；不得再以"没达 90%"反推证据不足。这同时回应了外部研究的提醒：即便给到相关上下文，生成器仍可能产出无支持内容——足量证据对照正是为隔离这一现象而设，它的判据自身必须干净。

## 4. 四态判定（P0 · 红队意见④）

系统在每个维度的读数取四态，废三态：

| 态 | 含义 |
|---|---|
| 过 | 该能力实测达标 |
| 失 | 该能力实测不达标 |
| **不可观察** | 评测接口无法观察该能力（系统可能有但未暴露） |
| **不适用** | 该系统架构本无此层，且未声称提供此功能 |

**"我没看到"（不可观察）与"它没有"（不适用）必须分开**——混同则把观察局限误读为能力缺失，是标准设计里的危险跳跃。无栈系统在"缓"维记"不适用"而非"失"。

## 5. 规范轨探针（四条纪律 → 四探针）

### 5.1 账本完整性探针（事件必记账）

埋入"事件—状态"对：事件题记"何时因何"，状态题记"现在如何"。无事件记录却由状态反推事件强答，即**无账强答**。指标：事件覆盖缺口率、无账强答率。

### 5.2 退役纪律探针（退役不删除 · P1 · 红队意见⑤）

更新序列改为五状态语义，消除"删除"歧义：

```
现役 → 退役（降级留史、退出注入面）→ 撤销（取消当前有效性，保留曾存在之事实）
     → 删除（物理移除，仅审计接口可见）→ 未知
```

序列：写 v1 → 查 → 写矛盾 v2 → 查 → **撤销 v2**（非"删除"）→ 查。目标行为：v2 撤销后回 v1 或判缓；退役值**永不进注入面**；失效不等于证伪。指标：**退役泄漏率**（退役值出现在注入面的比例，规范轨头号危险指标）、更新采纳率、旧事实残留率、失效误判证伪率。

### 5.3 出处链探针（出处不升级）

三级出处（一手/转引/回指）+ 幽灵引用。指标：转引升级率、幽灵引用采信率、出处链完整率。

### 5.4 不判探针（未决不进二值）

应缓题（同档位来源互斥）的正确输出是**两存之**（两说并存＋列入未决），不是选边也不是笼统拒答。指标：强制二值率、误判缓率（应答题被滥缓）、两存表达完整率。

### 5.5 边界子测试与呈现分离探针

**边界子测试**：干预一个前提，预标应失据/应照旧/应盲三类结论，五维评分（删除识别/依赖识别/不变量保持/边界判断/证据重算），四类标签宏平均。答案键不公开。

**呈现分离探针**：叙事注入面与证据审计面分离；审计面须能交出出处链全量、两存、备择、盲区。指标：审计面可得率、两面一致率。

## 6. 校准零号试验（P0 · 红队意见⑥ · 正式实施的前置门）

**在测任何真实系统之前，先用人为破坏的系统攻击《秤》自己。** 构造五个受控系统：

| 系统 | 破坏方式 | 规范预期（预注册） |
|---|---|---|
| 甲 · 无记忆 | 不接入任何记忆 | 交付净增量 ≈ 0 |
| 乙 · 坏写入 | 随机删 30% 关键记忆 | 写入/检索/交付三维齐降 |
| 丙 · 坏检索 | 写入完整，检索随机打乱 | 写入正常，检索与交付降 |
| 丁 · 坏呈现 | 检索正确，删除时间/否定/来源字段 | 逐字正常，结构保真降、边界子测试降 |
| 戊 · 正常 | 完整系统 | 各维正常 |

**通过判据（预注册）**：各系统的指标下降方向与预期一致，且五个系统在剖面上可被区分（乙≠丙≠丁）。**不通过 ⇒ 规范不进入正式实施，先修指标再谈规模。** 这一步把《秤》从"我们认为这些指标能测记忆系统"升级为"人为破坏某一环节时，指标确实能认出这个环节"——**效度先于规模**。

## 7. 统计与发布

### 7.1 主终点与功效

主终点：**交付净增量**（系统交付条件 − 闭卷条件），自然问句 × 主语料 × 主生成器，题目级配对连续分数差，单侧配对置换检验，α=.05。兑现率降为辅助归一化，分母 <10 个百分点只报差值不报比例。功效：试点估三级方差（题/章节/依赖簇）→ ≥2000 次模拟 → 检出中等效应功效 <0.7 启动预案。区间用依赖簇为重抽样单位的自助法，附聚类阈值敏感性。

### 7.2 题目权重（红队意见⑩）

题目不等价（某事实被 8 题复用、另一事实只 1 题）。除簇自助法外，**并列报告题目加权与节点加权两套读数**：按章节/事实节点/依赖面对题目贡献去重加权。两套结论一致则稳健，不一致则说明题库对高复用事实敏感，须如实披露。

### 7.3 成本附录（红队意见⑫）

检索延迟、生成令牌数、记忆库体积、索引成本、查询成本、更新成本单列附录，**不进核心质量分**。成本是能力剖面的第二坐标，不是质量指标——准确率 85% 延迟 10ms 与 87% 延迟 2s 的系统，价值取决于场景。

## 8. 三级认定（更名 · 红队意见⑪）

旧名（随测/标准/复核）易被误读为系统智能等级，改为描述证据等级的中性名：

| 等级 | 最低证据要求 | 允许宣称 |
|---|---|---|
| **初测** | 闭卷＋系统交付＋逐字保真，机械核验，冻结配置 | 特定题集上的端到端表现 |
| **对照测** | ＋原文参照、足量证据对照、语义判分、配对统计与区间 | 交付净增量与瓶颈的有限归因 |
| **复核测** | ＋双语文料、**生成器交换矩阵**、留出复测、独立复跑、完整审计材料 | 限定场景内可复现的系统差异 |

**生成器交换矩阵**（红队意见⑭，复核档要求）：记忆系统甲/乙 × 生成器一/二 全交叉。若甲在生成器一强、在生成器二骤弱，而乙两台皆稳，则甲的优势依赖特定生成器配合——这比"换台复测"强得多。

两条铁律：高分数不能替代低证据等级；等级量证据完整度，不量智能水平。

## 9. 报告（十节 · 加共现矩阵）

评测摘要 → 预注册一致性 → 资产与执行环境 → 通用轨结果 → 规范轨结果（四探针）→ 边界与呈现 → 扰动与生命周期 → 统计与判分可靠性 → 失败案例与不可测项（不得为空）→ 复现材料与异议记录。

**失败共现矩阵**（红队意见⑮）：四簿是观察视角不是独立样本——一次退役泄漏可能同时拉低"退/构/推/增"四维。报告附维度间共现矩阵（退×构、退×增、构×边界、缓×增），读者据此知维度相关性，不把"一个错误四处体现"误读成"四项能力独立失败"。

## 10. 治理（强制 · 加防破盲）

四条强制不变：利益回避 / 全量产物公开 / 三重盲态 / 既有自报读数降级为待验假设。

**防破盲补丁**（红队意见⑪）：判官盲态在制度上存在、实际可能破盲——某系统输出的特有格式（字段名、置信度记号）会泄露身份。故**一切答卷送判官前须经统一输出归一化**（剥系统特征格式，统一为"答案＋证据"结构）。

**立法理由**：理论稿与其同源记忆系统、基准出自同一生态。本规范的价值不在于成就该生态，而在于对包括该生态在内的所有系统一视同仁。**三者可共享作者，不得共享裁判权。**

## 11. 冻结与实证路线

**v2.1 为冻结版。** 六条件、三层判据、四态判定、双轨、校准零号、三级认定——核心不再增加指标。新增测量维度一律走扩展轨道，读数不进认定等级。

**实证路线（按序）**：

```
第一步  校准零号试验    五个受控破坏系统 → 指标认得出破坏方向？
        ↓ 通过才进第二步（效度门）
第二步  试点            朴素基线 + 30题 → 判官校准 + 模拟功效
        ↓ 功效达标才进第三步
第三步  主实验          三栈级 6–8 系统 × 六条件 × 双轨
        ↓
第四步  扰动+生命周期+对抗扩展 → 报告 → 三级认定
```
