## 0. 一句话总纲

**蜂窝网格上的自研 CNN × 并行条件路由 × 递归四态搜索，以信息差递归分配替代反向传播，以存算一体认知图为上下文容器**——一条不依赖 GPU/链式法则/黑箱框架的白箱视觉与认知计算路线。识别的本质是查询（荣 2026-09-08），存储即计算（第五篇定论），参数是简单关系量、语义是关系组合结构（荣神经元模型）。

## 1. 理论基础（四条公理级裁定）

1. **反传语义（荣定义）**：训练=**信息差递归分配** + **死区门控**（超死区的信息差才传播）+ **递归收敛**。禁链式法则 BP——梯度不存在，存在的是"哪里还有信息没榨出来"。
2. **白箱原则**：核参数可学习，但结构/损失/梯度/路由全程可审计；每一步数值有出处（有限差分可复算），黑箱组件零容忍。
3. **连接主义范式（荣 2026-09-08 战略指令）**：从拟合到激活——四层关系架构 L0 差分链（100%）→ L1 区域（84.5%）→ L2 物体 → L3 大域；训练集缩小=构型覆盖率问题。
4. **存算一体认知图（第五篇定论）**：上下文不是检索结果缓存，而是**存算一体**——认知图节点既是存储（md 认知图）又是计算单元（路由/资格裁决/查询式激活）。

## 2. 架构总览

```
输入图像 → HexGrid 蜂窝网格化（48/64 列晶格）
    → hex_conv 蜂窝卷积（核库：smooth/edge/可学习核）      [L0 特征层]
    → 并行条件路由（特征前端=CNN，语义判定层=路由）          [L1 区域层]
    → 递归四态搜索（大域→子域并行细分，条件剪枝+死区终止）    [L2 物体层]
    → 层级合成（组合卡→场景质心）+ 复合体会意                [L3 大域层]
    → 查询式识别（ConnectionLibrary 连接相似性+条件判断）
上下文/知识 ←→ 存算一体认知图（md_cg，条件化+信任化 IR）
```

三大机制贯穿全层：**正交残差金字塔**（语义方向逐层 Gram-Schmidt 剥离+信息差自适应深度，hex_ortho；与 VCP ResidualPyramid 两处独立来源同构）；**误差驱动生长**（结构随信息差生长，非预设固定）；**四态资格裁决**（ACCEPT/REJECT/DEFER/BLINDSPOT 通用于节点、路由、搜索剪枝）。

## 4. 反传语义与训练（核心算法）

```
前向：特征 → 条件路由 → 判定
反向：信息差 D = |期望激活 − 实际激活|，按层级递归分配
门控：D < 死区阈值 → 不传播（活动稀疏性的算法形态）
生长：持续超死区的连接 → 结构生长（新单元/新连接）
收敛：递归至各层信息差低于死区 → 停止
执行：有限差分（扰动必须真实进入损失——R1 闭包捕获教训）
```

与 BP 的本质区别：BP 传播的是**梯度**（链式法则，需全局可微），反传语义分配的是**信息差**（局部可测，白箱可审计）。四个数值坑在案：deadReLU/均值池化/float32/闭包捕获。

## 6. 存算一体认知图对接

- **上下文=认知图**：查询式识别的 ConnectionLibrary 与认知图节点同构——连接=关系边，条件判断=条件空间卡，资格=四态；
- **路由/资格复用**：md_cg 的四路检索+judge 四态与 hex_search 的条件剪枝是同一机制在两个域的实现；
- **数据流**：hex 视觉产物经 vision_evidence 进认知图（vision-protection 管线已验证），认知图知识经查询式反哺识别；
- **与 MDCG 的边界**：hex 管**感知特征层**（蜂窝/连接/搜索），md_cg 管**知识记忆层**（节点/图/检索）——感知→认知单向沉淀（16 条闭环），认知→感知条件反哺。
