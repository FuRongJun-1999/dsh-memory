> **两个跨语开关别混**：`MDCG_UNIFY_QUERY`（统一归一层，**默认关**——2026-09-30 使用者

> 原子序列→词法路即可命中中文节点；**2026-09-30 收窄作用域：只对英文内容做翻译归一——
> 中文段逐字保留、绝不送 segment**，中夹英 query 的中文关键词串不再被逐字切开）与
