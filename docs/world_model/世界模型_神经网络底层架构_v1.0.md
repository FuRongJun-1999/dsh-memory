## 0. 为什么它是「世界模型的神经网络底层」

这不是命名类比，有三条可核验的条件证据：

1. **裁定原文直接指向世界模型**：`hex_cnn.py` 头部裁定第 2 条写明其固化语义取自《世界模型理论_白箱固化_v1》命题「LLM/训练引导 → 固化后零训练」；设计根基第 1 条取自《白箱身体补充计划》§六「蜂窝形感知」。该架构从立纲起就是世界模型理论在**感知/特征域**的实现件。
2. **层级接口互补**：世界模型理论的传感器层给出「摄像头/麦克风/YOLO/CLIP/LLM/文本通道为可插拔外部器件，是神经网络与智能是否白箱无关」；hex 系列正是**传感器之后的第一段**——把原始像素归一为蜂窝晶格与语义卡（感知层 IR），再上交给 L3 条件路由与认知图。世界模型缺这一层则上层无输入中间表示。
3. **与白箱化纲领四原理同构**（`docs/白箱化纲领_三项目学习总架构与Ghidra交接_20260916.md`）：本条链路是纲领 W1–W4 在感知域的独立实例，见 §7.2。

**一句话总纲**：蜂窝网格上的自研 CNN × 并行条件路由 × 递归四态搜索，以**信息差递归分配**替代反向传播，以**存算一体认知图**为上下文容器——一条不依赖 GPU / 链式法则 / 黑箱框架的白箱视觉与认知计算路线。

## 2. 架构主链

```
输入图像 → HexGrid 蜂窝网格化（48/64 列晶格）
    → hex_conv 蜂窝卷积（核库：smooth / edge / 可学习核）        [L0 特征层]
    → 并行条件路由（特征前端 = CNN，语义判定层 = 路由）           [L1 区域层]
    → 递归四态搜索（大域 → 子域并行细分，条件剪枝 + 死区终止）     [L2 物体层]
    → 层级合成（组合卡 → 场景质心）+ 复合体会意                   [L3 大域层]
    → 查询式识别（ConnectionLibrary 连接相似性 + 条件判断）
上下文 / 知识 ←→ 存算一体认知图（md_cg：条件化 + 信任化 IR）
```

**三大机制贯穿全层**：

| 机制 | 载体 | 说明 |
|---|---|---|
| 正交残差金字塔 | `hex_ortho` | 语义方向逐层 Gram-Schmidt 剥离 + 信息差自适应深度；与外部 VCP ResidualPyramid 两处独立来源同构 |
| 误差驱动生长 | `hex_train` | 结构随信息差生长（连续 patience 步停滞在死区外才添加新核），非预设固定 |
| 四态资格裁决 | 全链 | ACCEPT / REJECT / DEFER / BLINDSPOT 通用于节点、路由、搜索剪枝 |

## 4. 反传语义与训练契约

```
前向：特征 → 条件路由 → 判定
反向：信息差 D = |期望激活 − 实际激活|，按层级递归分配
门控：D < 死区阈值 → 不传播（活动稀疏性的算法形态）
生长：持续超死区的连接 → 结构生长
收敛：递归至各层信息差低于死区 → 停止
执行：有限差分（扰动必须真实进入损失）
```

`hex_train.py` 头部五条落地语义（原文照录）：

1. 调整 = 有限差分（零链式法则；参数预算纪律：单层可学习参数 ≤ 几百）；
2. 支路死区 = |lr·梯度估计| < 参数分辨率 → 该支路本步冻结（动了也没意义）；
3. 全局死区 = 信息差 ≤ 初始值×ratio → 递归收敛，固化时刻；
4. 误差驱动生长 = 连续 patience 步无显著下降才添加新核，mix 列零初始化（白箱平滑扩展）；
5. 演化史全程记录（何时调整/冻结/生长/收敛——白箱可审计）。

**与 BP 的本质区别**：BP 传播**梯度**（链式法则，需全局可微）；反传语义分配**信息差**（局部可测，白箱可审计）。

**四个数值坑（在案）**：deadReLU / 均值池化 / float32 / 闭包捕获（R1 教训：扰动必须真实进入损失）。
