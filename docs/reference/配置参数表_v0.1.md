## 分层表（谁能进用户配置文件）

| face | 进用户配置文件 | 进调参序列 | 理由 |
|---|---|---|---|
| ENV | 否 | 否 | 部署/隔离必需（根路径/凭据/身份/密级/解释器/写路径白名单）——改了会换库或换身份，不是「用户可调参数」，只登记分类 |
| TUNE | 是 | 是 | 阈值/开关/预算/条数/超时——用户该能持久化调 |
| CALIB | 是 | 是 | 默认值本身需实验找较优；进配置文件但必须带 status/evidence/since |
