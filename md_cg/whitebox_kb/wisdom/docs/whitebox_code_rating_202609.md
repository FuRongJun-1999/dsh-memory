## 本轮关键：W6 评估器缺陷修复（honest calibration）

**发现**：W6 0.7871 长期持平的 145 失败中，108 个（74%）是**评估器误判**——
`_max_depth` 遍历整棵 AST（含函数定义层级 + 字典字面量 + 表达式嵌套），
导致「求值-条件表达式 max_depth=11」「字节码-反序列化 max_depth=15」等
简单函数误判超深（实际控制流嵌套仅 3 层）。

**修复**：`_max_depth` 改为只统计**控制流结构嵌套**（If/For/While/Try/With/
ExceptHandler）——不计表达式/字面量深度。这是修评估器（非改数字掩盖），
让真实能力浮出水面。

**结果**：W6 **0.7871 → 0.9457**（+0.1586），总分 **0.9692 → 0.9851**。
W6 剩余 37 失败为真实 `avg_cc>8`（状态机语义复杂度，非冗余）。
