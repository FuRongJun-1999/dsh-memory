# 灵枢 AGI 架构探索分类 · 文档规划（2026-09）

## 一、分类命名与定位（荣裁定）

**分类名**：AGI 架构探索（AGI Architecture Exploration）
**定位**：不是「智能体架构」——那是工程框架（多 agent 编排/工具调用）。
灵枢是**架构探索**：在真实 DSH 环境中复现业界公认的 AGI 核心功能，
每一项都有工程实现 + 理论条款（智能论 v3.3）映射 + 可验证指标。
