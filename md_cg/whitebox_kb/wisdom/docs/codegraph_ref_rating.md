**解读**：
- 白箱高在「功能正确性」——681 单元有**确定性样例断言**（物理基底裁决）；
  codegraph 无统一测试样例，W2 只能编译近似（诚实声明，非能力差异）
- codegraph 高在「可读性」——英文注释质量好（Rust 生态文档惯例），
  白箱被短名惯例（ip/kw/m）拉低
- codegraph 的 W6 效率 0.8333 真实（图算法复杂度），与白箱状态机
  语义复杂度同源——都是「功能正确但实现复杂」的确定性特征

## 评估方法诚实声明

1. W1/W2/W3/W5 用**项目级构建 + 文件级结构近似**——Rust 文件不能独立
   编译（依赖 crate 上下文）；cargo check 受 zstd-sys C 依赖环境限制
   （`build-script-build` 失败，非 codegraph 代码缺陷）
2. W2 无样例断言（项目未提供统一测试集）——编译通过≠功能正确，
   这是**标尺对齐的诚实边界**（白箱有样例是它的结构性优势）
3. W7 按用户指示：**英文注释**密度（`//`/`///` 含英文）
