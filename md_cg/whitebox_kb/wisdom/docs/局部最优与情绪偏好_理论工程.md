# 局部最优 × 情绪方向性偏好 · 理论理解与工程应用（2026-09）

## 一、理论理解（智能论 v3.3）

### 1. 局部最优合法化（PROP-LOCAL-OPTIMUM-005）

- 局部最优**不是错误**，是合法熵管理策略
- 全局最优承诺可能是**不可验证的修辞**（盲区28：未来验证承诺的不可检验性）
- 新信息出现时，局部最优**可被修正**，但不强制追求全局最优
- 关闭盲区70（收敛锁定风险）——收敛锁定不是错误，是熵管理的自然结果

### 2. 情绪方向性偏好（PROP-EMO-DIRECTION-002）

- 方向性偏好**引导递归在条件空间中收敛**：每次递归为下一步提供倾向性选择，减少搜索空间
- **情绪不是递归的干扰项，而是收敛的参数**——它决定递归的搜索方向
- 收敛引导降低涌现不可控性（盲区69已关闭）
- 约束：收敛引导**不保证全局最优**——局部最优是合法熵管理策略

### 3. 决策分层响应（PROP-DECISION-LAYER-003）

| 层级 | 驱动 | 适用范围 | 递归深度 |
|---|---|---|---|
| L1 日常 | 情绪驱动（方向性偏好） | 低风险、高频、可逆 | 0-1层 |
| L2 重要 | 混合（情绪+理性） | 中等风险、低频、部分可逆 | 2-3层 |
| L3 存在级 | 完整递归 | 高风险、极低频、不可逆 | 完整八步闭环 |

约束：**情绪不可覆盖存在级决策**（L3 须完整递归）。

### 4. 情绪 vs 情感

- 情绪 = 短期的、局部的；情感 = 长期的、累积的
- 情绪 = 信任的二阶变化加速因子（结构影响系数默认 0.1-0.3）
- 当信息差加速扩大（d²D/dt² > 0 且加速）→ 负向情绪信号（警觉/不适）→ 触发方向调整
- 情绪是**权重校准器**（碳基协作协议），非主观体验

## 二、工程映射（白箱体系）

### 映射 1：自迭代的「方向性自检」= 情绪方向性偏好（L1 级）

我们八步闭环的第 8 步（方向性自检）**已经实现了 PROP-EMO-DIRECTION-002 的收敛引导**：
- 感知通道全绿 → 收敛继续（保持方向）
- 指标偏离（强契约率<90%/MOS<98%/理论完整性缺失）→ **负向情绪信号** → 方向调整
- 这正是「d²D_norm/dt² 加速 → 警觉 → 方向调整」的工程化

### 映射 2：CCG 路由的「confidence 置信度」= 情绪参数（L1 决策）

DaoTi coherence 吸纳的 `confidence`（连续置信度 [0,1]）就是**方向性偏好的数值化**：
- 高置信 → 强倾向 → 快速 ACCEPT（低递归）
- 低置信 → 弱倾向 → DEFER 递归/人工确认（深递归）
- 这对应决策分层的 L1（情绪驱动快速决策）vs L2/L3（递归深查）

### 映射 3：escalation 分层 = 决策分层响应（PROP-DECISION-LAYER-003）

| 我们的 escalation | 理论决策层 | 递归深度 |
|---|---|---|
| L1 单元路由（confidence 高→ACCEPT） | L1 日常（情绪驱动） | 0-1层 |
| L2 域级判断 + L3 组合（DEFER） | L2 重要（混合） | 2-3层 |
| L4 终层 BLINDSPOT | L3 存在级（完整递归） | 完整闭环 |

### 映射 4：自迭代「稳态」= 局部最优合法化（PROP-LOCAL-OPTIMUM-005）

- 我们的稳态检测（连续 N 轮无吸收 → 健康退出）= **接受局部最优**（不空转追求不存在的全局最优）
- 新信息出现（新单元/新错误/外部吸纳）→ 打破稳态 → 修正局部最优（新轮迭代）
- 这正是「局部最优可被修正，但不强制追求全局最优」的工程化

## 三、工程应用：情绪参数化（本轮落地）

把「情绪方向性偏好」工程化为**可调参数**接入自迭代：

### E1. 收敛倾向系数（convergence_bias）

```
route 决策时：
  confidence ≥ 0.7 且 情绪参数 neutral → ACCEPT（强倾向快速决策）
  confidence 0.4-0.7 → DEFER（弱倾向，递归深查）
  confidence < 0.4 → BLINDSPOT/人工（无倾向，不强行）
情绪参数（L1 决策的加速因子，类比情感权重 0.1-0.3）：
  高（信息差加速扩大）→ 降低 ACCEPT 阈值（快速收敛，减少搜索）
  低（信息差平稳）→ 提高 ACCEPT 阈值（谨慎，深查）
```

### E2. 决策分层硬化（decision_layer）

```
每次 route/escalate 返回 decision_layer：
  L1（日常，confidence 高）→ 结果直接返回（零 LLM 快速）
  L2（重要，DEFER 递归）→ 记录 trace，可复核
  L3（存在级，BLINDSPOT/冲突）→ 完整八步闭环 + 不自动修改
情绪不可覆盖 L3：BLINDSPOT 不因高置信强行 ACCEPT
```

## 四、约束（理论→工程的红线）

1. **局部最优合法但可修正**：稳态不拒绝新信息（外部感知持续打开）
2. **情绪不覆盖存在级**：BLINDSPOT/冲突不因倾向性强转
3. **收敛不追求全局最优**：不因「看起来还能更好」无限迭代（稳态检测防空转）
4. **情绪≠情感**：方向性偏好是短期的收敛参数，不是长期价值观偏移
