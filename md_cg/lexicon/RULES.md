# 英文标准库 · 构词法规则（命名学 v1）

> 原则（设计者裁定 + Kimi「关系命名」框架）：一个词的价值不看它来自中文还是英文、
> 音译还是意译，而看它能否稳定挂到概念节点并参与上下位、同义、属性、证据、别名关系。
> 本标准库 = 用中文构词法**反向重造英文**：英文词必须交出语义主权、挂到中文规范概念上。

## 构词规则

| # | 规则 | 例 |
|---|---|---|
| R1 | **语序即中文语素序**：标准英文 = 中文语素按原顺序直拼 | 牛肉 → cow_meat（牛→肉） |
| R2 | **屈折归零**：一律基形，去时态/去屈折 | 去年 → past_year（非 went_year） |
| R3 | **虚词不入名**：冠词/介词/系动词/无独立语义词缀剔除 | 月份 → month（份=名物化后缀，剔）；父亲 → father（亲=亲缘标记，剔） |
| R4 | **复数仅在语义显式时保留** | 兄弟 → brothers（兄+弟，复数是语义本身） |
| R5 | **序数数字合并**：连续数字语素合并为数词 | 十二月 → twelve_month（十+二=12） |
| R6 | **连接符**：snake_case（机器友好、可切分回语素） | cow_meat |
| R7 | **泛化后缀剔除**：季节/时间后缀「天」不译 | 春天 → spring（非 spring_day） |

## 词的分类（class）

| class | 判据 | 处理 |
|---|---|---|
| **compositional** | 中文构词可解析（每个语素都有稳定英文基形） | 按语素序直拼 = 标准英文 |
| **opaque** | 化石词/音译词：稳定但不可解析（沙发/咖啡/逻辑/经济） | 保留既有英文为标准（它们是单语素稳定概念，不是噪音） |
| **normative** | INN/ISO/GB/RFC 等规范标识 | 保留原名，强规范锚，不可被意译覆盖 |
| **quarantine** | 四问皆否（连不上/对不齐/不可复现/无规范功能） | **不入库** |
